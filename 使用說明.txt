Prompt Studio

這份原始碼尚未附帶 EXE。完整安裝說明見 docs/GETTING_STARTED.md。

Windows 64 位元，先安裝 Python 3.12。
在專案資料夾開啟 PowerShell：

py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py

後續只需最後一行，也可依安裝指南建立桌面捷徑。
現有 Start.cmd 不會自動選擇 .venv。

第一次使用：選模組 → 選素材 → 調整右側組合 → 複製 Prompt。
從桌面生成前需安裝 ComfyUI 擴充並啟用控制，詳見 COMFYUI_GUIDE.md。

原始碼版資料預設在專案根目錄 data；更新前請先備份。
JSON 不含圖片與模型；外部連結原圖及模型需另外備份。
