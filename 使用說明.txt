Prompt Studio 0.5

ComfyUI 側邊欄：選模組 → 文字欄自動更新 → 照常生圖 → 喜歡就收藏。
第一次選擇要控制的文字節點與收藏資料夾，之後即可直接使用。
PNG 保留原本的生成資料與當次模組快照；桌面圖片庫可查看並恢復組合。
安裝與操作請看 COMFYUI_GUIDE.md。

右側拖曳只調整組合的輸出順序，不影響左側模組。
新加入的群組按左側順位插入；位置超過現有項目數時放在末尾。

設定 → 外觀：選擇 Acrylic 後顯示透明度，可拖曳滑桿或輸入 0–100%；越高越透明。
調整會預覽，按儲存保留，取消恢復原設定；不影響文字與素材區的清晰度。
清除手動內容時，可勾選「不再提示」並確認清除；取消不會記住勾選。
如需恢復提示，在設定 → 外觀 → 操作確認勾選「清除手動內容前先詢問」。

主視窗已改用 Windows 原生外框與標題列按鈕，由系統統一處理四角、陰影及最大化。
玻璃區提高透明度，文字與素材主區域仍維持深色。

如果你在封裝資料夾內，雙擊 PromptStudio.exe 即可開啟，不需要安裝 Python。
如果你在專案根目錄，雙擊 Start.cmd。

請保留 EXE 旁的 _internal 資料夾；搬家時複製整個 PromptStudio 資料夾。
個人資料在 EXE 旁的 data 資料夾，可由「資料」選單建立 ZIP 備份。

開始使用：
1. 提示詞：左側選模組，中間選項目，右側複製完整 Prompt。
   右側可拖曳群組名稱、群組內項目或臨時片段排序；右鍵亦可向上／向下移動。
   手動修改後，上方組合變灰並暫停操作；「清除內容」只清除手動版本，恢復原本的組合。
   「存入素材庫」與「清除內容」位於文字框上方；複製成功會在按鈕上短暫顯示確認。
2. 模型管理：已設定本機 ComfyUI 模型路徑；點模型可填名稱、觸發詞、網址與預覽。
3. 圖片庫：先新增資料夾，再加入圖片。預設只連結原圖，另外保存縮圖。
4. 工作區設定：保存建議模型、CFG、步數與其他參數，修改後會保留參數版本。
5. 設定：可調整字型、大小、色彩、Windows 材質，以及聯網候選。

模型的「移至資源回收筒」會移除真實模型檔案，操作前會顯示完整路徑供你確認。
圖片庫的「移除圖片紀錄」只移除應用內的紀錄，保留原圖。
