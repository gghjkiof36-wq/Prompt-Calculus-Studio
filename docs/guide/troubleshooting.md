# 疑難排解

[回首頁](../../README.md) · 適用：0.8.9 Beta2

## 大型閱讀或貼上需要較久

大型文件載入、HTML 轉換與最後排版仍可能停頓。先等目前操作完成，避免連續重複貼上；只需文字時可用 Ctrl+Shift+V，或分段處理。搜尋到尾端後可切回原文繼續編輯，本版已修正 lazy 排版後的末段捲動範圍與游標。

## 匯入結果含整份對話來源，或怕覆蓋手改筆記

舊版輸出不會自動刪除。請用本版重新匯入，另建一份不把解析來源 JSON 當附件的副本；先保留手改筆記，再比較新舊目錄。分享前檢查原始對話與附件，一般 JSON 附件仍可能是合法且私人的內容。

相同來源與目的位置的已完成匯入會略過，來源更新另建新目錄。取消或失敗可能保留未完成目錄，重試也不覆寫它。完整操作見[貼上與對話匯入](markdown-import.md)。

## 關閉時保存失敗，或重開出現恢復內容

關閉文件會先完成已開始的貼上與輸入法組字，再保存。恢復副本成功落盤後可離開；原檔或刷新失敗且副本也未保存時，視窗保持開啟並保留稿件與 Undo，請先保存或另存到可寫位置。輸入法提交後仍在組字時也不關閉。重開後先核對恢復文字並另存。

原檔若已被其他程式改動，保留兩份內容後比較，不要直接覆蓋。資料目錄與系統暫存都不可寫時，不能保證退出後恢復；重要未保存文字先另存到可寫位置。恢復不包含完整舊 Undo 歷史，見[資料位置](data-backup-privacy.md#關閉與恢復副本)。

## 重開後流程沒有繼續，或原文件已關閉

重開會查詢原提交，尚未執行的 Stage 保留並暫停。打開原 Canvas，從「任務紀錄 → 流程紀錄」確認工作流與狀態，再按「繼續」。已分離的舊紀錄可查詢或停止，需重新生成時從開啟文件建立新流程。

關分頁、切文件、收到排隊回執或按取消，都不足以確認後端已停。狀態未知先查原任務，不重複送出；詳見[多文件任務](scheduling.md#多文件執行與重開)。

## 已連線，但提示工作流功能無法使用

服務可達、資料格式可讀與工作流可執行分別核對。若提示目前模式限制或未提供某項能力，按具體原因檢查服務；只有格式不支援才更新配套。見[相容指南](comfyui-compatibility.md#連線正常但工作流不能執行)。

## 素材輪數、重複或取消後位置與預期不同

畫布每批固定一份，讀取流程才提供多輪。多來源取較大輪數，短者循環；全部固定或允許重複隨機且用自動時預設十筆。候選項數不等於輪數；外層次數是批數。對照[素材與批次](prompt-materials-088.md)先用少量可辨識文字核對。

已成功保存的任務即消耗取值進度，取消不倒退；已保存六筆後下一批接第七筆。重試沿原筆值，預覽不耗用。舊格式有效進度升級時保留；若仍異常，先保留舊資料副本與問題位置，勿反覆匯入覆蓋唯一資料。

## 顯示「不支援的備份版本」

先將主程式與配套擴充更新為同版。現行支援文件 1–7，舊配套可能只支援 1–4 或 1–6；只重啟舊版不能增加能力。關閉 ComfyUI 後安裝一份同版擴充，由你重啟後端並刷新網頁，再核對實際載入版。不手改文件版本號，見[相容指南](comfyui-compatibility.md)。

## 舊 Stage PNG 無法還原

本版包含舊 Stage PNG 的受限還原：只恢復圖片確實保存且能核對的內容，不補出缺失的上游、圖片與完整執行進度。部分存量 PNG 仍可能無法還原，請保留原 PNG、Canvas 與備份，優先從原資料取回；不要改附加資訊、放寬驗證或覆蓋唯一資料。見[本版驗證界線](../releases/0.8.9/validation/beta.2.md)。

## 如何安裝

下載來源包，安裝 Python 3.12 後依[開始使用](getting-started.md)啟動。來源已含同版配套擴充，可從 PCS 內安裝；完成後重啟 ComfyUI 並重新整理網頁。

## 安裝擴充顯示未提供、等待關閉或版本未載入

先確認完整解壓來源主程式，保留 `extensions` 與安裝腳本；只複製 `run.py` 或個別檔案會缺少配套。也可用同版獨立擴充 ZIP 依[手動安裝](comfyui.md#手動安裝方式)操作。

安裝時必須關閉 ComfyUI。若無法確認程序狀態，不會當作已關閉；查明並關閉後再操作。安裝完成但載入仍舊版時，重啟 ComfyUI 並重新整理工作流網頁；「已安裝」與「已載入」是不同狀態。

不明來源、同版不同來源或較新版本會停止覆寫。保留現有擴充和 `.pcs-program-backups`，先查「檢視安裝紀錄」。中斷後狀態不明時不要反覆安裝或刪資料。要回退，停用自動更新、關閉 ComfyUI，移出目前擴充，再依備份記錄恢復相容版本。

## 安裝回復未確認

`rollback_unconfirmed`、`replacing` 或未知交易會阻擋下一次安裝。其他程序同時建立目標時，不會以「已恢復」代替原樹核對；停止重試，保留目標與 `.pcs-program-backups`，按紀錄核對原擴充及設定。不要刪掉其中一份來繞過保護。

## Manager 沒有更新按鈕，或更新後仍待確認

支援 Manager API v2 的本機環境才提供 PCS 內更新；Legacy Manager 可讀清單並從 ComfyUI 操作。先核對連線及 Manager 能力。共用更新佇列已有任務時，先在 ComfyUI 處理；結果不明時按「重新查詢」，避免重複更新。完成後自行重啟 ComfyUI，再核對套件載入。

## 底部取消沒有清掉全部等待項

底部叉號只取消目前項目，保留並暫停其他等待項。取消確認後按「繼續」可恢復；若要全部取消，使用叉號右鍵或預排程「更多」中的明確操作。單筆移除用清單右鍵，不會刪掉整個預排程模塊。

## ComfyUI 頁面在背景時停在準備輸入

確認同版擴充已載入，工作流網頁保持開啟；服務連線燈號不代表頁面能立即回應。回到該網頁查看原任務與訊息，必要時保存工作流並重新整理。若提交結果未確認，保留原紀錄、先核對 ComfyUI，避免連續重按執行。

## Stage 參數顯示唯讀，或模型選單不能修改

先將 PCS 與擴充更新為同版，重啟 ComfyUI 並重新整理原生網頁，重新開啟工作流。舊網頁載入的節點可能仍使用舊版控制，無須手動重建工作流。

將指標移到欄位查看原因。已接線或由 PCS 文字／圖片綁定控制的欄位，請到真正供值的來源修改；需要尺寸或批量大小時，選左側的 Latent 節點，不在 KSampler 裡找這些欄位。動態模型選項、多選或特殊控制可能仍是唯讀，可在 ComfyUI 原生網頁設定，然後在 Stage 中保留該欄位不覆寫。

## 種子不能編輯，或數字超過範圍

PCS 種子編輯上限是 `1125899906842624`（2^50），也受節點自身範圍限制；超過上限的既有種子保留原值並顯示唯讀，可在 ComfyUI 中管理。數值輸入使用完整十進位整數。多組種子或特殊節點若顯示唯讀，依欄位提示在原生網頁操作。

固定、遞增、遞減與隨機模式在種子旁選擇；修改模式或按「套用」不會立即換種子，生成時依 ComfyUI 原生時機更新。詳見[Stage 參數指南](stage-parameters.md)。

## 套用參數被拒絕，或等待項不採用新的 Stage 值

原生網頁或另一處操作改了同一欄位時，PCS 會保留草稿並提示衝突。先核對原生值，再重新開啟面板比較與設定，避免用舊草稿覆蓋新值。

等待項保存加入時的 Stage 設定。要改已排入的一筆，打開該項的「Stage 名稱 · 參數」，再按「套用至此任務」；修改一般 Stage 不回寫舊項。已開始準備或提交的任務不能再改參數，待該筆結束後建立新項。Canvas Undo 只撤銷畫布設定，不撤銷已保存的任務設定。

## 按執行只改文字，沒有生成

確認 CLIP／圖片輸入的紫色控制線已接入有效 Stage。沒有接 Stage 時只套用綁定輸入；單獨放 Stage 或只接預覽不生成。再確認 Stage 選的是目前開啟的工作流，綁定提示沒有待處理項目。接法見[Stage 與圖片流程](stage.md)。

## 按執行後沒有進展，或切換工作流一直載入

先到 ComfyUI 查看佇列與歷史，確認任務是否已開始或完成，再從 PCS 底部活動任務數開啟該筆紀錄查看訊息。若任務已在執行，等它完成，避免再次送出相同內容。

若工作流一直載入，保存需要保留的工作流後重新整理 ComfyUI 網頁，再開啟要使用的工作流。重新整理網頁不會取消已送出的任務，仍需查看 ComfyUI 的任務狀態。

## ComfyUI 已生成圖片，PCS 沒有顯示

先確認 ComfyUI 的該筆任務已完成，圖片仍存在。從 PCS 底部活動任務數打開這筆紀錄，按「重取結果／重試失敗項」重新讀取圖片。

若 ComfyUI 顯示生成失敗，先處理工作流中的錯誤；再使用同一按鈕重試該項。若畫面提示指定圖片或輸出節點不存在，重新選擇實際有結果的節點或圖片。

若圖片已生成，但沒有填入下一步的圖片輸入欄位，目前需要手動選用該圖片。直接再次按「執行」會開始新的生成。

## 網頁文字被更新，或 PCS 文字沒有送出

檢查 CLIP 左側接入的文字、綁定節點與欄位，以及是否由上游供值或已被其他 CLIP 占用。PCS 文字只有按執行才套用，未綁定的原生欄位保留。詳細步驟見[連接與綁定](comfyui.md#第一次連接與綁定)。

## 圖片來源換了下一張，卻沒有繼續生成

圖片來源未直接接資料預排程時，一輪成功後會換圖，但不自動開始下一輪。要整批供應，將圖片來源直接接資料預排程；最多同時保留十個未結束項目，完成後再補入。Stage 輸出三張給 B 時，B 會逐張處理，收齊後才進 C。完整接法見[Stage 圖片流程](stage.md#串接多個工作流)與[預排程](scheduling.md)。

## 預覽空白或停留舊結果

未接線時預覽會清空，可另開「最近生成」。有接線時，確認原生工作流身分與輸出節點正確，ComfyUI 任務已完成；歷史被清除、圖片原檔移走或第三方輸出格式均可能使結果無法取得。回報時附版本、步驟與經去識別的 prompt_id，不上傳私人圖片或完整工作流。

## 更新擴充被拒絕

關閉 ComfyUI，核對完整包及 DesktopData 路徑；新舊擴充名稱不可同時置於 custom_nodes。保留舊包與資料後，依 [安裝指南](comfyui.md) 處理。不要直接覆蓋唯一資料或刪除憑證。

## CivitAI 回傳 401

檢查帳號權限、目前 Token 與模型存取限制。若使用 Token，請確認它仍有效且有權限存取該模型。只提供去敏的狀態碼與重現步驟，勿分享 Token、帶驗證資訊的網址或整份下載收據。

## CivitAI 偶發退出

本版已修正一條已重現的預覽排版退出路徑，但不代表所有退出原因都已排除。若仍發生，先保留未保存內容，記下版本、進入的頁面與操作順序；若可取得去敏錯誤訊息再附上。不要上傳 Token、私人圖片或完整下載收據。

## 資料庫被占用或素材不見

同一資料庫只開一個 PCS 主視窗；不要在程式運行時刪鎖檔。素材不見先核對 data 或 PROMPT_STUDIO_DATA，避免匯入覆蓋另一份資料。參考 [資料與隱私](data-backup-privacy.md)。

## 回報問題

到 [Issues](https://github.com/gghjkiof36-wq/Prompt-Calculus-Studio/issues) 附上 PCS／擴充版本、Windows 與 ComfyUI 版本、重現步驟、預期與實際結果，以及去敏錯誤訊息。安全問題依 [SECURITY](../../SECURITY.md) 私下回報。不要上傳資料庫、金鑰、私人圖片或日誌中的個人路徑。
