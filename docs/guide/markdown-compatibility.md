# Markdown、公式與圖片相容性

適用：PCS 0.8.9 Beta3 本機試用版，Chrome 擴充 0.2.6。

PCS 以保留原文為基礎，將常見 Markdown、Obsidian 核心語法與 ChatGPT 回覆呈現成可閱讀、可編輯的文件。這不等於支援全部 Obsidian 外掛或所有網站小工具。

## 數學與物理文字

行內公式可使用 `$E=mc^2$` 或 `\(E=mc^2\)`；獨立公式可使用 `$$…$$` 或 `\[…\]`。閱讀模式會排版公式，原文模式仍可修改 LaTeX。

已加入的測試包含分數、根號、微分與偏微分、積分、求和、極限、矩陣、向量、上下標、科學記號、物理單位與常見場方程。數值保留原文字，不經浮點數轉換。程式碼區中的公式符號保持原樣；需要顯示字面美元符號時可寫 `\$`。

PCS 目前使用內附的 KaTeX 0.19.0；Obsidian 使用 MathJax，兩者支援的 LaTeX 命令並非完全相同。不支援的命令會保留可見原文，方便修改，不會用猜測的公式替換。`physics`、`siunitx`、TikZ 等套件不在本輪承諾範圍。

## 貼上圖片、連結與網頁內容

| 內容 | 處理方式 |
| --- | --- |
| 剪貼簿點陣圖片 | 保存為文件旁的本機附件；搬移文件時一起保留附件資料夾 |
| HTML 中有效且未超限的 PNG data URI | 保留在 Markdown 內，離線重開仍能顯示 |
| 遠端圖片 | 保留取得的圖片網址；貼上時不自動下載，閱讀時由使用者載入 |
| 網址與有連結的文字 | 保留來源實際提供的網址及文字；不從圖示或網站名稱猜網址 |
| 有文章連結的縮圖 | 保留文章網址與圖片來源，避免只留下圖片；遠端縮圖仍依遠端圖片的載入方式處理 |
| 引用來源標籤 | 擴充保存可取得的來源為腳註；PCS 閱讀模式提供懸停卡片，其他 Markdown 閱讀器可使用腳註連結 |
| HTML 上下標與標記 | 保留安全的 `sup`、`sub`、`mark`，例如 H₂O 或 m² 的結構 |
| 無法直接轉換的 SVG、Canvas 或嵌入內容 | 一般貼上保留能取得的名稱、描述與來源，並註明圖形未保留。Chrome 擴充對已支援、可讀取的圖形另可保存靜態 PNG |
| 格式欄位是空的，但剪貼簿有純文字 | 使用純文字，不把有內容的貼上變成空白 |

只有畫面外觀、沒有原始公式或圖表資料時，不能可靠地還原成可編輯公式或完整數列。來源需要登入、禁止跨來源讀取，或剪貼簿根本沒有網址時，保留已有資訊與缺失說明。靜態圖片不代表保留原小工具的互動操作。

## 與 Obsidian 共用文件

本輪核對標題、文字樣式、清單、引用、提示、表格、腳註、Wiki 連結、相對連結、圖片尺寸、筆記／區塊嵌入、註解、Mermaid 及公式。能否正確解析、實際顯示、修改後保存，是分開檢查的事項。

建議跨程式共用的公式採用 `$…$`、`$$…$$`；`\(…\)`、`\[…\]` 是 PCS 為常見 LLM 輸出增加的讀取方式，不假設所有 Markdown 程式都支援。需要連結、圖片與嵌入筆記時，搬移整個資料夾。

[完整測試文件](../../tests/fixtures/markdown_compatibility/Markdown-相容性測試.md) 包含 69 組公式、逐式原文與人工核對清單。旁邊的輔助筆記、圖片及公式目錄也屬於測試資料。這是可持續增加的回歸樣本，不是「所有可能語法都已測完」的宣告。

本機版本的修正與證據見 [R9 驗證紀錄](../development/markdown-compatibility-r9.md)。
