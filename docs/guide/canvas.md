# Canvas 與工作區

適用：0.8.6 Alpha 1 · [使用指南](README.md)

## 認識工作畫面

啟動會進入 Canvas。新資料與新工作區提供六個已接線的起始節點，既有工作區保留原本的布局、文字草稿與縮放。

左上工作區膠囊集中工作區切換、清單模式與最近生成。頂列提供媒體庫、探索、匯出與設定，右上顯示 ComfyUI 連線狀態。CLIP 與 Stage 的待設定提示會指出下一個操作。

畫布可以平移、縮放；改變視窗尺寸不會重排節點。側欄收合後保留圖示，游標在左緣稍停可暫時展開；側欄按鈕可固定，拖曳右緣可調寬。窄視窗的執行列以「更多」收納部分工具，最近生成仍從工作區膠囊開啟。

## 文字與圖片的接線

模組組合文字，送到 Prompt 輸出；CLIP 再指定文字要套用到工作流的哪個節點與欄位。圖片由圖片來源接到 ComfyUI 圖片輸入。要生成時，將 CLIP 或圖片輸入的紫色控制線接入 Stage。

先看各節點的內容與目的地，再按執行。沒有有效 Stage 接入時只套用綁定輸入，不生成。節點在畫布上的位置用於整理流程，不代表生成畫面的精準空間控制。

文字編輯見[模組與提示詞](prompts.md)，生成與圖片接法見[Stage 與圖片流程](stage.md)。

## 管理工作區

從左上工作區膠囊切換工作區；工作區選單可新增預設流程、複製目前工作區、設定或刪除。切換時保留原工作區的等待工作並暫停，回來後先確認內容再繼續。

工作區設定可勾選固定模組。只有勾選「以目前選擇更新固定組合」並儲存，才更新固定選擇；之後切換到該工作區時還原這些模組的已存選擇，其他模組保留目前選擇。

「建議參數」可記錄模型、LoRA、權重、種子與採樣建議，也可從參數歷史帶回編輯後另存。這些是工作區備註；要控制實際生成參數，請使用[Stage 參數](stage-parameters.md)。Prompt 裡的 LoRA 文字不會自動建立 LoRA Loader。

刪除工作區會移除該工作區與參數歷史，素材庫、媒體與模型仍保留；至少需留一個工作區。

## 撤銷、外觀與快捷鍵

Canvas Undo／Redo 可撤銷或重做畫布編輯與一般 Stage 參數設定；不會撤銷已提交的生成，也不會重新送出任務。單筆等待任務的參數需回到該任務修改。

設定可選配色、字型、字級、間距及 Windows 視窗材質，材質效果依系統及透明設定而定；可選實色減少視覺效果。

| 快捷鍵 | 操作 |
|---|---|
| Ctrl+F | 在 Canvas 開啟節點工具；在清單聚焦搜尋。 |
| Ctrl+, | 開啟設定。 |
| Alt+←／Alt+→ | 返回上一頁／下一頁。 |
| Ctrl+Shift+C | ComfyUI 可執行時送出生成；否則複製最終 Prompt。 |

只想複製文字時，使用 Prompt 面板的「複製 Prompt」，避免將 Ctrl+Shift+C 當成固定的複製快捷鍵。
