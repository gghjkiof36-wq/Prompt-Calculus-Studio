# Canvas 與工作區

適用：0.8.9 Beta · [使用指南](README.md)

## 打開一份 Canvas

從內容側欄新增 Canvas，會得到六個已接線的起始模組。既有文件保留布局、文字草稿與縮放；刻意清空的 Canvas 不會在重開時被補回起始模組。

Canvas、Markdown 與 Prompt 管理檔都在分頁中開啟，可以左右並排。從側欄拖曳文件到分頁列或右側分割區，便能一邊看筆記、一邊整理流程。文件與資料位置見[工作區指南](workspace-089.md)。

畫布可以平移、縮放；改變視窗尺寸不會重排節點。側欄可收合、固定及調整寬度，懸停導覽入口可查看對應內容。CLIP 與 Stage 的待設定提示會指出下一步。

## 文字與圖片的接線

模組組合文字，送到 Prompt 輸出；CLIP 再指定文字要套用到工作流的哪個節點與欄位。圖片由圖片來源接到 ComfyUI 圖片輸入。要生成時，將 CLIP 或圖片輸入的紫色控制線接入 Stage。

先看各節點的內容與目的地，再按執行。沒有有效 Stage 接入時只套用綁定輸入，不生成。節點在畫布上的位置用於整理流程，不代表生成畫面的精準空間控制。

畫布每批提供一份固定文字，讀取流程可提供多輪；多筆來源以較長者決定筆數、較短者循環。CLIP 可直接接 Stage，也可先經預排程保存目標欄位；具體範例見[素材與批次](prompt-materials-088.md)。

文字編輯見[模組與提示詞](prompts.md)，生成與圖片接法見[Stage 與圖片流程](stage.md)。

## 匯入與保存素材

在 Canvas 的素材挑選頁使用「＋」匯入 Prompt 管理檔，會以檔名建立分類。加入畫布後保存為副本，之後編輯不回寫來源素材；分類與副本可隨 Canvas 保存、撤銷或重做。

包含素材分類的新版 Canvas 有自己的格式標記。遇到舊版不支援的提示，請換用相容版本及資料副本，不要刪除格式欄位來強行開啟。

## 各文件的連線與任務

CLIP、圖片輸入及 Stage 使用目前 Canvas 的 ComfyUI 連線與工作流清單。同一文件的不同視圖共用連線；其他文件各自保存綁定，不隨焦點切換。

同一個 PCS 工作區中的多份文件按順序執行，每份先跑完自己的流程。切分頁、關閉頁面或另存新檔，都不能據此判斷後端任務已停；取消後也要等回覆確認。重開及續接操作見[多文件執行與重開](scheduling.md#多文件執行與重開)。

保存或搬移時同時保留 Canvas 文件及 `data`，執行紀錄不只存在畫布檔裡。另存新檔會建立新的文件身份，原任務仍屬於原文件；單獨複製 Canvas 不會帶走完整任務紀錄。詳見[備份與回退](data-backup-privacy.md#備份與回退)。

## 撤銷、外觀與快捷鍵

Canvas Undo／Redo 可撤銷或重做畫布編輯與一般 Stage 參數設定；不會撤銷已提交的生成，也不會重新送出任務。單筆等待任務的參數需回到該任務修改。

設定可選配色、字型、字級、間距及 Windows 視窗材質，材質效果依系統及透明設定而定；可選實色減少視覺效果。

| 快捷鍵 | 操作 |
|---|---|
| Ctrl+F | 在 Canvas 開啟節點工具；在 Prompt Editor 聚焦搜尋。 |
| Ctrl+, | 開啟設定。 |
| Alt+←／Alt+→ | 返回上一頁／下一頁。 |
| Ctrl+Shift+C | ComfyUI 可執行時送出生成；否則複製最終 Prompt。 |

只想複製文字時，使用 Prompt 面板的「複製 Prompt」，避免將 Ctrl+Shift+C 當成固定的複製快捷鍵。

## 挑選、排序與多選

畫布空白處雙擊開啟文字模組挑選頁；外層空白雙擊開功能模組新增頁。素材挑選可選文字模塊、組合或流程，沿用 Editor 的資料夾及分類，窄窗顯示完整路徑，加入建立目的畫布的副本。

Ctrl＋左鍵拖曳或右鍵拖曳框選；Ctrl＋右鍵拖曳累加，Ctrl＋點擊加入／取消選取。一般空白左拖仍平移，短按右鍵開選單。框選畫布內部時處理該容器的文字卡，外層框選處理功能模組與容器。

多選複製保留內部連線及相對位置，貼上建立新識別；未選取的外部連線不複製。文字欄有焦點時，刪除、複製、貼上及文字復原仍處理該欄位。執行中的任務不隨卡片複製。

Prompt、圖片來源、單張載入與預排程的新增頁預覽使用正式卡片；已加入的卡片有相同控制與預設收合狀態。Prompt 可直接展開來源並拖曳根文字模組；圖片管理與排程順序分別以明確操作展開／套用。

## 獨立圖片預覽與視野

可從新增功能頁加入獨立圖片預覽，接入圖片來源後查看、切換或放大。預覽可折疊、改尺寸、複製並保存；只有兩端都選取的接線隨複製保留。預覽沒有輸出，觀看不改下游來源或消耗進度。

新 Canvas 的初始視野較均衡，既有自訂視野保留。執行列拖動後保存位置；文字編輯、排除 Tag 與側卡的展收不重排原有節點。
