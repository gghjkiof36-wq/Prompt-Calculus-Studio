# 模組與提示詞

適用：0.8.8 Alpha 1 · [使用指南](README.md)

## 素材與畫布副本

使用[Prompt Editor](prompt-editor.md)管理原素材與分類，Canvas挑選後建立獨立副本。副本可以有自己的文字、子內容、順序、權重及停用狀態；素材原件不會因修改副本而自動覆寫。

Prompt 輸出可展開每個畫布來源，直接拖曳其文字模組；來源順序與文字模組順序各自保存。每次實際排序可復原／重做，不以卡片位置推定生成順序。

文字模塊、組合與流程的模式、重複及當輪去重見[素材與批次](prompt-materials-088.md)。切換目前輸出（含空清單）不改其他輸出的有效順序；保存、重開及還原保留完整多輸出次序。

## 自動組合與手動稿

Prompt 輸出原本隨接入的素材自動組合。直接編輯輸出後，會保留你的手動稿，後續自動組合不會擅自蓋掉它。

要恢復自動文字，Canvas 的 Prompt 面板使用「更多 → 清除手動內容」；清單模式使用「清除內容」。確認後清除手動稿，保留已選模組與臨時片段，再以素材重新組合。使用「存入素材庫」可將目前輸出保存為素材。

CLIP 使用左側接入的文字，也接受刻意保留的空白稿。桌面編輯不會立即覆蓋 ComfyUI 網頁；按執行才套用。未綁定的原生欄位與歷史圖片維持原內容。綁定步驟見[ComfyUI 整合](comfyui.md#第一次連接與綁定)。

## Tag 候選與個人字典

英文候選可查詢 Danbooru，輸入 `@` 前綴可查繪師名稱。用方向鍵選候選，Enter／Tab 接受，Esc 關閉。

中文可先在「設定 → 個人字典」建立對照，例如 `白色的牆壁 = white wall`。任意中文長句不會自動轉成已核對的 Tag。

聯網候選可在設定關閉，既有本地候選紀錄仍保留。選用 Google Cloud Translation 時需自行開通服務並提供 API 金鑰，可能產生費用；金鑰只留在當次開啟期間。翻譯結果仍需自己核對，聯網內容見[資料與隱私](data-backup-privacy.md#聯網內容)。

## 從生成圖片取得文字

圖片含有效 PCS 紀錄時，可恢復相關文字模組；只有原始提示詞時，保留整段文字，不自動拆成 Tag。圖片缺少文字時會顯示原因，不沿用上一張的內容。

在 Canvas 使用「讀取文字」可選本輪實際提交的文字欄位；選取文字不會另啟動生成。歷史圖片的組合恢復見[媒體庫與模型](media-models.md#查看圖片資料與恢復組合)。
