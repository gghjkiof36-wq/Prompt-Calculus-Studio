# Prompt Editor

適用：0.8.7 Alpha 1 · [使用指南](README.md)

Prompt Editor 用來管理可重用文字，Canvas 用來安排目前的組合與生成流程。切換兩頁會保留目前編輯，素材原件和畫布副本各自保存。

## 找到與整理素材

左側選分類、資料夾集合或釘選入口，以名稱、別名或內容搜尋。素材可保存 tags、一般文字及 Markdown；選擇適合內容的格式，不會把一般文字強制清成 Tag。

內容分類旁的「＋」可新增分類或資料夾。資料夾收納一層分類；箭頭只展開／收合，點名稱查看其中所有素材，點分類只看該分類。舊庫不會自動分組。

分類「⋯」可重新命名、移至資料夾或刪除；分類也能拖進資料夾或移回外層。「刪除分類」將素材移到未分類，「刪除資料夾」將分類移回外層，兩者保留素材。未分類固定保護。

## 建立新素材並加入畫布

1. 在 Prompt Editor 按「新增模組」，編輯名稱、內容與所屬分類並保存。
2. 返回 Canvas，在目的文字畫布開啟挑選頁，找到剛保存的素材並加入副本。

這是目前可從介面完成的兩步流程；未保存的新文字先留在 Editor，不當成已加入畫布。

## 編輯與使用

素材卡的右鍵選單提供編輯、釘選與另存新素材。瀏覽或管理素材不會自動加入畫布；保存素材原件是明確操作。

Canvas 文字畫布內空白處雙擊可開文字挑選頁。選擇模組並加入後，建立目前目的畫布的獨立副本；修改或刪除副本不會自動改掉素材原件。Editor 的資料夾排序、分類歸屬及展開／收合狀態也用在挑選頁。

文字內容、草稿與權重沿用保存及復原。原位權重編輯按 Enter 套用、Esc取消；輸入法組字時不提前提交。範圍為 −100.0～100.0，加減每次0.1；含負值的資料回退時使用原副本。

## 避免誤改來源

切換素材、工作區或返回前確認目前編輯目標。畫布副本可另存新素材；不想改原件時使用獨立副本或另存。來源已被修改而無法安全覆寫時，保留當前文字並依提示重新選擇。

跨分類直接拖放素材尚未提供；使用分類管理及編輯中的所屬分類操作。
