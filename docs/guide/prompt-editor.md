# Prompt Editor

適用：0.8.8 Alpha 1 · [使用指南](README.md) · [素材與批次](prompt-materials-088.md)

Prompt Editor 管理可重用素材，Canvas 安排目前副本與生成路徑。切頁保留目前編輯，保存原件與加入畫布是各自明確的操作。

## 找到與整理素材

左側上方依「文字模塊／組合／流程」篩選，下方選內容分類、資料夾或釘選。以名稱、別名或內容搜尋；tags、一般文字與 Markdown 保持各自格式。素材類型不由分類名稱推定。

內容分類的「＋」新增分類或資料夾。資料夾收納一層分類，箭頭展收，名稱查看集合。分類「⋯」可改名或移動；素材可跨分類拖移，保留原 ID、草稿與歷史。刪除分類將素材移到未分類，刪除資料夾將分類移回外層，不會刪掉素材。

## 建立與編輯

1. 選擇素材類型並新增，填寫名稱、分類與內容後保存。
2. 文字模塊可加命名變體；組合排列文字模塊、權重或直接輸入；流程排列組合及重複次數。
3. 從「管理」調整變體與起始項。雙擊或「… → 編輯名稱」進入右側子頁，以「返回」回到清單。完整模式與重複規則見[素材指南](prompt-materials-088.md)。
4. 返回 Canvas，在目的畫布的挑選頁加入獨立副本。組合內只加入文字模塊，流程內只加入組合；Esc 回上一層，保留尚未保存的編輯。

右側預覽顯示名稱、圖片、Prompt、位置與「編輯」。切換預覽不消耗執行進度；釘選後保留清單與捲動位置。文字的各變體、組合的直接輸入／模塊草稿分開，空字串也是有效手動稿。

## 副本、權重與歷史

加入畫布建立副本，修改或刪除它不自動改素材原件。Editor 與挑選頁共用分類、資料夾及收合狀態；切換目前檢視不改其他 Prompt 輸出的順序。

權重可在卡片直接輸入，Enter 套用、Esc 取消；輸入法組字時不提前提交。範圍 −100.0～100.0，加減每次 0.1。修改經現有交易保存，Undo／Redo 不啟動生成。

修改前核對目前編輯的是原件、畫布副本或單輪內容；需要保留來源時另存新素材。原件已變而無法安全覆寫時，保留當前文字，依提示重新選擇。回退使用相容舊程式與原資料副本，勿直接覆蓋新版內容。
