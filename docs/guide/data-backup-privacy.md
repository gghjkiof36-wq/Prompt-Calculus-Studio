# 資料、備份與隱私

[回首頁](../../README.md) · 適用：0.8.9 Beta2

## 本機資料

來源版預設以 `run.py` 旁的 `files` 保存文件、`data` 保存設定與內部資料；`PROMPT_STUDIO_DATA` 可指定資料目錄。加入其他本機資料夾後，編輯會寫回該位置。

| 內容 | 位置或方式 |
|---|---|
| Markdown、Canvas、Prompt 管理檔 | 預設 `files`，或你加入的本機資料夾 |
| 共用設定、索引與快取 | `data/studio.sqlite3` |
| 文件身份、路徑及任務歸屬索引 | `data/execution-index.sqlite3` |
| 各 Canvas 的狀態、取值進度、任務與圖片副本 | `data/documents/<token>/`，資料庫為其中的 `studio.sqlite3` |
| 未寫入內容與編輯草稿的恢復副本 | `data/recovery/`；無法寫入時使用系統暫存位置 |
| 媒體縮圖及保存的原圖 | `data/thumbnails`、`data/originals` |
| 錯誤與原生異常記錄 | `data/error.log`、`data/fault.log` |
| CivitAI 下載收據 | `data/civitai/downloads` |
| CivitAI Token | `data/credentials/civitai.bin`，以 Windows 帳號 DPAPI 保護 |
| ComfyUI 設定、任務與收藏紀錄 | ComfyUI `user/prompt_studio`；擴充 `local_library.json` 指向桌面資料 |

外部圖片、模型仍在原位置。移除媒體紀錄不等於刪除原圖；模型的回收筒操作會處理實際檔案。DPAPI 憑證不能當成跨帳號或跨電腦可攜備份。

## 關閉與恢復副本

關閉或切換文件時，先完成已開始的貼上與輸入法組字，再保存文件。提交輸入法內容後若仍在組字，不會關閉視窗。恢復副本寫入成功後可以離開；若原檔／內容刷新失敗且恢復副本未落盤，視窗會保持開啟，保留稿件與目前 Undo。請先保存或另存到可寫位置；下次開啟可取回成功保存的恢復內容。若原檔已由其他程式改動，保留原件與恢復內容，先比較再另存，避免覆蓋。

恢復副本及素材草稿可能含私人文字與路徑。主資料與系統暫存位置都不可寫時，內容只能留在當次記憶體，不能保證退出後恢復。恢復內容也不代表重建上次執行的整組 Undo 歷史，操作見[工作區指南](workspace-089.md)。

## 圖片、排程、參數與診斷

圖片來源副本、預排程、Stage 設定、生成紀錄與 PNG 畫布快照可能含 Prompt、圖片、節點名稱、模型、參數、種子及工作流內容。任務紀錄與來源進度保存在文件所屬的本機資料庫，單獨複製 Canvas 不會帶走全部紀錄。

操作診斷記錄任務階段、時間與歸屬，不記錄 Prompt、圖片或 Token；其他工作流、收據、日誌及備份仍可能含私人資訊，分享前請檢查。重開先查原提交，尚未執行的 Stage 保留並暫停；PNG 還原與 Undo／Redo 不會提交生成。

## 對話匯入與生成資料

[對話匯入](markdown-import.md)只處理本機 ZIP／JSON，不登入帳號或自動下載遠端附件。每份匯入結果仍含所選對話的原始 JSON、全部分支及能對應的附件，屬於私人資料。解析用的來源 JSON 不當附件複製；一般 JSON 附件仍可保留，不能把全部附件都當成可公開。

舊版已產生的輸出不會自動清理。若曾夾帶整份對話來源，重新匯入會另建乾淨副本；先保留手改筆記，逐項比較後再自行決定如何整理。分享前檢查整個目錄，不只檢查看到的 Markdown。

生成快照只保留本次重建必要的素材與參照；必要 Prompt、名稱及工作流仍可能出現在提交與 PNG 附加資訊。較早的圖片不會因此重新清理。完整 JSON／ZIP 備份保留其範圍內的素材庫與收納資料，屬私人備份。

## 擴充安裝與 Manager

配套擴充的安裝位置、版本與自動更新開關存於目前 PCS 資料目錄，安裝紀錄可能含本機路徑。更新前會把舊擴充與原設定保存在 ComfyUI 的 `.pcs-program-backups`；分享紀錄前先去除私人路徑。

Manager 會讀取本機套件名稱、版本、來源與更新狀態；更新可能由 ComfyUI／Manager 連網取得套件。PCS 配套自動更新只使用本版隨附包。擴充備份不包含你的模型、工作流及全部 PCS 文件。

## 備份與回退

關閉 PCS 後，同時備份所有文件位置及完整 `data`，另外保留外部模型、圖片與 ComfyUI 擴充資料。系統暫存位置的恢復副本也不一定包含在 `data` 中。不要在程式仍寫入資料時只複製某一個 SQLite 檔。

程式內 JSON 匯出保存文字與索引；ZIP 備份保存其資料庫、縮圖、應用內原圖及下載收據，不含外部模型、外部圖片或 `credentials`。這些匯出不代替上述整個工作區備份，尤其要另外保留本機文件及任務資料。

ZIP 完整寫成後才開始發布；取消或發布前寫入失敗會保留既有 ZIP。覆寫時先將舊 ZIP 搬到恢復位置，再把完整新備份放到目的位置，因此兩步之間原檔名會短暫不存在。若中途失敗或程式中止，舊 ZIP 可能只在恢復位置；程式會在能回報錯誤時列出相關路徑，且不覆蓋其他程式趁此建立的檔案。先檢查目的 ZIP 與恢復檔，再決定是否重試。

新備份沿用原 ZIP 的讀取權限；原檔被其他程式以不相容方式開啟時，備份會停止並保留原檔。未完成的暫存檔不能當作備份還原。單一大檔寫入時，取消須等目前檔案收尾；開始搬移後會先完成或回報發布結果，避免把已發布的備份誤報為取消。

另存新檔會建立新的文件身份，舊任務仍由原文件的紀錄核對，不會隨新檔轉移。搬移或重開方式與界線見[多文件執行與重開](scheduling.md#多文件執行與重開)。

更新前保留舊程式、舊擴充及舊資料 A，新版使用副本 B。回退時舊程式只開 A，保留 B 的新內容；沒有自動合併保證。還原前另存目前資料，勿以舊備份蓋掉唯一的新資料。

## 聯網內容

| 操作 | 傳送或讀取的內容 |
|---|---|
| Danbooru 候選 | 查詢片段與候選文字，可在設定關閉 |
| 選用 Google 翻譯 | 待翻譯片段及驗證資訊，金鑰保留當次記憶體 |
| CivitAI 搜尋／詳情／預覽／下載 | 查詢、資產與下載請求；需要時使用自己的 Token |
| 網路圖片匯入 | 向所選網址下載圖片 |
| ComfyUI | 向本機後端傳送 Prompt、模組快照、控制及選定圖片，讀取任務與結果 |
| 保格式貼上、ChatGPT ZIP／JSON 匯入 | 使用剪貼簿或本機封存，不自動下載遠端圖片與附件 |
| 首次安裝依賴 | 從 PyPI 取得套件 |

ComfyUI 工作流中的其他擴充可能有自己的聯網行為。文字候選不等於上傳整份素材庫；圖片輸入會依使用者接線送往 ComfyUI。

CivitAI Token 只傳給允許的下載來源；下載收據與舊日誌在分享前仍需檢查。遇到 401 請核對 Token、帳號權限與模型存取限制，見[疑難排解](troubleshooting.md#civitai-回傳-401)。

## 分享前

PNG、工作流、收據、備份與錯誤記錄可能含 Prompt、模型名稱或私人路徑。公開回報先檢查內容；不要提交 data、Token、模型與私人圖片。可用 [匯出功能](image-export.md) 移除圖片附加資訊，再檢查結果；像素內的文字及私人內容仍會保留。安全問題見 [SECURITY](../../SECURITY.md)。

## 長訊息與診斷記錄

備份或恢復失敗的長訊息可以捲動到結尾並複製全文；先核對列出的備份、目的與恢復位置，再決定是否重試。錯誤記錄與本機診斷輸出可能包含路徑、文字或錯誤資訊，只保留在本機；分享前先移除私人內容。
