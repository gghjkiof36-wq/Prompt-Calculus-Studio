# Stage 與圖片流程

適用：0.8.6 Alpha 1 · [使用指南](README.md)

Stage 指定要生成的 ComfyUI 工作流。先完成[連線與文字綁定](comfyui.md#第一次連接與綁定)，生成期間保持 PCS、ComfyUI 後端與工作流網頁開啟。

## 執行一個 Stage

1. 在 Canvas 新增「Stage／執行階段」。
2. 將 CLIP 或 ComfyUI 圖片輸入的紫色輸出接到 Stage，確認所選工作流。
3. 正面、負面文字與圖片輸入可接入同一 Stage；這些輸入一起套用後，生成該工作流一次。
4. 確認待設定提示都已處理，再按底部「執行」。

第一條有效綁定可帶入目標，之後可手動選擇工作流。混接不同工作流的輸入時會套用各自欄位，但只生成 Stage 指定的目標；未綁定欄位保留。

沒有有效 Stage 接入時只套用輸入，不生成。單獨放置 Stage 或只接圖片預覽也不會生成。單 Stage 生成中可再點執行；多 Stage 流程執行中不會疊加另一條相同流程。

要調整 CFG、步數、尺寸、模型或種子，見[Stage 參數](stage-parameters.md)。

## 串接多個工作流

多 Stage 依控制線與圖片依賴順序執行，底部次數表示整個流程的輪數。節點位置不決定順序；A→B→A 需建立兩個不同的 A Stage 實例。

1. 將 Stage A 的圖片結果接到「加載圖片」或「圖片來源」。
2. 選全部或指定輸出節點，以及全部或指定批次圖片。
3. 接到 B 的 ComfyUI 圖片輸入（LoadImage），再將控制線接到 Stage B。
4. 也可在圖片來源選「本次 Stage 結果」，用明確依賴代替畫布上的長線。

B 會等 A 完成。A 產生三張圖時，B 逐張處理，收齊 B 的結果後才進 C；指定節點或圖片不存在時會說明原因，不拿舊圖代替。

## 圖片來源與預覽

預覽圖片只供觀看、切換與放大，沒有右側輸出；切換預覽不會改變下游圖片。最近生成為獨立面板，需要明確選用歷史結果。

圖片來源未直接接資料預排程時，一輪成功後會換到下一張，但不會自動開始下一輪；換圖前再點執行仍使用當時圖片。要整批供應圖片，見[預排程](scheduling.md)。

## 結果與中斷處理

底部活動任務數可查看各筆紀錄。ComfyUI 已完成但 PCS 未顯示時，先查原任務，再使用「重取結果／重試失敗項」讀取結果。

若生成圖片沒有填入下一步，可手動選用該圖；直接再次執行會開始新的生成。工作流一直載入、連線中斷或取消問題見[疑難排解](troubleshooting.md)。
