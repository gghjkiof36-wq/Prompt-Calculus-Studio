# 預排程與任務管理

適用：0.8.9 Beta · [使用指南](README.md)

預排程保存文字、圖片、綁定輸入或連續 Stage 的待辦。排入等待不等於凍結整張原生工作流；先確認[Stage 接線](stage.md)與[素材取值](prompt-materials-088.md)。

## 選擇接法

| 接法 | 保存與用途 |
|---|---|
| 文字／圖片 → 預排程 | 保存經過該端口的資料，其他來源依其設定取值 |
| Prompt → CLIP／圖片綁定 → 預排程 → Stage | 保存每筆輸入及工作流目標欄位；不把綁定控制線改成原始文字或圖片線 |
| Stage → 預排程 | 保存一個或一組連續 Stage，在「輸入取值」逐欄選保存或即時 |

同一張預排程不可同時當綁定資料排程及 Stage 範圍排程。直接接 Stage 與經過預排程使用相同取值計畫；舊接線依明確整理操作轉換，可復原。

多來源取較大輪數，短來源循環；畫布當批固定，讀取流程逐輪前進。容量補位沿原批定義、已取值前綴與當時畫布值，不重讀目前編輯內容。空閒時執行會開始工作；要先累積待辦，先暫停再加入，確認後繼續。

Stage 範圍保存的欄位使用加入時內容，即時欄位在執行時讀取。未來圖片保留為所屬上游 Stage 結果依賴，不固定成舊圖片。範圍需連續，避免交錯重疊；外層每一項跑完整流程。

## 查看與修改

等待項可排序、複製、查看及修改，已提交項只查看。每筆等待項保留加入時的 Stage 明確參數，修改一般 Stage 不回寫舊項。要修改單筆，開該項「Stage 名稱 · 參數」，按「套用至此任務」，見[Stage 參數](stage-parameters.md)。

清單右鍵「移除此項」及 Delete／Backspace 只處理可移除的等待或已確認失敗項。提交未確認時先查 ComfyUI 原任務，不用刪除或重試來猜是否送出。

## 保存與進度

內容和取值位置一起保存，成功保存即算用過。已保存六筆、完成兩筆後取消四筆，下一批仍從第七筆開始；相同 Prompt 的任務不合併。保存失敗不消耗進度，完成回執不再消耗，重試沿用原筆內容。

修改素材、接線或來源只影響新批次。已排入的目標綁定若變更，依提示先暫停核對，不重寫舊項。Stage 未覆寫的模型、尺寸與採樣欄位仍依原生提交準備時的工作流取值。

## 暫停、取消與重開

暫停只停止後續派送，已提交工作仍收結果。底部叉號取消目前項目，保留並暫停其他等待項；要全部取消，從叉號右鍵或預排程「更多」選擇「取消此工作區全部流程」。

全部取消會保存相應任務狀態並處理可確認歸屬的 PCS 工作，其他工作區或外部任務保留。取消要求不代表未知後端已停；仍需按回覆核對，不自動重送未知提交。

斷線或重開後，尚未執行的 Stage 保留並暫停，確認工作流與輸入再繼續。切換分頁只改變目前看的文件，不把任務移交給新分頁。Undo／Redo、PNG 還原及開關視窗不提交生成。0.8.3 舊等待項需重新安排；更新前[備份](data-backup-privacy.md#備份與回退)。

ComfyUI 已完成但未顯示結果時，從活動任務紀錄重取；狀態未知先查佇列與歷史，見[疑難排解](troubleshooting.md)。

## 多文件執行與重開

每份 Canvas 保存自己的執行紀錄與 ComfyUI 綁定。同一 PCS 工作區內，跨文件的流程依加入順序執行，每份先跑完整流程；這個順序不協調另一個 PCS 程序或你手動送出的 ComfyUI 任務。

內容成功保存後才接受排入與派送。改變焦點、切分頁、關閉頁面或另存新檔，都不會把原任務改掛到另一份文件；取消某份文件的等待項，也不會取消另一份文件正在做的工作。

重開 PCS 後會依原提交記錄查詢 ComfyUI 的佇列與歷史，不自動重送狀態未知的生成，即使原文件沒有恢復成分頁也保留其歸屬。請打開原 Canvas，從「任務紀錄 → 流程紀錄」確認狀態，再按「繼續」執行尚未開始的 Stage。

與目前內容分離的舊紀錄仍可查詢或停止，不能直接用舊內容重試或繼續。需要重新生成時，打開文件、核對內容，再建立新流程。

「已加入佇列」或取消要求的回執都不表示生成已完成或後端已停止。狀態未知時先查原任務；不要靠重複按執行來判斷是否送出。生成期間仍需保持 PCS、ComfyUI 後端與工作流網頁開啟。

執行紀錄在 `data` 中，備份與搬移應同時保留文件及資料目錄。詳見[資料、備份與隱私](data-backup-privacy.md)，本版驗證界線見[Beta 紀錄](../releases/0.8.9/validation/beta.md)。
