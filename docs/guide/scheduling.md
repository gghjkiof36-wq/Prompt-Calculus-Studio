# 預排程與任務管理

適用：0.8.6 Alpha 1 · [使用指南](README.md)

預排程讓你先安排文字、圖片或一組 Stage，再依序執行。先確認[Stage 接線](stage.md)正確；排入等待不等於凍結整張 ComfyUI 工作流。

## 資料預排程

資料預排程保存經其端口的文字與圖片，其他輸入在提交時讀取。要固定圖文，請把兩者一起接入。

空閒時按執行會立即開始；忙碌時保存後續項目。若想先累積多筆，先手動暫停，排好後再明確繼續。

圖片來源直接接入資料預排程可供應整批圖片，最多同時保留十個未結束項目，完成後再補入下一項。未經這個接法的圖片來源只在成功後換圖，不自動開始下一輪。

## Stage 預排程

將 Stage 的紫色輸出接到預排程，可保存一個或一組連續 Stage。在「輸入取值」逐欄選擇保存或即時：保存的欄位使用加入時內容，即時欄位在執行時讀取。

尚未生成的圖片保留為本輪 Stage 結果依賴，不固定成舊圖片。Stage 明確指定的參數隨項目保存；未指定的模型、尺寸與採樣等欄位仍於提交時讀取。

內外層有各自進度；外層的每一項會跑完整流程。排程範圍需連續，避免建立交錯重疊的範圍。

## 查看與修改等待項

等待項可以排序、複製、查看及修改，已提交項只能查看。每筆等待任務保存加入時的 Stage 覆寫；修改一般 Stage 不會回寫已排入項目。要改單筆，打開該項的「Stage 名稱 · 參數」，再按「套用至此任務」，見[參數操作](stage-parameters.md#比較兩筆不同-cfg)。

清單右鍵「移除此項」可移除等待或已確認失敗項；Delete／Backspace 只作用於選取項目。若尚無法確認該筆是否已開始生成，先核對 ComfyUI 原任務，再決定後續操作。

## 暫停、取消與恢復

暫停停止後續派送，已提交工作仍收取結果。底部叉號取消目前項目，其他等待項保留並暫停；取消確認後可按繼續。要全部取消，從叉號右鍵或預排程「更多」選單操作。

取消只作用於確認歸屬的 PCS 工作，不清空其他來源的 ComfyUI 任務。編輯、PNG 還原與 Undo／Redo 不會重新提交生成。

斷線、切工作區或重開 PCS 後，等待流程保留並暫停。確認工作流、輸入與接線後，再明確繼續。0.8.3 的舊等待項不會自動轉成分層排程，需重新安排；更新前先[備份資料](data-backup-privacy.md#備份與回退)。

若 ComfyUI 已完成但沒有收到圖片，從活動任務紀錄重取結果；若提交狀態不明，先查 ComfyUI 佇列與歷史，避免重複生成。詳見[疑難排解](troubleshooting.md)。
