# ComfyUI 配套與資料格式相容

適用：PCS 0.8.8 Alpha 1 · [安裝步驟](comfyui.md) · [疑難排解](troubleshooting.md)

## 選擇同版配套

主程式與配套擴充都須更新。0.8.8 的通用、legacy 與 modern 配套使用同源核心，支援 PCS 文件／快照格式 **1–7**；每次只在 `custom_nodes` 安裝一份 PCS 擴充。

| 配套 | ComfyUI 後端對照 | 前端對照 |
|---|---|---|
| 通用 `PCS-v0.8.8-Alpha1-ComfyUI.zip` | 一般安裝入口使用 | 實際能力仍須核對 |
| `PCS-v0.8.8-Alpha1-ComfyUI-legacy-0.39.2.zip` | 0.39.2 | 1.53.10 |
| `PCS-v0.8.8-Alpha1-ComfyUI-modern-0.40.0.zip` | 0.40.0 | 1.55.17 |

legacy／modern 是包內 `COMFYUI_COMPATIBILITY.json` 的相容設定檔，非三套互相獨立的生成核心，也不代表本輪已完成兩版真實 GPU 驗收。其他 ComfyUI 版本、官方 Desktop、新機及第三方節點需按實際環境核對。[發布頁](https://github.com/gghjkiof36-wq/Prompt-Calculus-Studio/releases/tag/v0.8.8-alpha.1)列出實際附件。

## 遇到「不支援的備份版本」

ComfyUI 後端版、網頁前端版、PCS 擴充版及文件格式版是四個不同維度。文字組合曾使用格式 5，綁定後預排程／獨立預覽使用格式 6，三層素材與使用進度需要格式 7。舊配套可能只認得 1–4 或 1–6；重新啟動同一份舊擴充不會增加支援格式。

1. 保存工作流，關閉 ComfyUI。
2. 用同版 PCS 的安裝入口，或從同版 Release 取得完整擴充包更新。保留舊包與備份，不同名稱的兩份擴充不要並存。
3. 由你啟動 ComfyUI、重新整理工作流網頁，再核對 PCS 管理頁的實際載入版。
4. 仍不相容時保留原資料與錯誤訊息，核對桌面、配套和格式，不手動降低文件版本號。

連線前會檢查配套能力，不支援的資料保持原樣並報告版本。已安裝與已載入不同，連線燈號也只表示服務可達；工作流網頁仍需開啟並能回應。

## 欄位與工作流界線

受信任的原生註冊／同步序列化路徑已有相容處理，工作流草稿、切換及種子生命週期沿原生回執核對。未適配的子圖、動態節點、特殊序列化或多選模型欄位仍可能唯讀，依提示回到 ComfyUI 設定。

種子可編輯範圍上限為 `1125899906842624`（2^50），也受節點更嚴的限制；較大的原值保留唯讀。模型選單不下載模型或建立節點。不能從局部節點通過推論全部第三方／DynamicPrompts 都受支援。

## 證據適用範圍

本版來源有離線協定、純核心、Qt 與保存／還原檢查；固定功能來源及界線見[0.8.8 驗證紀錄](../releases/0.8.8/validation/alpha.1.md)。離線通過不等同新安裝、實際服務載入或 GPU 生成。

較早的 0.8.8 準備版曾在 ComfyUI 0.40.0／前端 1.55.17 實際安裝、重啟並讀取格式 5；0.39.2 當時只做固定來源與隔離檢查。這是當時來源的歷史證據，不作最終格式 7、目前配套或全部 GPU 工作流的通過紀錄。
