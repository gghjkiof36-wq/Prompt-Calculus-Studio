# ComfyUI 配套與資料格式相容

適用：PCS 0.8.9 Beta2 · [安裝步驟](comfyui.md) · [疑難排解](troubleshooting.md)

## 選擇同版配套

主程式與配套擴充都須更新。0.8.9 Beta2 的通用、legacy 與 modern 配套使用同源核心，支援 PCS 文件／快照格式 **1–7**；每次只在 `custom_nodes` 安裝一份 PCS 擴充。

| 配套 | ComfyUI 後端對照 | 前端對照 |
|---|---|---|
| 通用 `PCS-v0.8.9-Beta2-ComfyUI.zip` | 一般安裝入口使用 | 依實際工作流能力核對 |
| `PCS-v0.8.9-Beta2-ComfyUI-legacy-0.39.2.zip` | 0.39.2 | 1.53.10 |
| `PCS-v0.8.9-Beta2-ComfyUI-modern-0.40.0.zip` | 0.40.0 | 1.55.17 |

legacy／modern 是包內 `COMFYUI_COMPATIBILITY.json` 的相容設定檔，共用同一套核心；不代表本輪已完成兩版真實 GPU 驗收。其他 ComfyUI 版本、官方 Desktop、新機與第三方節點需按實際環境核對。[本版 Release](https://github.com/gghjkiof36-wq/Prompt-Calculus-Studio/releases/tag/v0.8.9-beta.2)列出下載附件。

## 遇到「不支援的備份版本」

ComfyUI 後端版、網頁前端版、PCS 擴充版與文件格式版各有用途。三層素材與使用進度需要格式 7，舊配套可能只接受 1–4 或 1–6。若實際載入較早的 preparation.7，它只接受 1–6；重新啟動同一份舊擴充不會增加格式支援。

1. 保存工作流，關閉 ComfyUI。
2. 用同版 PCS 的安裝入口，或從同版 Release 取得完整擴充包更新。保留舊包與備份，不同名稱的兩份擴充不要並存。
3. 啟動 ComfyUI、重新整理工作流網頁，再核對 PCS 管理頁的實際載入版及格式支援。
4. 仍不相容時保留原資料與錯誤訊息，核對桌面、配套與格式，不手動降低文件版本號。

隨附、已安裝與已載入是不同狀態。安裝操作完成後仍要重啟後端並刷新網頁；本版文件不表示你的現有安裝已經更新。

## 連線正常但工作流不能執行

連線燈號表示服務可達，還需要配套支援資料格式、目前模式允許工作流功能，以及工作流網頁能回應。

若格式可讀、執行能力卻受限制，依提示的模式或功能原因處理；例如服務回報單一使用者模式限制時，先核對該限制。只有確定格式不支援時才按更新配套處理，避免反覆安裝同一份擴充。

CLIP、圖片輸入與 Stage 使用目前 Canvas 的連線與工作流清單。同文件的不同視圖共用，不同文件各自保存綁定；切換分頁不會把舊任務改掛到新文件。執行與重開見[任務指南](scheduling.md#多文件執行與重開)。

## 欄位與工作流界線

受信任的原生註冊／同步序列化路徑已有相容處理，工作流草稿、切換及種子生命週期沿原生回執核對。未適配的子圖、動態節點、特殊序列化或多選模型欄位仍可能唯讀，依提示回到 ComfyUI 設定。

種子可編輯範圍上限為 `1125899906842624`（2^50），也受節點更嚴的限制；較大的原值保留唯讀。模型選單不下載模型或建立節點，個別節點的結果不代表全部第三方／DynamicPrompts 都受支援。

## 證據適用範圍

來源、合成回覆、套件與真實安裝的證據分開記錄。本版固定功能與未驗範圍見[Beta 驗證紀錄](../releases/0.8.9/validation/beta.2.md)。套件格式及離線檢查不能代替你目前服務的實際載入、工作流或 GPU 生成。

較早版本的真服務結果只適用當時來源；格式 5 的歷史安裝結果不能當作目前格式 7、全部新配套或 GPU 工作流的通過紀錄。
