# ComfyUI 0.39.2 與 0.40.0 配套擴充

適用：PCS 0.8.8 相容與視窗效能前置驗證 7。本頁記錄此候選版本，不改變公開 0.8.7 的驗證範圍。

## 保留的兩個版本

| 包名 | 對照的 ComfyUI 後端 | 對照的前端 |
| --- | --- | --- |
| `PromptCalculusStudio-ComfyUI-legacy-0.39.2.zip` | 0.39.2 | 1.53.10 |
| `PromptCalculusStudio-ComfyUI-modern-0.40.0.zip` | 0.40.0 | 1.55.17 |

兩包位於桌面包的 `extensions`，以 0.39.2 為舊版保留界線。它們使用相同的相容核心與路由，均可讀 PCS 文件版本 1–6；包內 `COMFYUI_COMPATIBILITY.json` 標示對照版本。此修復不需要把資料降版，也沒有依版本號禁止其他 ComfyUI 版本。其他版本仍須另行核對。

一般安裝／更新入口使用同目錄的 `PromptCalculusStudio-ComfyUI.zip`，其程式內容與兩個保留包相同。只安裝一份 PCS 擴充，勿把兩份同時放進 `custom_nodes`。

## 「不支援的備份版本」的原因與處理

ComfyUI 後端版本、前端版本、PCS 擴充版本及 PCS 文件版本是不同的版本。這次問題是舊 PCS 擴充只認得文件 1–4，而目前文字組合資料已使用文件 5；多個獨立預覽則會使用文件 6。配套擴充須同時支援這兩種資料。僅重新啟動同一份舊擴充不能解決；也不能從這句訊息推定 ComfyUI 0.40.0 移除了相關功能。

1. 保存工作流，關閉 ComfyUI。
2. 用同版 PCS 的擴充安裝入口更新，或依[ComfyUI 整合](comfyui.md)安裝所需的保留包。安裝器保留原擴充備份與素材庫設定。
3. 啟動 ComfyUI，重新整理工作流頁面；核對擴充管理頁的實際載入版本。

前置 7 會先檢查擴充能力，再登記素材庫和同步工作流。不相容時會指出需更新 PCS 擴充，不再先送出無法讀取的新資料。擴充遇到未支援的文件版本會明確報告版本，保持資料原樣。

## 驗證範圍

已核對官方 [ComfyUI 0.39.2](https://github.com/Comfy-Org/ComfyUI/releases/tag/v0.39.2) 與 [0.40.0](https://github.com/Comfy-Org/ComfyUI/releases/tag/v0.40.0) 的佇列、歷史、事件傳遞及驗證入口。兩版保留此擴充使用的介面。

對照前端的原始 ChangeTracker 程式已通過隔離檢查：工作流 A／B 的未存草稿、切換、復原及下一次提交保留。新版的 `captureCanvasState` 與延後草稿整理也納入切換保護，避免載入過程讀到尚未完成的畫布；舊版 `checkState` 入口仍保留相容。

本輪已在 ComfyUI 0.40.0／前端 1.55.17 實際安裝、重啟並讀回前置 7 擴充版本；服務可讀取文件 5 的既有素材庫。0.39.2 的檢查為固定來源與隔離測試，未另啟動舊版服務，也未進行 GPU 生成。

離線協定檢查、套件校驗、實際載入與 GPU 生成是不同驗證。本候選不以離線測試宣稱所有舊版服務、第三方節點或 GPU 工作流均已驗收；真實生成仍需在實際使用的工作流驗證。
