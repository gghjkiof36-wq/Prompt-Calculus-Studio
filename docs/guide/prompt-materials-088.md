# 0.8.8 候選版：素材與批次

適用本機 `v0.8.8-candidate.1`；公開 0.8.7 尚未包含本頁新增功能。

## 三種素材

| 類型 | 用途 | 新增與編輯 |
|---|---|---|
| 文字模塊 | 一段 Prompt，可保存多個文字變體 | 「新增變體」後可命名、排序、刪除、設定各項重複次數。每次只顯示選中的文字，切換後仍可各自復原輸入。 |
| 組合 | 將多個文字模塊排成一份 Prompt | 可加入素材、拖動排序、改權重，或切換到直接輸入。兩種方式保留各自草稿。組合本身沒有變量模式。 |
| 流程 | 依序使用多個組合 | 先看組合總覽，雙擊進入一組；可拖動、複製、改重複次數，或從列選單設為起始組合。 |

類型和分類各自獨立。素材庫可篩選全部、文字模塊、組合或流程；原分類、資料夾、搜尋、釘選與排序繼續使用。「加入素材」按所在層級顯示可加入的類型，單擊加入後返回原頁。

文字變體和流程共用固定、遞增、遞減、隨機四種變量；隨機可選允許重複或不重複。不重複隨機先洗牌，再連續完成該項的重複次數；新一遍仍可能接到上一遍結尾的同一項。固定流程只固定外層組合，內部文字變體仍按自己的使用進度前進。

去重位於組合頁，只整理該組合當輪重複的完整 Tag，保留首次順序。不同權重、自然語言及其他組合不合併，也不刪除文字相同的任務。舊文字模塊已保存的去重設定仍按原規則讀取。排除 Tag 保留原作用範圍，沒有文字輸出時仍保留模塊。

## 畫布與讀取流程

畫布每次執行提供一份當次內容；即使放入流程卡片，也只取當輪。卡片顯示當前實際 Prompt，權重放在名稱旁，索引可用左右按鈕、輸入數字或滾輪切換。

「讀取流程」可一次提供整個流程，選擇自動輪數或指定數量；指定數量預設十輪。未選流程時只顯示較窄的選擇視窗，選好後再展開內容。自動輪數包含重複次數，從中間開始也會走完整一遍。固定或允許重複隨機不以候選數決定長度；所有來源都沒有有限一遍時，自動使用十輪。

兩個多筆來源以較長者決定筆數，較短者循環。例如十輪和六輪共十筆，配成 aa、bb、cc、dd、ee、ff、ga、hb、ic、jd。圖片批次也使用這個規則。固定當次圖片及畫布內容在同批中保持一致。

```text
讀取流程 ─┐
          ├→ Prompt 輸出 → CLIP 輸入 → 預排程（可選）→ Stage
畫布 ─────┘
```

六輪流程 abcdef 配固定畫布文字 1，送出 a1、b1、c1、d1、e1、f1。外層執行三次，就是三批；畫布每批前進一次，流程內文字按每筆實際使用前進。同一位置分線不會重抽或多生一批；另放一份副本則有獨立進度。

Prompt 輸出統一管理文字；CLIP 保留每筆文字與目標欄位。預排程只接受輸入模塊或 Stage，接上後保留下一個空白輸入。直接接 Stage 和經過預排程的取值規則相同。舊資料接線可用現有整理入口轉換並復原。

## 保存、取消與重開

每筆內容成功保存進任務後即算取用，畫面顯示下一個位置；圖片完成回執不會再推進一次。已保存六筆後取消四筆，下一次從第七筆開始。建立或保存失敗的部分不消耗進度。

容量不足時後續補位沿原批內容與規則，保留原批的畫布值。重試使用原筆值；修改素材、接線或畫布不改寫已保存任務。重開會暫停未完成批次，明確恢復後才繼續，不因重開或復原而重送生成。

本候選使用第 7 版文件，須配合同包擴充。舊候選及原資料應保留，不能將新版資料交給只支援 1–6 的舊擴充。[相容說明](comfyui-compatibility.md)列出兩個保留包及更新方式。
