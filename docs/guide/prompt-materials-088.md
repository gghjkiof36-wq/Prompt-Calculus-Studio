# 素材、取值與批次

適用：0.8.8 Alpha 1 · [開始使用](getting-started.md) · [使用指南](README.md)

## 選擇素材類型

| 類型 | 用途 | 可以設定 |
|---|---|---|
| 文字模塊 | 一段 Prompt 及可選的命名變體 | 各變體文字、重複次數、起始項與取值模式 |
| 組合 | 把有順序及權重的文字模塊組成一份 Prompt | 加入文字、排序、權重、當輪去重或直接輸入；沒有另一層組合變量 |
| 流程 | 依次使用多個組合 | 組合順序、各組重複、外層模式；組合內文字依自己的進度變化 |

Prompt Editor 左側上方固定為「文字模塊／組合／流程」，下方是資料夾和內容分類。類型不由分類名稱決定；搜尋、釘選及排序沿用。加入 Canvas 建立獨立副本，原件、各放置位置與其他副本的進度分開。

編輯組合時，「加入素材」只列文字模塊；編輯流程時只列組合，進入組合後再加入文字。按 Esc 回上一層，保留本次編輯。素材的預覽依序顯示名稱、圖片、Prompt、位置與鉛筆「編輯」；文字切變體，流程切各組預覽。預覽不消耗執行進度。

## 變體與右側管理

1. 在文字模塊使用「＋ 新增變體」，編輯目前所選文字；長文字在 Prompt 框內捲動。
2. 開啟「管理」的變體頁，拖動列可排序。圖釘位於次數左側，指定起始項；未釘時滑過顯示，已釘時以實心圖示常駐。
3. 雙擊變體，或從右下「… → 編輯名稱」進入右側子頁，修改名稱與重複次數；用「返回」回到變體頁。返回與變體頁籤對齊。
4. 在管理卡片處理資訊、排除 Tag 與預覽圖。組合的 Prompt 預覽在名稱右側，管理入口在主頁底部。

切換變體保留各自文字復原狀態；直接輸入與模塊組合也各留草稿。流程內的「移除」只移除該組位置，保留最後一組保護。釘選素材會保留目前清單與捲動位置。

## 模式、重複與位置

文字變體及流程都可選固定、遞增、遞減或隨機。先選一項，再連續完成該項的重複次數。流程固定在組合 c 時，只固定外層選擇，c 內文字變體仍按實際使用前進。

隨機分為允許重複與一輪不重複。不重複模式先洗牌各項，再展開重複次數；下一輪重新洗牌，前輪最後與後輪第一可能相同。允許重複則每次都可能再次抽中同項。

只推進本次實際使用的位置，沒選到的組合與文字不前進。同一位置分線共用同一次取值；另放一份副本則獨立。預覽、開關編輯與取消編輯不消耗進度。

## 畫布一份，讀取流程多份

畫布每個執行批次提供一份內容，放入流程素材也只取當輪。「讀取流程」新增時預設提供整個流程；既有明確逐輪設定保留。可選自動或指定數量，指定欄預設十輪。文字先交給 Prompt 輸出逐筆彙整，CLIP 保留各筆文字與目標欄位；圖片使用自己的輸入路徑。

```text
讀取流程 ─┐
          ├→ Prompt 輸出 → CLIP 輸入 → 預排程（選用）→ Stage
畫布 ─────┘
```

CLIP 可直接接 Stage；加上預排程不改取值或筆數。預排程也保留原有 Stage 範圍用途。舊含糊接線依明確整理操作轉換，可復原，不會在開啟時自動重接。

| 情況 | 輸出結果 |
|---|---|
| 讀取 A 十輪＋讀取 B 六輪 | 十筆，B 循環：aa、bb、cc、dd、ee、ff、ga、hb、ic、jd |
| 讀取 A 十輪＋畫布文字二十變體 | 第一批十筆共用畫布第一變體；下一批才用第二變體 |
| 固定或允許重複隨機＋另一個有限六輪來源 | 六筆，候選項數不決定批次長度 |
| 全部固定或允許重複隨機，使用自動 | 預設十筆；可指定數量 |
| 十輪從第七項開始，自動跑一遍 | 7、8、9、10、1、2、3、4、5、6 |
| a、b、c，其中 b 重複兩次 | 一遍 a、b、b、c，共四輪 |
| 指定五輪，最後一輪剛開始 b 的三次重複 | 本批停在五筆，下批先接 b 剩下兩次 |
| 外層執行三次、每批讀取十輪 | 三批共三十筆；畫布取三次值，流程內文字按每筆使用前進 |

多個實際可達的多筆來源取較大輪數 **max(N)**，短來源循環；未接入的模塊不參與計算。自動輪數含重複次數，固定及允許重複隨機不以候選數當有限長度。指定數量先參與整批計算，確定 N 後嚴格輸出 N 筆；一筆工作流可能產生多張圖片。

同一來源供給多個 Stage 時共用已凍結的取值前綴，較長分支只延伸尚未保存的部分，不會重抽已取值內容。

## 去重、排除與手動文字

去重位於組合，只處理當輪該組合內完全相同的 Tag，保留第一次次序。不同權重、語法或自然語句保留；不同組合、不同輪及文字相同的任務各自保留。舊文字去重設定仍可讀，不自動擴成全域開關。

排除 Tag 沿用原作用範圍，不刪除或停用模塊。手動空字串也是有效草稿；清除手動內容後才恢復自動組合。Prompt 輸出順序與卡片位置分開，切空輸出不重排其他輸出。

## 保存、暫停、取消與重試

每筆內容和取值進度一起成功保存後就算已用；完成回執不再推進。已保存六筆，完成兩筆再取消四筆，下一批仍從第七筆開始。尚未建立或保存失敗的部分不消耗進度。

暫停保留原批；容量補位及重試沿用原筆內容，不重新抽選。修改來源、畫布、模式或接線只影響新批次。重開後未完成批次保持暫停，確認後再繼續；不確定的提交先查原任務，不連續重送。完整操作見[預排程](scheduling.md)。

新版資料使用文件格式 7，主程式與配套擴充都要更新。備份與生成圖片的內容範圍不同，見[相容指南](comfyui-compatibility.md)及[資料與隱私](data-backup-privacy.md)。
