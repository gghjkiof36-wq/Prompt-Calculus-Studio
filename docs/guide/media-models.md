# 媒體庫與模型

適用：0.8.9 Beta2 · [使用指南](README.md)

## 整理圖片

媒體庫可建立自己的圖片資料夾；新增後直接在列表命名，再加入多張圖片，或匯入磁碟資料夾本層的圖片。預設連結原圖並建立縮圖；勾選另存副本才將原圖複製到應用資料內。

可切換縮圖或檔名清單，用滑桿或 Ctrl＋滾輪調整縮圖大小。列表標示的「檢視中」代表右側詳情與圖生圖的對象，多選則供批次匯出；檔案操作集中在詳情「更多」。

移除圖片或資料夾紀錄不刪原圖、應用內副本與縮圖。原圖移動後可用「重新連結原圖」，先確認是同一張圖片；原有手動附註仍會保留。分享用副本與批次轉檔見[匯出圖片](image-export.md)。

## 查看圖片資料與恢復組合

按「查看圖片資料」另開閱讀視窗，可看摘要或完整內嵌資料。PNG 可顯示 Prompt、Workflow 及可辨識的參數；多個文字節點與採樣器分開列出，自訂節點或間接連線可能無法解析。JPG／WebP 可預覽，本版未解析其 EXIF 生成參數。

「附上目前工作區資料」會另存當下建議，與圖片真正內嵌的生成資料分開。含 PCS 模組快照的圖片可恢復歷史組合：程式先備份目前狀態，再建立圖片工作區；歷史素材不會覆蓋現有素材，缺失圖片需重新指定。

部分舊 Stage PNG 可在資料完整的範圍內恢復已保存內容，不能補出缺失的上游、圖片或完整執行進度。保留原 PNG、Canvas 與備份，遇到拒絕時見[還原限制](troubleshooting.md#舊-stage-png-無法還原)。生成圖片仍有必要 Prompt／參照，完整備份保留私人素材庫，分享前核對[資料與隱私](data-backup-privacy.md)。

## 最近生成與收藏

ComfyUI 連線後，開啟「最近生成」，查看結果並收藏。收藏前先選目的地；未收藏結果依賴 ComfyUI 的 output／temp 原檔，清除或移動原檔後可能無法再取得。

Canvas 的預覽與下游圖片來源用途不同，接線說明見[Stage 與圖片流程](stage.md#圖片來源與預覽)。

## 本機模型管理

到「探索」開啟模型資產，選 ComfyUI 的 `models` 根目錄；會掃描 `loras`、`checkpoints`、`diffusion_models`、`unet` 與其子資料夾。掃描只讀取檔案資訊，不載入模型權重。

每個模型先顯示簡短預覽，開啟詳情後可編輯名稱、分類、觸發詞、網址、備註及預覽；來源與檔案資訊集中在第二頁。個人資料修改後自動保存，失敗時保留草稿供重試，關閉後仍可回來繼續。

點觸發詞的複製圖示會複製目前編輯中的文字；預覽中的文字也可點擊複製。觸發詞與備註各自捲動，較長內容不會推走整個視窗。預覽圖上方整區可更換、下方可移除；沒有圖片時整區可新增，也可拖入圖片。匯入模型會複製已下載的檔案，保留來源且不覆寫同名檔；外部新增或移動模型後按「重新掃描」。

「移至資源回收筒」會處理實際模型檔案，確認視窗會顯示路徑；失敗時不改用永久刪除。移走後仍保留說明與預覽，可還原檔案後重新掃描。

模型庫中的建議不會自動改動 ComfyUI 工作流。實際模型選項需在原生工作流或[Stage 參數](stage-parameters.md)設定。

## CivitAI

CivitAI 搜尋、預覽與下載會連網，部分下載需要自己的 Token。回傳 401 時先核對 Token、帳號權限與模型存取限制；不要把 Token、驗證網址或完整下載收據貼到 Issues。

已修正一條可重現的 CivitAI 預覽排版退出路徑，更新或清除 Token 後的舊回覆也不再改動目前畫面。這不涵蓋全部實機退出情境；若仍遇到異常，先保留未保存內容，再回報版本、操作步驟與去敏訊息。

Token 與下載收據的保存、分享注意事項見[資料與隱私](data-backup-privacy.md)。
