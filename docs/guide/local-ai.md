# 本機模型、對話與 Markdown 文字協作

適用 [0.8.10 Pre-alpha1](../releases/0.8.10/pre-alpha.1.md)。PCS 直接管理自己的本機推理程序，不需要另開 LM Studio。

## 準備模型與引擎

1. 自行取得支援的單檔 GGUF 模型，以及 [llama.cpp b11900](https://github.com/ggml-org/llama.cpp/releases/tag/b11900) 的 Windows `llama-server.exe`。先核對下載來源、模型授權與硬體需求，完整解壓引擎套件並保留同目錄 DLL。
2. 在 PCS「探索 → 本地模型」開啟「引擎設定」，選擇該 `llama-server.exe`。也可將完整引擎套件放在程式旁 `runtimes/llama.cpp`，使用其中的 `llama-server.exe`。
3. 按「加入模型…」選既有 GGUF，或設定「模型資料夾」掃描。這些操作只登記原檔位置，不搬移模型或立刻開始推理；原資料夾需保留。
4. 選用模型，從模型列齒輪調整上下文、回覆上限、溫度、思考與 GPU 層數等設定。GPU 層數「自動」交由引擎依記憶體分配，0 為 CPU；思考限制須由模型與引擎共同支援。

模型、引擎及所需 DLL 都不隨來源包提供。目前沒有產品內引擎安裝／更新及模型網路搜尋下載。已核對的運行證據只涵蓋指定引擎及個別模型，不代表任何 GGUF 都相容。

## 保存本機對話

從文件新增入口建立本機對話，或在模型頁開新對話。選模型後輸入訊息並送出，PCS 才會準備所選模型；保持程式開啟，閒置釋放依引擎設定處理。

對話是可保存的 `.pcs-chat` 文件，可加入附件、重試回覆、查看訊息版本與分支，並匯出 Markdown。思考及正文分開顯示；停止會保留已收到的文字。圖片附件可保存與查看，目前不能據此推定模型能理解圖片。

## 改寫選取文字

在 Markdown 編寫／原文模式選取文字，在浮動輸入框選擇模型並輸入要求。請求會帶完整文件作上下文，只將選取部分作為改寫目標；不會混入目前聊天的歷史。

生成後在原頁比較淡灰刪除線的原文與藍色候選。按「保留」才提交修改；可「重試」或「刪除」候選，保留後可 Undo。送出前後若原稿已變，先重新選取並檢查，勿將舊候選套回不同內容。

沒有選取時，可在空白文件起稿或在文末續寫。全文超過上下文時會回報，請縮短文件或調整設定；系統不會以靜默截斷冒充完整上下文。

## 更新與私密資料

先備份 `files` 與 `data`，用副本試新版本。模型登記保留原位置，移走模型可能使登記失效。模型生成可能省略原意或加入錯誤，請審閱再採用。對話、提示詞、附件及啟動日誌可能含私人內容，分享前請檢查。
