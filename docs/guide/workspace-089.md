# 開始使用 0.8.9 Beta2

[更新內容](../releases/0.8.9/beta.2.md) · [驗證與限制](../releases/0.8.9/validation/beta.2.md)

## 來源版

將 `PCS-v0.8.9-Beta2-source.zip` 完整解壓到新的資料夾。使用 Windows 64 位元 Python 3.12，在含 `run.py` 的資料夾開啟 PowerShell：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py --v0.8.9-beta.2
```

首次安裝依賴需網路，之後雙擊 `Start.cmd`。首次會開啟「歡迎使用.md」，從裡面的連結進入「入口」資料夾的教材。之後會接續已保存的分頁；關閉歡迎頁後，不會每次強制插回。教材可直接編輯，想保留初始內容可先複製文件。

本版公開來源與三種配套，沒有 Windows EXE 下載。下載入口見[本次 Release](https://github.com/gghjkiof36-wq/Prompt-Calculus-Studio/releases/tag/v0.8.9-beta.2)。

## 內容與資料

預設 `files` 保存新文件，`data` 保存設定、工作區記錄及內部資料；兩者都在程式旁。可從「內容 → 加入本機資料夾」接入既有內容副本。原件不會因加入資料夾而自動複製；在該文件上編輯會保存到它所在的位置。

進階啟動可用 `--root <內容資料夾>` 與 `--data <資料資料夾>` 指定獨立位置。`PROMPT_STUDIO_DATA` 亦可指定資料位置；內容資料夾須放在資料目錄外。

## 先試一次完整操作

1. 從歡迎頁開啟「從筆記到 Prompt」，依序試海岸筆記、海岸素材與練習畫布。新增自己的 Markdown 筆記，輸入文字，再切換閱讀模式。
2. 新增 Prompt 分類與 Canvas 工作流，將文字素材拖入 Canvas。新建 Canvas 提供畫布、Prompt 輸出、CLIP 輸入、預排程、Stage 與圖片預覽六個已連接的模組。兩份文件可左右並排。
3. 收合內容側欄，將游標移向左側，確認它暫時展開；移開後會收回。設定 → 介面個人化 → 操作行為可調整此功能。
4. 關閉再重開文件，確認內容與工作區布局。Canvas 與分類沿既有保存流程自動保存。

要使用 ComfyUI，安裝同版配套擴充，並由你重新啟動後端與刷新工作流網頁。通用、legacy 與 modern 配套擇一；相容設定名稱不代表已完成真實 GPU 驗收。

## 閱讀、貼上與分頁

文件連結優先回到已開頁；從側欄拖到分頁區開啟，拖至右側並排。原文與閱讀依目前欄寬顯示，大綱可收回；浮動側欄可切換內容及調寬，仍保持浮動。

在 Markdown 編寫或原文用 Ctrl+V 保留來源可提供的格式，Ctrl+Shift+V 貼純文字。從「⋯ → 匯入對話…」選本機 ZIP／JSON，勾選對話後保存全部分支、所選原始紀錄與附件。詳見[貼上與匯入](markdown-import.md)。

## 關閉、草稿與恢復

關頁或退出先完成輸入法組字，再保存。若提交後仍在組字，視窗會保持開啟。原檔或內容刷新失敗，且恢復副本也未成功寫入時，保留視窗、稿件與目前 Undo，請先保存或另存到可寫位置。恢復副本已落盤、正常保存或明確捨棄時，沿原流程關閉。原檔已被外部修改時不直接覆寫；重開恢復內容也不等於恢復先前完整 Undo 歷史。

素材編輯視窗可點外側、按 Esc 或關閉圖示離開；未確認表單保留為該素材草稿，下次開啟再恢復。「保存」提交內容，「捨棄修改」清除草稿，只查看不製造修改。模型詳情的自動保存與圖片操作見[媒體庫與模型](media-models.md)。

## 連線與多文件執行

在「設定 → 連線與工作流」填自己的 ComfyUI 位址並連線，右上燈號顯示連線狀態。先安裝一份同版配套，由你重啟後端、刷新工作流網頁並核對實際載入版。舊 preparation.7 只讀格式 1–6，格式 7 需新配套；格式已相容但工作流模式受限時，依具體原因處理，見[相容指南](comfyui-compatibility.md)。

分頁 Canvas 的 CLIP、圖片綁定與 Stage 參數使用文件自己的連線。同文件多視圖共用，其他文件的綁定與草稿隔離。

同一 PCS 工作區的完整流程依序執行。按執行先保存當次輸入，其他文件還在執行時顯示「已排隊」，懸停可查看順序。切頁、關頁或另存不轉移已送出任務；取消等待文件也不取消另一文件。

重開先用原任務身分核對已送出的工作，不因恢復重送。尚未執行的流程暫停，開啟所屬文件後，在「任務紀錄 → 流程紀錄」選擇並「繼續」。執行或取消後不清楚有沒有送出／停止時，先看 ComfyUI 佇列與歷史；查證完成前新的流程會等待。已分離的舊紀錄可查詢或停止後續流程，不從舊內容重試發起新任務。

PCS、ComfyUI 後端與工作流網頁仍須保持開啟。這個順序只協調目前工作區，不統一排其他 PCS 程序或 ComfyUI 手動任務。

任務紀錄在 `data`，與 `.pcs-workflow` 分開。備份或搬移整個環境時，同時保留內容與 `data`；只複製文件不等於帶走執行歷史。另存新檔建立獨立歸屬，先前任務仍從集中紀錄核對。

## 更新前

保留舊程式、舊擴充及原資料。先以新的資料目錄和內容副本使用 0.8.9，不讓新舊程式同時寫入同一份資料。完整舊資料庫導入仍有驗證限制；這個啟動器不會自行轉換或刪除原安裝。

舊匯入輸出不自動清理，需重匯另存並保留手改內容。大型文件及異常退出的剩餘限制見[本版摘要](../releases/0.8.9/validation/beta.2.md)。

## 筆記範圍與閱讀更新

新增或移除筆記資料夾後，閱讀中的嵌入筆記會依目前有效範圍重新解析。較深的資料夾可以改變同名筆記的可見範圍；舊範圍的背景結果不會蓋回目前內容。可見閱讀頁延遲刷新，隱藏頁在返回時更新，原稿、未保存修改與瀏覽位置保持原有歸屬。
