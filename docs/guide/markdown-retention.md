# 保存演示、整理對話與匯出

適用：0.8.9 Beta3 本機開發版 · [對話匯入](markdown-import.md)

## 保存演示

在 Markdown 編寫模式，從插入選單選 **演示／原檔**。填入標題，選擇原檔、預覽圖片和相關檔案資料夾，再按 **預覽保存內容 → 保存並插入**。

已保存的演示可從 **附件與修訂** 補檔或建立新版。插入與替換引用支援復原、重做；各版附件分別保存。

## 選擇與瀏覽對話

從文件右上角 **⋯ → 查回與整理對話…** 開啟「對話整理」。選擇已匯入的對話，或按 **匯入對話…** 選取 ChatGPT 匯出的 ZIP／JSON。從對話資料夾開啟時，會直接顯示該對話。

| 頁面 | 用途 |
| --- | --- |
| **原對話** | 搜尋、閱讀與釘選原始問答 |
| **ChatGPT 整理** | 複製對話片段、貼回 ChatGPT 的整理結果 |
| **整理稿** | 編輯整理內容、按需查看原文、預覽與保存 |

**原對話** 左側是訊息清單，右側顯示原始問答。頂端可切換分支、搜尋訊息；角色、範圍與日期在 **篩選** 中。需要保留的訊息可按 **釘選原文**。

## 用 ChatGPT 整理

1. 按 **交給 ChatGPT 整理**，選用途與篇幅，再按 **準備整理**。
2. 在左側按 **複製內容**，貼到 ChatGPT；取得回覆後，在右側按 **貼上 → 加入整理稿**。
3. 對話較長時會分段。頂端顯示進度，加入一段後切到下一段；每段的貼回草稿會分別保留。
4. 按 **查看整理稿**，選擇項目後直接編輯內容。窄窗可從頂端選單切換項目。
5. 按 **預覽整理稿**，編輯最後內容，再選 **複製**、**另存 Markdown…** 或 **儲存新版本**。

需要確認整理內容是否符合原意時，按 **查看原文**，再視需要修改內容或用 **選擇引用** 更換來源。**項目選項 → 分類** 決定整理稿的分組；**已對照原文** 是自己的閱讀記錄，未勾選也可保存。

**分段設定** 可調整每段字元數；**整理稿 → 輸出設定** 可調整字數上限。未完成所有段落時，整理稿會標明已整理的範圍。

預覽後可按 **編輯項目** 返回；再次預覽會保留手改內容。若整理項目有變更，選 **保留編輯** 繼續使用目前稿，或 **重新產生** 套用更新；重新產生可用復原還原。

已儲存的版本放在對話旁的 `整理稿` 資料夾；可從 **ChatGPT 整理 → 開啟整理稿…** 重新編輯。來源版本有變動時，畫面會顯示對應狀態。

## 匯出與重開

1. 開啟要帶走的文件，選 **⋯ → 匯出文件與來源…**。
2. 選資料夾或 ZIP、對話分支，以及是否附帶整理稿來源。
3. 按 **預覽匯出內容**，確認檔案清單，再選位置匯出。
4. 資料夾從 `閱讀說明.md` 開啟；ZIP 使用 **⋯ → 開啟可攜 ZIP 副本…**。

匯出採用開啟視窗當下的文件內容，包括尚未保存的編輯。每次匯出和開啟 ZIP 都建立新副本。缺少的附件會列在預覽中。

## 檔案範圍

單檔上限 256 MiB；單次合計 512 MiB、最多 2,000 個檔案。HTML 演示以靜態圖片預覽，原檔連結交由外部程式開啟。可攜副本包含所選文件、引用附件、嵌入筆記及所選對話分支。
