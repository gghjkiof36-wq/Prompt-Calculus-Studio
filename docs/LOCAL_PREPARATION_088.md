# 0.8.8 本機前置驗證

此文件適用本機 `--v0.8.8-preparation.3` 驗證包，不表示已發布 0.8.8。公開 0.8.7 Alpha 1 的版本與下載內容未更新。

## 前置驗證 3 修復

- 圖片來源的單張／多張／資料夾選擇、最近生成的收藏資料夾，以及共用的嵌入／替換圖片、圖生圖來源及工作流匯入，恢復使用系統原生檔案選取視窗。Windows 使用與媒體庫相同的檔案選取介面；不再強制使用 Qt 自製視窗。保留檔案類型篩選、上次匯入目錄、排序及取消行為。
- 「文字畫布」模組統一稱為「畫布」，包括新增選單、預覽、來源類型及相關操作提示。新工作區採用新名稱；載入既有文件時，只更新完全等於舊預設名稱的畫布，其他自訂名稱保留。首次轉換沿用原有自動備份機制，模組 ID、內容、接線與手動草稿不變。
- 檔案視窗的原生選項、選取／取消、圖片匯入後的 Undo／Redo 及保存重開，以隔離資料及 Qt 離屏替代視窗核對。Windows 系統視窗外觀與 Shell 操作仍待原生桌面人工確認。

## 前置驗證 2 已有修復

- Prompt Editor 開啟素材預覽後，切換其他頁面再返回，清單會保留預覽欄所需空間，避免與預覽卡重疊。關閉預覽後仍恢復單欄。
- Canvas 執行欄拖曳期間，任務狀態更新會保留當前拖曳位置；放開滑鼠才儲存位置。視窗縮小時仍限制在可用範圍內，外觀與執行操作維持原樣。
- 以上以隔離資料及 Qt 離屏事件核對頁面往返、視窗縮放、定時狀態更新和位置保存；尚待原生桌面人工驗收。

## 前置驗證 1 已有變更

- 新增功能模組：窄視窗或大字級下，預覽、名稱與說明改由詳細區捲動顯示，搜尋及新增操作仍可使用。
- 圖片來源與單張圖片：Canvas 的圖片預覽可點開原圖；拖曳或右鍵不會開啟，雙擊不重複開啟。
- Prompt Editor：將素材卡拖到分類列可移動原件的分類，支援 Undo／Redo；畫布複本、手動草稿與 Prompt 排列保持原值。資料夾須先展開，將素材放到分類列，不能直接放到資料夾或「全部模組」。Canvas 新增文字模組頁沿用相同資料夾、數量及收合設定。
- 原生提交：網頁回覆遺失時，用後端佇列／歷史中的實際任務 ID、原始圖與 PCS 提交識別核對。已確認接收的任務不會被稍後的網頁錯誤改為失敗；缺少證據時仍顯示未確認，不自動重送。
- Stage 文字參數：支援由原生工廠建立、已核對 DynamicPrompts 處理器且輸出不變的純文字，包括空字串。提交前逐字核對實際輸出；現場網頁與響應式控制項原值會復原。

## 仍有的限制

**準備下一筆工作仍需要 ComfyUI 工作流網頁。** 舊背景執行程式內的固定版本與 `hooks_verified` 標記，不能證明目前前端具備相同能力，因此沒有重新啟用。解除此限制需要前端提供可持續核對的序列化／控制回呼能力、工作流身分及版本、參數投影與種子證據；重啟、重新連線或能力變更時也必須能撤銷。對帳已接收任務不等於能離線準備下一筆。

| 欄位／來源 | 本機前置版處理 | 原因 |
| --- | --- | --- |
| 原生 INT、FLOAT、BOOLEAN、ENUM、STRING | 符合既有型別、範圍、工廠與回呼核對時可編輯 | 以實際提交內容驗證，不能只依節點名稱判斷 |
| 原生 DynamicPrompts 純文字 | 可編輯，提交輸出必須與要求逐字一致 | 已核對原生處理器與同步執行路徑 |
| `{a\|b}` 動態選項、會被移除的註解或跳脫轉換 | 在 ComfyUI 編輯模板 | 原生處理會改變要求的文字；已知模板唯讀，新覆寫若觸發轉換則拒絕提交 |
| 外掛自訂／非同步序列化器、未知 before／after 回呼、被換掉的 setter | 維持唯讀或拒絕參數投影 | 未具備可隔離、復原且能核對的生命週期 |
| 連線供應、PCS 文字／圖片綁定的欄位 | 保留來源或既有唯一綁定 | 不以 Stage 覆寫來源，也不覆寫未綁定欄位 |
| 子圖路徑、無提交對應欄位、多組或未識別種子控制 | 維持既有限制並顯示原因 | 缺少可靠的欄位路徑、唯一控制或原生政策證據 |
| 超出 JavaScript 精確整數範圍的原生數值 | 不推定可精確編輯 | 避免種子或整數失真 |

原生能力測試可指定既有前端檔案：`PCS_FRONTEND_ASSETS` 與 `PCS_FRONTEND_VERSION=1.53.10`。測試執行已安裝的原始碼與 Vue／Pinia 控制，外層圖與頁面環境使用離線適配；尚未驗證完整瀏覽器、真實服務或 GPU。

本機驗證包與配套擴充須使用同一提交。使用隔離資料；保留公開版及原資料。程式碼回退不會回退資料，資料相容與正式更新另行驗證。
