# 資料、備份與聯網

[回首頁](../README.md)

## 本機資料

原始碼版預設保存於專案的 `data`，封裝版保存於 EXE 旁的 `data`。自行指定 `PROMPT_STUDIO_DATA` 時，以該路徑為準。

| 內容 | 位置 |
|---|---|
| 素材、工作區、設定與圖片索引 | `studio.sqlite3` |
| 壓縮縮圖 | `thumbnails` |
| 應用保存的原圖副本與收藏 | `originals` |
| 匯入前資料庫備份 | `before-import-*.sqlite3` |
| 最近錯誤訊息 | `error.log` |

外部連結圖片及 ComfyUI 模型保留在原位置。移除媒體庫紀錄不刪除原圖；模型管理中的回收筒操作則會處理實際模型檔案。

## 備份

在「資料與備份」選擇 ZIP 備份，可保存一致的資料庫快照、縮圖與應用內原圖副本。外部圖片及模型需另外備份。

JSON 匯出保存文字與檔案索引，不包含圖片、模型檔、匯出紀錄與匯出預設。匯入 JSON 會先驗證並詢問是否取代索引，也會備份資料庫。單份 JSON 匯入上限為 64 MB；完整備份請使用 ZIP。

## 還原

1. 關閉 Prompt Studio。
2. 將目前的 `data` 另存到其它位置。
3. 解壓備份，把其中的 `data` 放到程式使用的資料位置。
4. 啟動程式，確認素材與圖片可讀取。

外部圖片路徑改變時，使用重新連結；模型則重新指定根目錄並掃描。舊縮圖與原圖副本目前不會自動永久清理。

## 什麼時候會連網

| 操作 | 傳送或讀取的內容 |
|---|---|
| Danbooru 補全 | 目前查詢片段，取得候選文字 |
| 選用 Google Cloud Translation | 待翻譯片段與服務所需驗證資訊 |
| 拖入網路圖片 | 向圖片網址下載圖片 |
| ComfyUI 連線 | 向本機後端交換組合、任務與結果資料 |
| 首次安裝依賴 | 從 PyPI 下載 Qt 套件 |

可在設定關閉聯網候選。Google 金鑰目前只保留於程式記憶體，不寫入資料庫或 JSON；使用服務前請了解其計費。

## 分享圖片與問題紀錄

PNG 可能含完整工作流與 Prompt。需要移除附加資訊時，使用 [匯出功能](../CLEAN_EXPORT_GUIDE.md)，並確認結果通過驗證。

原有工作流可能包含檔案路徑；分享工作流、日誌、資料庫與截圖前請自行檢查。匯出會清理檔案附加資訊，畫面內的文字、浮水印及像素內容會保留。
