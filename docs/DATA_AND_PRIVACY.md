# 資料、備份與隱私

[返回首頁](../README.md)

## 資料存在哪裡

從原始碼啟動時，預設保存在專案根目錄的 `data`。設定環境變數 `PROMPT_STUDIO_DATA` 可以改用其他資料位置；移動或切換前請先備份。

| 內容 | 位置 |
|---|---|
| 模組、工作區、設定、索引及候選快取 | `data/studio.sqlite3` |
| 預覽縮圖 | `data/thumbnails` |
| 選擇保存的圖片副本 | `data/originals` |
| 錯誤記錄 | `data/error.log` |
| ComfyUI 擴充設定、任務及收藏紀錄 | ComfyUI `user/prompt_studio` |

外部連結圖片及模型保留在原位置。應用內的相簿、標籤或記錄更動不等於搬動那些檔案；模型「移至資源回收筒」則會操作實際模型。

## 備份方式

「資料與備份 → 匯出 JSON」保存文字與檔案索引，不內嵌圖片或模型。匯入會驗證資料、詢問是否取代索引並建立匯入前資料庫備份。

ZIP 備份包含一致的 SQLite 快照、縮圖及應用內原圖副本。外部連結圖片、模型與 ComfyUI 擴充資料需另外備份。還原前關閉程式並另外保存目前 `data`，再將備份中的 `data` 放回原始碼根目錄。

## 何時使用網路

- 啟用聯網候選時，輸入片段可送至 Danbooru 查詢候選。設定中可關閉；程式保留本地快取。
- 選用 Google Cloud Translation 時，翻譯片段送至該服務。需使用自己的服務與金鑰；金鑰只保留於當次記憶體。
- 連接 ComfyUI 時，Prompt、模組快照與控制請求會送到你指定的本機 ComfyUI，並讀取生成結果。
- 安裝依賴套件時會連接 PyPI；點擊外部網址會開啟相應網站。

文字候選查詢不會上傳圖片、模型或整份素材庫。ComfyUI 工作流內的其他擴充或服務可能有自己的聯網行為，請依你使用的工作流確認。

## 分享前檢查

PNG、工作流、備份與錯誤記錄可能包含 Prompt、模組內容、檔名或本機路徑。向他人分享時先檢查內容；公開版目前沒有無 metadata 圖片匯出功能。不要將個人 `data` 或原圖備份加入 Git 提交。
