# 資料、備份與隱私

[回首頁](../README.md) · 適用：0.84 Alpha 1

## 本機資料

來源版預設使用 run.py 旁的 data；PROMPT_STUDIO_DATA 可指定其他位置。舊識別名稱保留相容用途。

| 內容 | 位置或方式 |
|---|---|
| 模組、工作區、設定、索引與快取 | data/studio.sqlite3 |
| 縮圖及保存的原圖 | data/thumbnails、data/originals |
| 錯誤與原生異常記錄 | data/error.log、data/fault.log |
| CivitAI 下載收據 | data/civitai/downloads |
| CivitAI Token | data/credentials/civitai.bin，以 Windows 帳號 DPAPI 保護 |
| ComfyUI 設定、任務與收藏紀錄 | ComfyUI user/prompt_studio；擴充 local_library.json 指向桌面資料 |

外部圖片、模型仍在原位置。移除媒體紀錄不等於刪除原圖；模型的回收筒操作則會處理實際檔案。DPAPI 憑證不能當成跨帳號或跨電腦可攜備份。

## 0.84 圖片、排程與診斷

圖片來源副本與預排程保存內容可能含Prompt、圖片及來源資訊，分享前檢查。Stage保留本輪任務結果，歷史需明確選用；PNG及undo/redo不重新提交任務。

操作診斷每項最多64筆固定階段、時間及歸屬事件，不記錄Prompt、圖片或Token。其他工作流、收據、日誌或備份仍可能含私人資訊，診斷限制不能代替整體分享檢查。舊等待保留並暫停，不升級後自動補跑。

Windows版data預設在EXE旁，原始碼版在run.py旁；兩種啟動要確認目前資料位置。公開Windows包不得包含個人資料庫、私人圖片或私人啟動設定。

## 備份與回退

ZIP 備份包含一致的 SQLite 快照、縮圖、應用內原圖與 CivitAI 下載收據；不含外部模型、外部圖片或 credentials 目錄。JSON 匯出保存文字及索引，不內嵌模型與圖片。擴充資料需另外備份。

更新前保留舊程式、舊擴充及舊資料 A，新版使用副本 B。要回退時舊程式只開 A，保留 B 的新內容；沒有自動合併保證。還原前關閉程式並另存目前資料，勿以舊備份蓋掉唯一的新資料。

## 聯網內容

| 操作 | 傳送或讀取的內容 |
|---|---|
| Danbooru 候選 | 查詢片段與候選文字，可在設定關閉 |
| 選用 Google 翻譯 | 待翻譯片段及驗證資訊，金鑰保留當次記憶體 |
| CivitAI 搜尋／詳情／預覽／下載 | 查詢、資產與下載請求；需要時使用自己的 Token |
| 網路圖片匯入 | 向所選網址下載圖片 |
| ComfyUI | 向本機後端傳送 Prompt、模組快照、控制及選定圖片，讀取任務與結果 |
| 首次安裝依賴 | 從 PyPI 取得套件 |

ComfyUI 工作流中的其他擴充可能有自己的聯網行為。文字候選不等於上傳整份素材庫；圖片輸入會依使用者接線送往 ComfyUI。

CivitAI 重導會限制憑證跨來源傳遞；新版將特定下載例外轉成固定訊息，避免遠端錯誤原文直接進入新收據。這不會清理舊收據，也不代表真實服務 401 已修好或所有資料已完成隱私審查。

## 分享前

PNG、工作流、收據、備份與錯誤記錄可能含 Prompt、模型名稱或私人路徑。公開回報先檢查內容；不要提交 data、Token、模型與私人圖片。可用 [匯出功能](../CLEAN_EXPORT_GUIDE.md) 移除圖片附加資訊，再檢查結果；像素內的文字及私人內容仍會保留。安全問題見 [SECURITY](../SECURITY.md)。
