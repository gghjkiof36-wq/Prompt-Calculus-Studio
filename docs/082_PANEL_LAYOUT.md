## 使用結果

- 新增模塊面板頂部搜尋，下方依序為類別、本地模塊、聯網查詢。右側候選沿用現有個人字典、熟悉詞、文字快取及查詢來源，以來源名稱標示，不再彈出遮住本地列表。
- 移除大標、原操作說明、X 與底部關閉；點背景或 Esc 關閉。遮罩只變暗，140 ms 淡入／小幅位移；遵守既有減少動畫設定，動畫完成後停用透明度效果。
- 右下角可調整面板大小，維持可用視窗範圍內置中。三欄獨立捲動；搜尋依字型與內容調高，隱藏多餘垂直捲軸。「新增分類」與「新增空白模組」位於各自欄位底部且水平對齊。
- 本地素材、手動 Tag、選定候選均在新增一項後關閉，沿用原始呼叫的場景座標。原始程式中，手動／候選 Tag 加入後曾保持面板開啟；這項差異依 rev 6 統一。
- 模型頁移除底部 20 個邏輯像素的外層空隙；Manager 頁移除底部 16 個邏輯像素的外層空隙，加入可捲動容器。模型詳細表單在分頁、字級及尺寸改變後重新計算一次布局，修正底端動作超出捲動範圍的情況。

## 鍵盤規則

| 所在位置 | 按鍵 | 行為 |
|---|---|---|
| 搜尋 | 下 | 本地第一筆；本地空白則維持搜尋 |
| 搜尋 | 右 | 游標末尾、無選取且未組字時，進入建議第一筆 |
| 本地 | 上／下 | 上下瀏覽；第一筆上回搜尋並恢復游標／選取 |
| 本地 | 右 | 首次建議第一筆，之後恢復建議欄選取 |
| 建議 | 左 | 回此次入口：搜尋框或原本地項目；瀏覽其他建議不改入口 |
| 三區 | Tab／Shift+Tab | 搜尋、本地、建議固定順序往返，略過空列表 |
| 搜尋／結果 | Enter | 加入手動文字／目前選定項目；中文組字期間不提交 |

結果按身分保存選取，重新查詢或項目消失後不保留失效索引。正在瀏覽的項目被移除時回搜尋框；晚到的新結果不主動搶焦點。面板大小只保留在當次開啟期間，沒有新增跨重開的設定或資料格式。

## 工程邊界與相容性

`text_canvas.CanvasPalette` 保留匯入入口，面板內容移至 `canvas_palette.py`。`CanvasTagEdit` 繼承現有 `PromptEdit`，以 `lookup_active` 和 `lookup_notice` 提供嵌入列表所需的可用狀態與區內回饋。`CompletionService` 仍是唯一排程、快取、來源查詢與排序入口；一般文字編輯器保留彈出式候選。

查詢排程與開始請求時保存資料庫／工作區身分；回應核對序號、身分、查詢片段、線上設定及關閉狀態後才寫快取／顯示。已取消、過期或關閉的結果不再回寫。既有傳輸仍以 timeout 收尾，不承諾立即中斷 socket。

新增仍呼叫 `add_tag`／`insert_asset` → `append_value` → `TextCanvas.commit`，多畫布歸屬由既有 `MultiCanvas` 判斷；沒有新增平行狀態、API 或資料庫。資料格式、依賴、內部識別、生成快照、綁定與 ComfyUI 純 Python 模組均未改動。

## 首批時的 C 持久文字快取短方案

現有 `core.Storage.cache/cached` 已使用 SQLite 持久保存，最多 500 筆查詢，按寫入時間淘汰；線上有效期 24 小時，離線可讀較舊資料。個人字典和已接受詞紀錄已有独立資料，不能當作快取一起刪除。

建議首版：

1. 最多 **5,000 筆查詢且文字 JSON 合計 16 MiB**，先到者觸發淘汰；以最後讀取／寫入時間保留常用查詢，超額單筆不保存。16 MiB 是快取內容預算，不承諾整個 SQLite 檔案的固定大小。仍每次最多 12 個候選，只保存使用者查過的文字，不抓全站或加圖片快取。
2. 沿用 24 小時線上新鮮度。命中舊文字先標示快取並顯示，線上按既有節流更新；離線只使用本機保存結果。空結果僅保存 1 小時，避免暫時無結果長期擋住後續查詢。
3. 「禁止搜尋快取」停止讀寫搜尋快取，保留舊資料；不影響個人字典、已接受詞、素材或歷史。「清除搜尋快取」只刪該用途資料。清除／停用遞增快取世代，已在途回應不可重建清除前的內容；重新啟用只供新查詢讀寫。
4. 來源、provider、查詢及 artist 等條件保持分離。Google 翻譯與未核對來源不自動套用擴大保存方案。

上述為首批時的工程建議；使用者其後明確要求「快取方案順便做一下」，已依方案實作，詳見 `082_FLOW_CACHE.md`。來源服務允許的保存範圍與真實 API 行為仍未完成外部核對，不能由程式碼授權推定網站資料授權。

首批保留的品牌、浮動執行列、Prompt／CLIP 拆分已由使用者在本輪核准。多選、最近使用／完整 Prompt 歷史與多網站仍未納入；專用收藏、CLIP 強度及未來轉譯不在本輪。
