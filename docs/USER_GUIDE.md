# 使用手冊

## 模組與素材

模組是你自己建立的分類，可新增、改名、刪除與排序，也可設定單選或複選。素材保存名稱、Prompt、別名、備註與預覽圖。

在左側選模組，再點素材加入組合。上方搜尋可比對名稱、Prompt 與別名。尚不需要保存的文字可按「加入片段」，作為這次組合的臨時內容。

預覽區可拖入本機圖片，或貼上剪貼簿圖片。從瀏覽器拖入時，需要取得圖片本身或可讀取的圖片網址；登入限制或只有網頁連結時，可能無法匯入。

## 排序與權重

左側排序決定模組清單位置；右側排序決定 Prompt 的輸出順序。拖曳右側群組不會調整左側清單。

新加入的群組依左側順位插入；取消整組後再加入，會重新套用這個規則。已有群組保留目前手動排序。群組內的素材也可排序，右鍵提供上移、下移等操作。

素材上的 −／＋每次調整整段權重 0.1。例如 `red dress` 加一次後輸出 `(red dress:1.1)`；素材庫原文維持不變。已有括號的文字會再包一層，實際效果取決於使用的模型與文字解析方式。

## 暫停衝突 Tag

編輯素材時，在「使用此項目時，自動停用以下 Tag」填入要排除的完整 Tag，一行一個或以逗號分隔。

例如「閉眼」素材的內容是 `closed eyes`，排除清單填 `red eyes`。選用它後，其它素材中的 `red eyes` 會從自動輸出暫時移除，其餘文字保留。受影響素材會有黃色邊框與原因提示；取消「閉眼」後恢復。

比對忽略大小寫及底線／空格差異，支援一般括號權重。近義詞需自行列出。排除規則不會改寫手動稿。

## 手動版本

直接編輯右側最終 Prompt 後，程式會使用手動文字，組合區暫停操作。

- 「存入素材庫」可保存文字供下次選用。
- 「清除內容」會清除手動稿，恢復原先的素材組合與臨時片段。
- 若關閉了清除確認，可到「設定 → 外觀 → 操作確認」重新開啟。

## 工作區

工作區適合保存不同模型或創作主題的常用組合。左上角切換工作區，「⋯」提供新增、設定與刪除。

將模組設為固定後，勾選「以目前選擇更新固定組合」並儲存，才會更新預設選擇。切換工作區時只還原固定模組，其餘選擇、臨時片段及手動稿保留。

工作區可記錄模型、LoRA、CFG、步數、採樣器、Denoise、Seed 與備註，並保存參數歷史。0.7.1 的這些值供你參考，實際生成仍以 ComfyUI 工作流為準。

## 模型管理

1. 按「選擇資料夾」，指定 ComfyUI 的 `models` 根目錄。
2. 程式索引 `loras`、`checkpoints`、`diffusion_models` 與 `unet` 及其子資料夾。
3. 點選模型，填入易讀名稱、分類、觸發詞、網址、備註與預覽。

掃描只讀取檔案資訊，不載入模型權重。外部移動或新增檔案後，按「重新掃描」。

「匯入模型檔案」會複製已下載的模型到指定位置，同名不覆寫，可取消背景複製。「移至資源回收筒」會處理實際模型檔案，執行前請核對顯示的路徑。從回收筒還原後，可重新掃描。

目前不提供自動從 Civitai 下載模型或抓取預覽。

## 媒體庫與收藏

先建立資料夾，再加入圖片。預設連結原圖並建立縮圖；若希望把原圖存入應用資料，可勾選另存副本。加入磁碟資料夾時只匯入本層圖片。

移動相簿紀錄不會搬動外部原檔，移除圖片紀錄也會保留原圖。外部原圖移走後，可重新連結，保留原先備註。

最近生成的收藏方式見 [ComfyUI 指南](../COMFYUI_GUIDE.md)。分享用副本的操作見 [匯出指南](../CLEAN_EXPORT_GUIDE.md)。

## 查看生成資料

選取 PNG 圖片後，可查看內嵌的 Prompt、工作流，以及可辨識的模型、LoRA、採樣器等資訊。多個節點會分開列出；自訂節點與間接輸入不一定能完整解析，可開啟原始生成資料確認。

「附上目前工作區資料」會另外保存手動附註，與圖片內嵌資料分開顯示。JPG／WebP 可預覽，但目前沒有解析其 EXIF 生成參數。

圖片若含 Prompt Studio 模組快照，可按「恢復這次模組組合」。程式會先備份目前狀態，再建立圖片工作區；已變動或刪除的素材以歷史內容保留。

## Tag 補全

搜尋框輸入英文片段可取得 Danbooru 候選；`@ap` 可查詢繪師。接受過的候選會保留本機快取，供常用排序與離線選用。

中文可在「設定 → 個人字典」加入對照，例如：

```text
紅色衣服 = red clothes
簡單背景 = simple background
```

目前沒有全量詞庫下載或任意長句自動拆 Tag。Google Cloud Translation 為選用介面，需自行提供金鑰，尚未完成真實金鑰的端到端驗收。聯網內容見 [資料與隱私](DATA_AND_PRIVACY.md)。

## 外觀與快捷鍵

設定可調整字型、字級、間距、色彩及實色／Mica／Acrylic。透明效果依 Windows 與顯示環境而異，不支援時會使用實色。

| 快捷鍵 | 操作 |
|---|---|
| Ctrl+F | 搜尋 |
| Ctrl+Shift+C | 複製完整 Prompt |
| Ctrl+, | 開啟設定 |
| Enter／Tab | 接受目前補全候選 |
| Esc | 關閉候選 |
| Ctrl+↑／Ctrl+↓ | 調整組合中項目順序 |
