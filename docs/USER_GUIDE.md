## 模組、Prompt 與 Canvas

模組是自己的分類，素材保存名稱、提示詞、備註及預覽。先選素材，再調整順序與權重；排除 Tag 只影響自動組合，原文保留。清單與 Canvas 共用素材，操作與手動稿分開。

Canvas 中以模組組合文字、交給 Prompt，再由 CLIP 指定工作流文字目的地；圖片沿接線流動。保存畫布與使用 undo/redo 時留意目前工作區。畫布位置用於整理內容，不代表生成畫面的精準空間控制。

## 手動文字

桌面直接編輯的 Prompt 是手動稿，不應由後續自動組合擅自覆寫。清單「清除內容」會清除手動稿並恢復原素材組合，請確認後操作。

CLIP 的「使用 PCS 提示詞／使用 ComfyUI 手動文字」另外決定網頁欄位來源。預設 PCS；選手動網頁文字後，網頁刻意清空也保留。切回 PCS 前先保存需要的網頁文字。這個切換不表示歷史圖片內容會一起更新。

## 單一工作流生成

安裝同版擴充、保持 ComfyUI 工作流網頁開啟，明確綁定 CLIP 文字欄後執行。每次只提交該工作流一次，batch_size 沿用網頁；未綁定參數也以網頁當前值為準。

工作流排序可以保存與復原，本版未開放跨工作流、多輪或無網頁背景提交。步驟與相容界線見 [ComfyUI 指南](../COMFYUI_GUIDE.md)。

## 圖片與最近生成

將圖片來源接到預覽可查看整批結果，點圖放大不改加載選擇。斷開來源後預覽清空；「最近生成」是獨立結果入口。要把圖片送入同工作流的 LoadImage，先明確選定目標與單張輸入；整批逐張下游執行尚未完成。

收藏可複製結果到選定位置。媒體庫中的外部連結需保留原圖；分享前用 [匯出指南](../CLEAN_EXPORT_GUIDE.md) 檢查 Metadata，像素內私人內容仍需自行處理。

## 模型與 CivitAI

模型管理可索引本機模型、記錄觸發詞與預覽；索引不載入模型權重。CivitAI 搜尋、預覽及下載會連網，部分下載需要自己的 Token。模型刪除會涉及實際檔案，先核對路徑。

Repair 5 的 CivitAI 錯誤訊息保護已有本機驗證；401 或受限模型的實際下載成功率沒有因此獲保證。不要把 Token 貼到 Issues，資料與憑證說明見 [資料與隱私](DATA_AND_PRIVACY.md)。

## 保存與備份

修改保存在目前資料位置。更新前用 ZIP 備份並保留外部圖片、模型及擴充資料；新版用副本，回退用舊資料。第一次使用與資料位置見 [開始使用](GETTING_STARTED.md)。

## 模組與 Prompt

左側是模組，中間是該模組的素材，右側是目前組合與最終 Prompt。模組可設為單選或複選；素材可填名稱、實際提示詞、別名、備註及預覽圖。

在素材或組合上按右鍵，可以編輯、複製或取消選取。上方搜尋框可搜尋已有素材，也可加入尚未保存的臨時片段。

右側組合順序獨立保存，拖動群組不會改變左側素材庫順序。同一群組內的素材也能排序。新加入的群組依左側位置插入，既有群組保留手動順序。權重及排除 Tag 會反映到自動組合結果；停用或排除不會刪除素材原文。

直接修改最終 Prompt 會進入手動版本。此時保留你輸入的文字；要重新採用自動組合，按「清除內容」。確認清除後，已選模組與臨時片段仍在。使用「存入素材庫」可保存這次輸出。

## 工作區

左上角切換工作區，旁邊「⋯」提供新增、設定與刪除。工作區可保存固定模組、模型與 LoRA 建議、權重、Seed 及採樣參數。

只有勾選「以目前選擇更新固定組合」並儲存，才更新固定選擇。切換工作區時還原固定模組，其他選取、臨時片段與手動稿保留。參數歷史可帶回編輯後另存一版。

這份公開版本中的模型與採樣參數屬於建議值。ComfyUI 實際生成以工作流為準，擴充更新明確綁定的文字欄；Prompt 中的 LoRA 文字不會自動建立 LoRA Loader。

## Tag 候選

英文候選可查詢 Danbooru，輸入 `@` 前綴查找繪師名稱。方向鍵選候選，Enter／Tab 接受，Esc 關閉。中文可先使用「設定 → 個人字典」，例如 `白色的牆壁 = white wall`。

聯網候選可關閉；程式會保留本地候選紀錄。任意中文長句尚不會自動轉成已驗證 Tag。Google Cloud Translation 選項需自行準備 API 金鑰與服務，真實金鑰端到端流程尚未驗證；金鑰只保留於當次記憶體。詳細聯網範圍見 [資料與隱私](DATA_AND_PRIVACY.md)。

## 模型管理

選擇 ComfyUI 的 `models` 根目錄，掃描 `loras`、`checkpoints`、`diffusion_models`、`unet` 及其子資料夾。掃描讀取檔案資訊，不載入模型權重。

每個模型可保存名稱、分類、觸發詞、網址、備註及預覽。匯入模型會複製已下載的檔案，保留來源且不覆寫同名檔。外部新增或移動模型後，按「重新掃描」。

「移至資源回收筒」會操作實際模型檔案，確認視窗會顯示路徑；失敗時不改用永久刪除。模型移走後仍保留說明與預覽，可在還原檔案後重新掃描。

## 圖片庫與最近生成

圖片庫可建立相簿、加入多張圖片或匯入磁碟資料夾本層的圖片。預設連結原圖並建立縮圖；勾選另存副本才把原圖複製到應用資料內。移除圖片紀錄不刪外部原圖，原圖移動後可以重新連結。

選取 PNG 時可查看已內嵌的 Prompt、Workflow 及可辨識的參數。多個文字節點、採樣器會分開顯示，自訂節點或間接連線不保證解析。JPG／WebP 可預覽，這份公開程式尚未解析其 EXIF 生成參數。

手動「附上目前工作區資料」會另外保存當下建議，與圖片實際內嵌資料分開。含模組快照的圖片可恢復歷史組合；程式會先備份目前狀態，歷史素材不覆蓋現有素材。

「最近生成」在 ComfyUI 連線後提供結果預覽與收藏。收藏前先選目的地；未收藏結果仍依賴 ComfyUI 的 output／temp 原檔。詳見 [ComfyUI 整合](../COMFYUI_GUIDE.md)。

## 外觀與快捷鍵

設定可調字型、字級、間距、配色及 Windows 視窗材質。效果受作業系統與透明設定影響；希望減少視覺效果時可選實色。

- `Ctrl+F`：搜尋。
- `Ctrl+,`：開啟設定。
- `Ctrl+↑`／`Ctrl+↓`：在支援的組合項目上調整順序。

`Ctrl+Shift+C` 與右側主要按鈕共用操作：未就緒時複製 Prompt，ComfyUI 桌面控制就緒時會送出生成。已連線時請以介面顯示的「運行」狀態判斷，勿把此鍵當成固定的複製快捷鍵。
