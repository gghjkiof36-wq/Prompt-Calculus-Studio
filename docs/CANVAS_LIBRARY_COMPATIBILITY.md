# Canvas 匯入 Prompt 管理頁

此修正版讓 Canvas 文件保存「已匯入但尚未放到畫布」的素材。匯入是獨立副本，
不修改來源 `.pcs-category`；附件先驗證再複製，整次匯入只有一筆復原紀錄，
並使用原有自動儲存流程。匯入不改 Prompt 草稿、輸出順序、生成綁定或畫布位置。

`.pcs-workflow` 的 `payload.state.library_categories` 保存匯入分類 ID。
文件投影保留這些分類及素材，避免未使用素材在儲存時被依賴裁剪移除。
該欄位存在時，外層 `required_features` 必須包含 `pcs.canvas-library.v1`；
已知標記和欄位不一致、未知必要語義皆拒絕載入，保留原件。

沒有使用這項功能的既有文件不增加此欄位或標記，維持原格式。
較舊的讀取器會拒絕帶有新必要語義的文件，不會默默刪除匯入素材。
生成快照只保存生成所需素材；完整備份仍保留整份文件及其附件。
分類及素材 ID 沿用現有文件複製規則；管理頁匯入時重新分配其擁有的 ID。

驗證涵蓋匯入、附件失敗的原子性、來源隔離、復原／重做、儲存與重新載入、
必要語義標記、既有文件相容，以及 Qt-free 共用程式封裝。
