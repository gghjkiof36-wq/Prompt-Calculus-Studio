# 舊 Stage 快照還原與視窗生命週期維護

適用於 0.8.9 第一階段開發來源，基於公開 0.8.8 Alpha 1；不是已發布 0.8.8 成品的新驗證聲明。資料契約見 [資料與相容性](data-compatibility.md)。

## 舊 Stage 投影

0.8.8 發布前的一種 Stage 快照保存了實際提交的 Canvas 內容，卻同時保留 Reader 派生快取標記。Stage 投影原本就不保存上游 Reader 及其接線；載入時物化程序因而把這些凍結內容當成斷線快取移除，最後的文字一致性檢查拒絕還原。

還原邊界現在辨識這種格式 7 的自包含 Stage 投影：單一 Stage、同工作流的 CLIP 綁定、連續 Stage 文字輸出、精確的 Canvas → 輸出 → CLIP 接線、沒有 Reader／圖片來源／排程或執行暫存，並核對派生 ID 與保存的簽章、索引及成員順序。原始快照必須先通過完整驗證。含來源錯誤、未支持的 raw 文字覆寫、失配 ID 或一般斷線文件都不套用轉換。

只有通過上述條件的副本，才將凍結 Canvas 的派生快取標記轉成普通已保存成員；根內的來源參照、序列、輪次及已存在的游標不清空。轉換前後及最終還原後核對全部輸出的生成文字、實際文字與手動稿狀態，包含非目前輸出及空字串。原圖不改，仍沿原入口建立新的圖片工作區，不派送任務。

可恢復範圍是 PNG 實際保存的內容與配置。未寫入的 Reader 定義、完整工作流上游關係、排程 journal 和剩餘執行進度無法由圖片補造；此相容處理不是整個生成工作階段的復原。新生成快照的最小必要投影與完整私人備份規則保持。

固定合成反例由 `0252a0391381c98e3dc263fccdf7ce3011154b9b` 的實際 BoundScheduler 產生，保存在 `tests/fixtures/legacy_stage_snapshot_088.json`，SHA256 為 `3e135623131259d7cc796a1b74c04a79985e972bec0dcc3879c6256fac1a7c82`。`test_legacy_stage_snapshot.py` 保護原值、雙輸出、空稿、拒絕條件、保存重開及原件不變；`test_stage_snapshot_privacy.py` 等持續驗證新生成資料的隱私與還原。

## Reader 延遲布局

Reader 的兩處零延遲排版回呼附上所屬對話框的 QObject context。強制處理 DeferredDelete 時，Qt 可取消已銷毀對話框的待執行回呼，避免再存取 PageStack。正常關窗、布局與套用操作沿原流程；未修改共用視窗處置、UI 布局或資料格式。

`test_reader_lifecycle.py` 分開正常 modal 編輯與立即／延遲關窗、套用與 Undo／Redo、強制先刪除再處理事件。強制處置反例的修復，不代表另一起原生退出事件已找到原因。

## 維護後的驗證契約

- 分類標題按完整資料夾路徑驗證，身分、內容、Undo／Redo 與重開另有斷言。
- 工作區歷史允許活動 scene 的重複 view 快取省略；頂層真實檢視、所有內容、非活動 scene 及保存結果必須保持。
- 文件 4 的升級與現行格式 7 往返分開驗證，資料庫在失敗時也關閉，原始備份保持。
- 幾何只允許有限的 DPI 四捨五入與樣式邊距；原生框不移動、子框不累積漂移、清單可見且完整、按鈕與內容不裁切的檢查仍在。
- 舊清單草稿經現行素材庫選單讀回，保留手動空稿、Canvas 草稿及原文件。

這些是限定來源回歸，不構成全庫、所有原生環境、真 ComfyUI 或 GPU 驗收。
