# 技術債與維護注意事項

適用：0.8.6 Alpha 1 主分支。這裡列出程式仍保留的限制與維護時需要核對的邊界。

| 項目 | 現行處理 | 修改時的驗證重點 |
|---|---|---|
| 搜尋取消 | urllib 查詢以 timeout 結束；取消及工作身分阻止過期結果回寫 | 取消後不顯示舊結果、不把取消誤報為成功 |
| 模型識別快取 | size／mtime 減少重複 Hash；下載仍核對檔案 Hash | 快取不是防範刻意保留 metadata 的竄改機制 |
| Prompt 刷新範圍 | 範圍協調器合併通知；未細分呼叫仍走原路徑 | 調整範圍須覆核手動稿、生成及 Undo／Redo |
| 歷史建置旗標 | 共用當前建置器保留舊旗標映射 | 選舊旗標不等於還原當年的完整來源；重建歷史版本使用固定標籤 |

0.8.1 時已完成的維護與當時檢查結果見[歷史審查](../archive/0.8.1/technical-debt-2026-09-14.md)。
