# 文件關閉與本機恢復

分頁關閉或切換文件時先完成已開始的文字插入與輸入法組字，再儲存目前文件。一般儲存失敗會保留已落盤的本機恢復副本並允許離開；若兩個恢復位置皆不可寫，保留編輯頁。原檔消失的特殊情況見下節。

## 原檔消失時先保留可編輯頁

原檔被外部刪除或移出原位置後，`CloseRecovery.prepare_close` 在保存副本後核對來源仍為檔案；來源缺失且仍有待保存內容時，保留目前編輯器與 Undo，提示使用 Ctrl+Shift+S 另存後再關閉。即使已有重啟後的恢復入口，仍優先保留當前編輯環境，不另開確認視窗，也不自動復建原路徑。

另存沿用原 writer 與身分／引用流程，成功後清除對應恢復副本並可正常關閉。一般原檔存在但寫入失敗的恢復機制、明確捨棄操作及本來就無編輯內容的缺檔佔位頁不變。

## 重啟後從缺檔恢復稿另存

重開後若原分頁仍在布局中，`MissingDocument` 在文件頁內顯示名稱、儲存位置、「另存新檔」和「重試」，不額外加入說明段落。舊分頁已關閉、布局不再記錄它時，首頁的「未儲存的內容」提供被動入口；只有本工作區有相符的缺檔恢復紀錄才顯示，不自動追加分頁或執行恢復。沒有恢復稿時仍只有「重試」。錯誤在頁內顯示，沒有獨立恢復視窗。

`workspace_recovery_export` 重新讀取磁碟副本並驗證原位置、種類及內容，再用既有排他 writer 建立新檔；拒絕原路徑，重名自動加 `(n)`。Markdown 同資料夾保留原始 bytes，包括 BOM、換行與空稿；移到其他位置時沿用既有引用改寫及位置驗證。原生分類及工作流沿 `document_projection` 共用投影，建立新的文件與內容身分，保留附件但不接管舊執行紀錄或重送生成。

恢復寫入的回執包含預期檔案摘要與當時磁碟恢復稿摘要；開啟前後都驗證，確認所有同原件的缺檔視圖已轉為同一新文件後才清理原恢復稿。新檔已寫入但開啟失敗時，只重試開啟該檔，不自動再輸出一份。寫入後結果不確定、目的檔被換掉或恢復稿被另一個 writer 更新時，保留原紀錄；可明確選擇「另存另一份」。`SaveResult.published` 只表示該次排他建立是否曾完成，不是持久格式或允許重試的指令。

恢復回執目前限於當次程序。若整個程式在建立新檔後、完成開啟前中斷，重啟仍保有原恢復稿，但再次另存可能產生編號副本。恢復不是完整備份：Markdown cache 不包含已遺失的外部圖片附件；原生素材尚未確認的獨立表單草稿仍留在原 runtime，不會直接轉移到新文件身分。舊 runtime、原件及其他恢復紀錄均不刪除。

## 儲存責任

- `CloseRecovery` 保存文件的未寫入內容。Markdown 包含原編碼、換行與原檔雜湊；可攜文件包含編輯狀態、原始基準與身分映射。副本不覆寫原件。
- `DraftCache` 共用 JSON 與原子替換機制，主位置在隔離資料目錄的 `recovery/`；主位置失敗才寫入系統暫存目錄中按資料目錄區分的副本。兩處均不可寫時只保有當次記憶體內容，不能保證重啟恢復。
- 成功儲存或另存後移除相應副本。載入恢復副本時驗證版本與結構，狀態轉換使用 `state_loading.prepare_state`，不在 UI 刷新時重複轉換。
- Markdown 原檔若已被其他程式改動，恢復編輯內容但停止自動覆寫；重複關閉及重開仍保留最初原檔雜湊。可攜文件遇到原件變更時保留恢復紀錄及原件，不直接套用衝突狀態。
- 分頁配置寫入失敗也有本機副本；正常寫入成功後清除。恢復編輯內容不等於恢復應用重啟前的整組原生 Undo 歷史。

## 編輯介面

素材編輯視窗可用外側點擊、Esc 或關閉圖示離開。未確認的表單留作該素材的草稿，下次開啟同一素材再恢復；「保存」提交內容，「捨棄修改」清除草稿。只開啟查看並關閉不製造修改。管理頁排序與收合偏好屬本機設定，不使可攜素材內容變髒。

模型詳細資料採同一個可離開的視窗，個人資料變動自動保存。寫入失敗保留草稿，關閉後可重試；更新縮圖不覆蓋背景辨識剛更新的來源欄位。資料頁只讓觸發詞與備註內部捲動，欄名置於文字欄上方，複製圖示使用目前編輯中的觸發詞。來源及檔案資訊合併在第二頁；此處不再提供舊版臨時片段的「加入組合」。預覽上方 2/3 整區更換、下方 1/3 整區移除，沒有圖片時整區新增；拖放沿用圖片匯入入口。

本機恢復副本可能含私人文字及路徑，不是公開交付材料。此機制不更改可攜文件 schema，也不取消仍在進行的檔案作業、背景下載或外部生成的既有生命週期保護。

## 驗證入口

`test_workspace_close_recovery` 涵蓋無修改關閉、保存失敗後重開、外改衝突、未確認素材草稿、群組／空變體與不支援版本。`test_workspace_file_operations` 保留另存／移動、原件與 Undo 檢查，並驗證寫入失敗後可離開及恢復。`test_workspace_file_interactions` 核對缺檔後的實際 Canvas／Markdown 編輯、磁碟副本、共享視圖、Undo／Redo、另存及明確捨棄。`test_explore_model_layout` 涵蓋模型欄位保存、失敗重試、預覽失敗不彈阻擋視窗，以及大字體與窄視窗欄位可達。

`test_workspace_recovery_export` 驗證磁碟讀回、Markdown bytes、原生身分／附件、重名競態、已發布後錯誤與內容摘要。`test_workspace_missing_recovery` 透過實際工作區操作頁內另存、多分區、開啟失敗重試、外改保護及獨立程序重啟。`test_workspace_recovery_inventory` 驗證首頁孤立紀錄入口的範圍、去重與安全讀取。
