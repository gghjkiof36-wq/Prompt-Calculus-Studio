# 本機工作環境：層級與後續渲染

2026-10-17。使用者已確認本輪面板分區方向，並指定後續以卡片、霧面玻璃與層級為主。以下是下一輪的設計判斷及驗證安排，不是已交付的完整深度系統，也不自動擴大產品階段。

## 讓深度說明關係

| 表面 | 本輪／後續處理 | 理由 |
| --- | --- | --- |
| 最外框、頂列與入口列 | 共用原生材質，維持連續 | 形成同一個應用外殼 |
| 固定側欄與內容 | 實底、色階、局部細接縫；不加懸浮陰影 | 它們是並列工作區，不應看起來漂浮 |
| Canvas 卡片 | 保留現有卡片表面；後續按靜止、選中、拖曳分配深度 | 選中主要靠邊界與操作狀態，拖曳才需要更強離地感 |
| 選單、預覽、對話框 | 後續用適量遮蔽與陰影區隔，必要時局部霧面 | 讓使用者清楚知道哪一層接受操作 |

先穩定色階，再調陰影。亮色與深色不共用相同陰影濃度；深色界面常需要更細的邊緣反射，亮色則更容易看出陰影。不能用一圈明亮輪廓取代所有層次，也不能把每張卡片都畫成同樣高度。

## 渲染要守住的邊界

- 原生 Mica／Acrylic 留在 Windows 視窗底層；不替每個 Canvas 節點建立獨立背景模糊。文字與輸入欄維持穩定、可讀的表面，避免多層透明相乘後失去對比。
- 整體內嵌表面的圓角與子視圖裁切由共同容器處理。側欄內緣平直；外側圓角、遮罩和接縫共用幾何。陰影需要延伸的浮動層須放在合適的上層，不能一邊裁切一邊補畫假圓角。
- Canvas 縮放時區分場景尺寸與螢幕像素。細線與陰影擴張不能讓圖示點擊區、連接埠或文字偏移；節點的繪製邊界要包含真正的陰影範圍，避免移動後殘影。
- 若採用陰影快取，依尺寸、圓角、配色、顯示比例及深度分級失效；文字與互動控制仍原生繪製。避免每次平移重建模糊，也避免對整個 Canvas 套用大範圍效果。
- 材質切換、顯示比例變更、跨螢幕移動、最大化／還原與暫時失焦都要看過。失去原生材質時回落實底，不降低整窗透明度。

## 下一輪如何判定值得保留

使用相同文件、節點數、視窗尺寸與桌面背景，比較現有版與深度方案。檢視 125%／150%、深／淺色、實色／Mica／Acrylic，以及正常、收合、窄窗、最大化。操作時看平移、縮放、拖曳、選單開合與文字輸入，量測畫面耗時、記憶體及長尾卡頓。

本輪已完成原生材質／輪廓與配色操作檢查；尚未為上述未實作的陰影系統提供效能數字。未來只有在層級更容易理解、文字仍可讀，而且操作耗時沒有不可接受的退步時才採用。
