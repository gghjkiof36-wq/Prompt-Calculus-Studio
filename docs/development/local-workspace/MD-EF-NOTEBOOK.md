# Markdown 筆記管理與復原（E／F）

E／F 在既有文件工作區加入筆記搜尋、整理、復原與進階編輯。新增功能集中在原有側欄和命令入口；文件工具列、可編輯檔名、卡片大綱、黃色搜尋命中及空白文件保持既有設計。

這是本機試用功能，並非整個 1-1 的最終驗收。尤其接近 8 MiB、含大量短段落的文件仍會造成明顯延遲；實體中文輸入法、不同 Windows DPI 與大型真實資料庫也不能由背景測試代替。

## 找到與管理筆記

側欄標題可切換「內容、搜尋、標籤、屬性、連結、腳註、書籤」。它們共用側欄，不新增常駐按鈕列。`Ctrl+Shift+F` 搜尋目前資料根；原有快開仍可依檔名／路徑尋找，沒有符合項目時可建立筆記。

- 全文搜尋支援引號詞組、空格 AND、`OR`、`-` 排除、括號，以及 `file:`、`path:`、`content:`、`tag:`、`match-case:`、`ignore-case:`。屬性使用 `[status:draft]`、`[count:>3]` 等條件。這不是 Obsidian 所有搜尋運算子的完整相容層；正規表示式及 task／section／block 運算子未提供。
- 標籤以層級整理；屬性可查看目前筆記及資料根的使用情況。筆記連結分為反向連結、未連結提及及連出連結。結果能開啟位置或預覽筆記，腳註清單可定位引用與定義。
- 書籤可保存筆記、目前標題或搜尋條件；每個資料根分開保存。搜尋結果最多呈現 500 筆，避免一次建立過多介面列。
- 索引在背景執行，接受目前未保存稿件作為查詢內容；取消的舊工作不能覆蓋新查詢。側欄更新會保留展開狀態、選取及捲動，重複引用也維持原選取的次序。
- 索引不寫正文，不讀取 `.obsidian`，沿用既有根目錄與檔案系統連結防護。複數資料根可在側欄選擇範圍。

## 建立、範本與整理

`Ctrl+Shift+P` 開啟文件命令；「新增筆記、開啟今日筆記、新增不重複筆記、開啟隨機筆記、插入範本、範本與日誌設定」都有實際操作入口。斜線命令可在進階編輯中停用。

範本支援 `{{title}}`、`{{date}}`、`{{time}}` 及日期時間格式。插入時只合併缺少的 YAML 屬性，既有屬性及未知複合值保持；正文插入目前選取位置，可一次 Undo。每日筆記可設定資料夾、日期檔名及範本；已存在時開啟原檔，時間命名筆記遇重名會改用未占用的名稱。

「合併目前筆記」與「擷取選取內容」先顯示目的、位置及內容預覽。提交前重新核對來源與目的地；開啟後內容已變更時拒絕套用過期草稿。合併保留來源副本並協調引用；擷取產生新筆記及來源引用。相對附件與連結隨目的位置調整，無關原文、BOM、換行及未保存稿件保留。

「復原上次筆記整理」會核對整組操作後的檔案，再回復原來的來源、目的與引用。一般寫入／buffer 更新失敗會回復本次已套用的變更；復原失敗則回復到復原前狀態，避免只還原一半。紀錄保存在本版資料目錄。這個入口作用於本次執行的最後一次整理，並不等同斷電後自動重播任意交易；復原版本另由下述功能提供。

## 版本與布局

「檔案復原」可選擇本機版本、比較差異、查看完整原稿及還原。開啟文件時保留基準，保存後有改動才記錄版本，通常以五分鐘間隔去重；保留七天及各檔最新版本，單檔最多 200 筆。版本以完整原始位元組壓縮保存並檢查雜湊，大小限制保持 8 MiB。

還原前保留目前稿件。仍開啟的文件透過共用編輯交易還原，可以一次 Undo；外改或版本損壞不能靜默覆寫。差異的新增／刪除在深淺主題有各自文字色，完整原稿不誤套差異著色。

「工作區布局」可命名保存、覆蓋、載入、刪除分頁與分割配置，沿用既有最新布局還原。保存／覆蓋／刪除可在對話框中復原；未選擇或名稱空白時，對應操作不可用。切換布局不把視圖快照當作正文，既有未保存稿件與遺失文件的恢復保護保持。

## 進階編輯

- `Ctrl+D` 依序增加相同文字的選取；`Ctrl+Alt+↑/↓` 增加上下游標；Alt 點擊增加游標；Alt+Shift 拖曳為矩形選取。一次輸入或刪除是一筆共用 Undo，UTF-16 位置與 emoji 會換算；開始輸入法組字時退出多游標。
- Vim 鍵位預設關閉。提供 normal／insert、基本移動、單字／行操作、選取及 Undo；它是基礎鍵位模式，不是完整 Vim／外掛或 Ex 指令相容層。
- 英文拼字檢查預設關閉。使用封裝在本機的字典，右鍵可採用建議或加入個人字典；不傳送文字、不下載字典，也不宣稱提供中文文法校對。檢查採延遲及可見範圍預算，格式重繪不重複啟動整份檢查。
- 「編輯快捷鍵」可調整搜尋、取代、編輯／開啟連結、屬性、命令、工具列七項文件操作。禁止重複、工作區保留鍵或普通輸入鍵；設定只套用文件操作，不攔走其他頁面的編輯。

## PDF

「匯出 PDF」使用目前稿件的獨立閱讀投影，輸出白紙深字、A4 及 16mm 邊距。輸出前等待字體、圖片、公式與 Mermaid 完成，展開折疊內容，並保留表格及腳註。缺少資源、載入失敗或超時會明確失敗，不把不完整輸出冒作成功。

先產生完整 PDF，再比較目的檔案是否已被外部變更並安全寫入；不改 MD，不覆寫匯出期間被他人修改的目的檔。遠端資源仍遵守原有載入限制。

## 效能與驗證邊界

編寫區使用可見段落排版，保留既有字體、行距、段落對齊、縮排及折疊。格式、高光與左側標記只處理畫面附近；收合長章節時跳過隱藏內容，後面的標題與勾選框仍能顯示和點擊。大綱關閉時不建立整份樹，打開後才載入。格式延遲不改變保存內容與 Undo。

搜尋結果按內容版本快取，統一換算 UTF-16 位置，避免每筆結果重新掃描全文；大量命中只繪製可見部分，總數、上一筆／下一筆與取代仍包含全部結果。黃色背景、深色文字及清除搜尋後的普通選取各自保持。工具列陰影收在容器範圍內，避免邊緣裁切。

大綱的選取與滑過底色由整列統一繪製，涵蓋各層縮排，避免 Windows 在箭頭旁疊加直線記號或方塊；滑鼠收合、鍵盤展開及標題定位保持。

大稿件的詞數計算由共用內容在背景合併處理，舊結果不能覆蓋新稿件；計算期間先顯示準確字元數。閱讀投影在內容、路徑或顯示設定沒有變動時重用。大型文件使用既有本機閱讀渲染器，不再建立隱藏的第二份原生富文字排版；一般文字重用編寫區已解析的段落資料。上述改動改善重複計算，首次載入仍需處理整份稿件。

同一份閱讀投影中，重複引用的圖片共用路徑解析與圖片檔頭檢查，保留各次引用的名稱和顯示尺寸；每次重新產生投影都重新核對資源，不跨更新沿用舊路徑或圖片狀態。

測試使用合成資料，涵蓋查詢、索引更新、範本、原文保持、原始位元組復原、整理失敗的原子回復、多游標與組字事件、矩形選取、個人字典、布局及 PDF 的實際輸出。相關測試為 `test_notebook_core.py`、`test_notebook_workspace.py`、`test_markdown_large.py`、`test_markdown_performance.py`、`test_markdown_pdf.py`，並回歸既有 Markdown、檔案操作、共用視圖、自動保存及布局。

接近容量上限的散文與極高段落數文件分開測量；後者的開啟、排版及輸入仍會阻塞。現階段不能把長文件優化記作 M18 全面通過。實際測量、固定來源版本、試用入口及原生操作證據由同次本機交付紀錄保存；測試數量與圖片不代替使用者接受。
