# P2：本機分頁檢視入口

這是單區、本機編輯的開發入口。全寬頂層分頁列在所有入口常駐；只有首頁的文件會建立分頁。媒體庫、探索、匯出與設定直接切換整個工作區及各自側欄。點任何文件分頁都回到首頁、顯示原文件與內容側欄，未保存修改及原生 Undo 保留。

依使用者本輪檢視修正：分頁文字靠左、與導航間留白，少量分頁寬 228 邏輯像素，多頁逐漸縮至 124 後溢位；選中頁籤的上圓角與底部外展曲線接到頁面。側欄開關、上一頁／下一頁移到分頁左側，與分頁及右側 ComfyUI 燈號共用唯一頂列。側欄開關中心對齊最外側入口圖示，文件完整路徑留在分頁提示。全域入口在左側圖示列。第二列導航、舊工作流／模式橫列、功能頁左上重複名稱、返回工作區與保存工具列已移除。

功能頁不把任何文件畫為當前內容，但所有入口保留分頁，仍能點擊此前選中的同一頁籤回到文件。這是本輪最後確認的操作方式。

## 啟動與資料

`run_workspace.py --root <文件根> --data <獨立工作資料>` 必須明確提供兩個位置，不採用正式使用者資料目錄。`--check` 只讀取文件與檢查 Qt 可載入性，不開 UI，也不寫入檢視資料。正常啟動使用 `QLockFile` 避免同一個 data 被兩個檢視程序同時開啟。

可在 Windows 以 `tools/build_local_workspace_preview.py --out <全新輸出目錄> --vendor <PySide6 依賴目錄>` 建立 BAT、合成分類／工作流／Markdown、獨立 data 與來源紀錄。輸出存在時拒絕重建，避免清掉檢視者的修改。BAT 使用目前 checkout 的 Python 原始碼，並非可獨立搬移的正式 EXE；不會替換原程式或加入永久的新舊模式按鈕。

固定提交後可使用 `--refresh-launcher` 更新同一 checkout 的啟動檔與來源紀錄；此操作保留所有檢視文件與 data。

## 文件與視圖的邊界

- `WorkspaceShell` 管理分頁、內容樹、視圖生命週期與側欄；其 state 僅含外觀，不裝載任一文件的全域 current state。
- `DesktopDocument` 各自持有文件 ID、讀取 receipt、dirty、保存結果及隔離工作目錄。每份已開文件只有一個可寫 host；同一實體檔案的別名聚焦原頁，另一位置的同 ID 文件拒絕形成第二個 writer。
- `EmbeddedHost` 重用既有 `Window` 的編輯、Canvas、原生 QTextDocument、Undo／Redo 與交易。在整個開頁期間不更換其文件 state 或 SQLite。分頁切換只顯示既有 widget；不重新建立文字 document。
- 文件 host 不再建立未使用的設定／探索介面，並繼承 shell 樣式，避免重複建立及重新套用大量隱藏元件。完整工具頁僅在第一次進入功能入口時建立一份。
- 可攜附件從已驗證 manifest 複製至工作目錄的邏輯位置及實體位置：舊 UI 依邏輯名讀圖，文件 writer 依 manifest 驗證。刪掉預覽引用只移除新文件的 manifest 項目，不刪原附件。
- 原生編輯對話框的「保存」提交素材交易，Ctrl+S／分頁選單「保存文件」才寫回 `.pcs-category`／`.pcs-workflow`。表單名稱、備註、預覽、變體等使用共同 `draftChanged` 訊號。關頁選保存時先完成尚開啟的素材對話框交易。
- 外改衝突或寫入失敗保持 dirty，提供目前檔案與候選回復檔的只讀檢視。關閉取消不移除頁面；關閉整個視窗先處理所有文件的決定，取消時保留全部頁籤。

## 操作

普通單擊重用一個乾淨的瀏覽頁；斜體表示瀏覽頁。雙擊、開始編輯、明確另開會保留頁面。一般點擊同一文件聚焦原頁。`＋`／Ctrl+T 開保留的新分頁，Ctrl+W 關頁，Ctrl+S 保存目前文件，Alt+Left／Right 返回或前進。功能頁 Ctrl+W 不會關閉藏在首頁的未保存文件。頁籤可重排，空間不足時單列捲動與清單仍可操作。

保存、復原／重做與錯誤回復仍可從分頁右鍵選單進入；依使用者要求移除它們的常駐工具列。未保存使用頁籤星號表示；保存錯誤會顯示說明、保留 dirty，詳情也在頁籤提示中。關閉仍有保存／捨棄／取消。

分類頁保留原搜尋、三類素材篩選、釘選、排序、預覽、變體、新增、編輯與取消。內容樹只列分類文件、工作流文件、Markdown 與資料夾，不列每個素材。統一側欄寬度、列高、標題與單一選中背景，功能入口替換首頁側欄。

五個入口共用側欄拖曳邊界：220～480 邏輯像素、預設 264；窄視窗保留至少 380 像素內容空間。往左縮到 220 先停住，繼續超過 36 像素才收合；再展開恢復該次拖曳前寬度，鍵盤左右鍵只調整寬度。寬度與展開偏好保存於隔離 data/workspace-ui.json。

預設介面字級調為 10 pt，頂端／最外側圖示 16 邏輯像素，內容樹圖示 15 像素；原按鈕點擊範圍保留，已保存的字級優先。共用側欄左上、右上與左下使用 10 像素圓角。

設定 → 介面個人化 → 閱讀與顯示的介面字級（9～22 pt）同步到首頁內容樹與外層介面，不另設一個側欄字級。字型、介面／提示詞字級、視窗材質與透明度共用上述 UI 偏好檔，重啟保留；不改文件內容或文件 settings。最外側入口列與頂端背景重用原生 Mica／Acrylic 及既有遮罩透明度；選中分頁、內容側欄、文件和可操作控制維持可讀實色。平台不支援材質時回落實色，不以整窗 opacity 讓文字透底。

探索頁保留原本 ComfyUI／CivitAI 的圖像卡片與開啟入口；使用者所述未來 Obsidian 沿用同一套卡片，本輪沒有新增或連接 Obsidian。內容樹以連續整列底色表示選取，移除縮排處重複的藍線。分頁的原生關閉按鈕及點擊範圍依最後繪製位置對齊，距分頁矩形右緣 14 邏輯像素，位於外展曲線內側；縮窄及捲動沿用同一定位。

新分頁以置中的固定閱讀寬度呈現：上方列出真正最近開啟的最多五份文件，下方為新增 Canvas 工作流、管理頁（文字模塊）、Markdown 筆記，另提供開啟既有文件。最近紀錄寫入隔離 data/recent-files.json；不是根目錄所有檔案。短視窗可捲動，不把按鈕推到畫面外。

三種新增皆寫入真正文件，不覆蓋同名檔。Markdown 提供 UTF-8 編輯、原生 Undo／Redo、保存與關閉取消；保留原 BOM／CRLF、空檔有效，8 MiB 上限，外改衝突阻擋覆寫並保留編輯內容。這是為本輪新增入口提供可用流程，不是完整 Markdown 預覽或外部監看階段。

## 本階段限制

這個入口只供本機編輯。`LocalEditingClient` 阻止實際連線與派送，沿用既有離線引擎狀態；它不是第二個執行引擎。媒體庫、探索、匯出、設定可從左側進入，但共用 AppServices、跨文件任務路由與全域設定整合仍待後續階段。

文件關閉／程式重啟後不還原整組頁籤或承諾完整原生 Undo。每次開啟的隔離 SQLite 留在 data/sessions；其長期 history／索引歸屬由後續儲存整合承接。本輪不提供檔案搬移／回收、左右雙區、Markdown 預覽或外部監看，也不匯入正式舊資料。不能把本次必要的新建／MD 編輯視為整個 P3～P6 已完成。

## 可重複的驗證

`tests/test_workspace_shell.py` 以真 Qt 視窗檢查預覽重用、保存目標、編輯取消、dirty 關頁、整窗取消、附件、衝突回復、同檔別名、原生文字物件、工作流 Undo 與窄視窗分頁。`tools/check_local_workspace_ui.py --root <合成根> --out <全新證據目錄>` 先複製合成文件，再實際操作素材／變體與 Canvas 對話框並截圖，結果不寫入供人檢視的來源樣本。

UI 自驗、獨立需求核對、真 ComfyUI／GPU 執行與正式發布是不同結果。測試紀錄必須標明來源提交、平台、比例、受影響範圍及原已存在的失敗，不以通過數量取代使用者檢視。
