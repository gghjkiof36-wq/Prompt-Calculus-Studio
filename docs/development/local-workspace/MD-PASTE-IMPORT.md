# Markdown 貼上與對話匯入：保存及驗證契約

此功能接續本機分頁工作區，尚未宣告公開版本交付。使用方式見 [操作說明](../../guide/markdown-import.md)。底層 `SourceBuffer`、原文切片、共用 Undo、保存收據及目錄固定機制沿用既有實作，不新增筆記資料庫或修改 Canvas 格式。

## 格式與操作邊界

| 項目 | 決定 |
| --- | --- |
| 貼上優先序 | `text/markdown`、`text/x-markdown` → HTML → 純文字；只有圖片的剪貼簿沿用附件保存 |
| HTML 轉換 | 有界樹形轉換，8 MiB 輸入／輸出、100,000 元素、128 層；不執行或取得資源 |
| 大型貼上 | 超過 128 Ki 字元的 HTML 在背景準備，回到捕獲的文件／修訂／選取套用一筆交易 |
| 修訂已變 | 不覆蓋新內容；顯示重新貼上提示。回呼不切走目前文件的鍵盤焦點 |
| 支援匯出 | 單對話 JSON、對話陣列、含 conversations 陣列的物件；ZIP 內 conversations 與編號分段 JSON |
| 訊息關係 | 驗證 parent／children／識別／循環；依每個葉節點產生完整根到葉路徑。來源 current_node 只作標記 |
| 原始資料 | 保存所選對話物件的全部欄位；重新序列化 JSON，不主張位元組相同。來源封存不改 |
| 重複／更新 | 來源識別＋對話內容及附件雜湊；相同則略過，更新另建資料夾，既有手改 MD 不覆蓋 |
| 附件 | 只用明確 pointer／附件欄位／檔名配對；含糊或缺失留下說明；未知可執行類型保存為 `.bin` |
| 預覽 | 有界、唯讀、離線，禁止資源與連結載入；切分支不改勾選 |
| 所有權 | 單工作區一個匯入視窗；工作開始時固定來源、目的位置及欄位；關閉等待取消確認 |

`markdown_html`、`markdown_table_cells` 是無 Qt 的轉換工具。表格編輯與貼上共用相同儲存格編碼；`markdown_paste` 只選 MIME。匯出讀取、Markdown 產生、目錄保存、視窗互動各有一個來源，避免預覽或不同分頁各自實作保存規則。

## 保存及恢復

來源使用只讀 handle，Windows share 規則拒絕原地修改；開啟及寫入前核對識別／SHA256，完成前再次核對來源識別。來源與目的資料夾的完整鏈經既有 `pinned_parent` 固定，拒絕重解析點；ZIP 名稱先驗證原始與正規化形式，拒絕越界、碰撞、連結與加密項目。

每段對話建立獨立目錄及開始紀錄，所有 payload 以 exclusive create 寫入並 flush／fsync，最後才寫完成紀錄。這是「逐對話完成紀錄」，不是整個資料夾的原子 rename。崩潰、磁碟失敗或取消可能留下部分目錄；只有有效完成紀錄才可被略過。重試另建目錄，不遞迴清除失敗現場；完成項、略過、未完成、未處理各自呈現。

來源 ≤256 MiB；ZIP ≤20,000 項、單項 ≤256 MiB、展開 ≤512 MiB；≤10,000 對話、合計 ≤100,000 節點；每段 ≤2,048 分支、根到葉合計 ≤2,000,000 步；輸出 ≤512 MiB。JSON 另有 500,000 物件上限。超額不裁切；MD 分卷目標 ≤7 MiB，仍受原有 8 MiB 硬上限保護。

| V-A03 交付 | 操作說明、本契約、固定來源／BAT 與交付紀錄 |

## 設計參考與限制

採用先預覽再確認、選擇性本機匯入、每段獨立筆記與明確格式退路。[Obsidian 的 Notion 匯入說明](https://obsidian.md/help/import/notion)提供匯入前檢視及 ZIP 路徑的參考；[Joplin 匯入說明](https://joplinapp.org/help/apps/import_export/)說明一般格式轉換與複雜內容的差異。本實作仍使用 PCS 的共用視窗、顏色、按鈕及文件行為。

真實 ChatGPT 帳號匯出、不同歷史格式、未知音訊／影片編碼、非本機 NTFS 等環境尚未全面驗證。JSON 解碼及最終 Qt 文本排版有不可逐步取消的區段；不能把背景處理描述成完全沒有 UI 停頓。既有長文效能問題、CivitAI 偶發關閉與公開發布條件仍獨立追蹤。
