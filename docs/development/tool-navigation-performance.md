# 工具頁首次開啟與動畫：量測方式

本輪以使用者已接受配色的 r13（`834eddc475a30b90744396b38a8fa8193c80fd93`）為對照。處理媒體庫、探索、匯出首次開啟、反覆切換與編輯器展開／收合。既有配色與可見布局不變。

## 可重現測量

在 checkout 根目錄，以具有 PySide6 的 Python 執行：

```powershell
$env:QT_QPA_PLATFORM = 'offscreen'
$env:QT_SCALE_FACTOR = '1.25'
$env:PROMPT_STUDIO_V08 = '1'
python tools/measure_tool_navigation.py --source <來源資料夾> --out <全新輸出資料夾> --first gallery
```

`--first` 分別使用 `gallery`、`explore`、`export`；每次都是新程序、新合成文件及獨立 data。先開一份 Canvas，確認工具主機尚未建立，再開始點擊工具頁。交替執行基準與候選三輪，第二輪反轉順序。每輪另測三次回訪。

- 同步階段：從呼叫開頁到呼叫返回。
- 排隊布局／繪製階段：接續處理 20 次事件迴圈，涵蓋零延遲的布局和繪製；不將固定睡眠算入。
- 總開頁時間：上述兩段合計。截圖在計時結束後進行。
- 模組匯入、字型準備及主視窗／初始 Canvas 建立分開記錄；另加總首次走完三個工具頁及返回首頁的耗時，避免將工作移到啟動或其他入口。
- 使用 Windows 微軟正黑體與 Segoe UI 實際字型；離屏平台需明確登錄字型，以免方框字替代造成量測失真。
- `--images 200` 建立 200 張合成圖片及有效縮圖，首頁仍使用正式程式的 60 筆分頁。另加 `--no-thumbnails` 測量缺少縮圖時讀原圖的退路。造測試資料的時間不計入產品操作。
- `--profile` 另行量測共用主機、資料庫、頁面建構、刷新與導覽。剖析會增加成本，不能拿其絕對值代替未剖析的正式時間；父方法包含子方法，不能直接相加。

這是相同本機的 Qt 離屏對照，不是 Windows 畫面呈現延遲、實際 FPS、遠端圖片、真實模型服務或清空 OS 磁碟快取後的測量。

## 消除的工作

1. 工具主機不再建立永久用不到的舊清單編輯介面；保留圖片組合還原所需的 Canvas、手動稿與生成控制介面。
2. 媒體庫與匯出頁固定留在自己的父容器，回訪不再搬到舊分頁再搬回 Canvas，減少整棵元件樹重新套用樣式與布局。
3. 新工具 session 的狀態先在記憶體準備一次，不先寫舊格式、重新開庫、備份、再遷移。既有文件／匯入／快照的遷移路徑保留。
4. 全域輸入監聽集中按事件種類派送，布局／樣式事件不再逐一進入只處理滑鼠或鍵盤的 Python 監聽器。保留後安裝先處理、事件攔截與清理語意。
5. 媒體庫首次建構已刷新首個資料夾，開頁不再刷新第二次。回訪沿用目前 60 筆清單已有的解碼圖示；以來源路徑、大小、修改與建立時間確認是否失效。換頁、搜尋、刪除／重建檔案及重新連結仍更新，不延後到捲動才讀圖，也不保留整個圖片庫的解碼資料。
6. 編輯器展開／收合依點擊後的單調經過時間推進，第一幀較忙不會讓整段動畫延後起跑；關閉時停掉計時，反向沿用當下位置。「減少動畫」能跨工作區及巢狀視窗套用並保存。

## 檢查範圍

回歸涵蓋首次／回訪與父容器穩定性、未預載工具頁、圖片變更／遺失／重建與單頁保留上限、搜尋／選取、工作區設定、Canvas 模式的圖片還原與空白手動稿／Undo／Redo、分頁拖曳、F2 與鍵盤焦點、提示文字、選單、動畫中途反向及關閉。
