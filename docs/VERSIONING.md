0.8.0 及更早版本只保留開發紀錄，沒有 GitHub Release 下載頁。

使用舊版時，請搭配同一版本的 PCS 與 ComfyUI 擴充。0.8.1 至 0.8.3 的下載檔名已更新，包內程式標題與文件仍保留上表的舊名稱。若要核對個別檔案，可查看該頁的 `RELEASE_IDENTITY.json` 與 `SHA256SUMS.txt`。

舊下載連結仍可使用，會顯示對應的現行版本入口。
