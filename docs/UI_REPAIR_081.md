# UI Repair 1 修改與驗證

更新日期：2026-09-14。基準：0.81 Alpha 2 Maintenance 1，Git `8e73c80`。修改前工作目錄乾淨。

| 修改位置 | 原因及結果 |
| --- | --- |
| `settings_page.py` | 將頂部與內容布局分開；移除外層右／底留白，導覽連同其邊距一起收合。返回工作區置於導覽首列。節點頁內側留白由黑色內容承接。 |
| `theme.py` | 固定不透明的 SettingsSurface 遮住材質；改為沿用 Shell，SettingsReading 保持不透明黑色且無底部圓角。設定分頁移除 pane 偏移。文字取消按鈕不再使用停止符號的 24px 字級。 |
| `civitai_ui.py` | 分頁動作移到搜尋列，取消固定底列及底部內距；結果與錯誤提示仍保留。搜尋、下載與圖片載入方式未變更。 |
| `workflow_manager.py` | 七列高度依實際字型重新計算，修改介面字級後更新，避免只看到五列。 |
| `run_controls.py`、`window.py` | 文字取消按鈕與執行、次數欄同高，沿用介面字級；保留停止符號樣式。Canvas 設定入口改在匯出之前。 |
| `releases.py` | 新增獨立 UI Repair 1 建置描述，所有舊旗標仍保留。 |
| `v081_check.py`、`tests/test_settings_edges.py` | 驗證黑色邊緣、圖片區到底、導覽收合、返回與手動稿、七列、材質參數及取消尺寸；封裝檢查也核對這些元件及箭頭資產。 |

資料格式與依賴沒有變更。狀態協調、手動稿、唯一綁定、來源資料、生成提交與取消操作入口維持既有方式。

## 檢查

87 項相關回歸通過，詳見 `qa/ui-repair-1/regression/result.json`，不同測試模組各用獨立程序，預設 ComfyUI 傳輸替換為離線回應；測試自行提供的模擬傳輸仍保留。

8 項新增檢查涵蓋所有設定頁、1040／1440 寬度、詳情展開／收合、11／18 pt 字型、重複次數 1–100、材質與透明度切換。材質檢查模擬 DWM 可用，只證明 Qt 透明度與參數正確，並非實機模糊效果驗收。

固定畫面使用既有公開預覽檔及合成工作流；`qa/ui_repair_visual.py --baseline` 渲染備份程式，無旗標時渲染修正版。初次沿用的舊截圖腳本會唯讀取得本機工作流目錄，最終對比已改為固定回應，沒有送出生成。

獨立 Windows EXE 驗收另列於測試包的 `驗收紀錄`，不與來源測試或真實服務混算。未執行原生桌面操作、DWM 效果目視確認、GPU 生圖或外部下載。

## 保護與回復

`qa/ui-repair-1/baseline/source.zip` 是修改前 Git 封存，SQLite 透過唯讀連線建立一致性副本，完整性為 `ok`；個人資料只存在隔離測試資料與備份，不放入程式來源封存。

Maintenance 1 程式雜湊保存於 `baseline/backup.json`；不覆蓋正在使用的程式，不整包還原工作目錄。若需要回到舊版，使用原 Maintenance 1 入口即可；新版使用的資料副本互相獨立。
