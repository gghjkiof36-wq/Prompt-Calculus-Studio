# 常見問題

[回首頁](../README.md)

## 下載後找不到 EXE

GitHub 的 Download ZIP 與 Source code 是原始碼。請依 [開始使用](GETTING_STARTED.md) 安裝依賴並啟動。Windows 封裝包必須由 Release 的獨立附件取得。

## 啟動時顯示找不到 PySide6

在包含 `setup_dependencies.py` 的專案目錄執行 `py -3.12 setup_dependencies.py`，完成後用同一個 Python 版本執行 `run.py`。

## 顯示資料庫已開啟

同一份資料庫只能由一個 Prompt Studio 主視窗開啟。檢查背景或其它桌面是否已有程式，不要在運行期間刪除鎖檔。

## 連上 ComfyUI，按鈕仍是「複製」

確認 ComfyUI 網頁中的 Prompt Studio 側欄已指定文字節點，並按「啟動桌面版控制」。只建立網路連線還不代表取得文字欄控制權。

切換工作流、關閉網頁或直接修改被控制的文字欄，都可能中止控制。確認目標後重新啟用。

## 側欄沒有 Prompt Studio

確認安裝的是建置後的擴充，目錄位於 `ComfyUI/custom_nodes/comfyui_prompt_studio`。重新啟動後端並重新整理網頁；仍無法載入時，查看 ComfyUI 啟動日誌。

擴充包需要共用核心，不能只複製原始碼中的同名資料夾。完整步驟見 [安裝擴充](../COMFYUI_GUIDE.md)。

## 無法綁定文字欄

目前使用最外層、可直接編輯的 `text` 欄位。若由上游連線提供文字，請綁定上游文字來源。子圖或其它自訂欄位尚未列入支援範圍。

## 按運行時出現收藏位置提示

先到「最近生成」指定收藏目的地，或選擇媒體庫資料夾，再重新運行。

## 最近生成沒有新圖片

先查看 ComfyUI 是否執行成功，並確認工作流使用標準 Save Image／Preview Image PNG 輸出。若整個輸出命中快取而沒有新 PNG，清單不會新增圖片。

來源被移除、ComfyUI 歷史清除或第三方輸出格式不同，也可能使結果無法讀取。

## 圖片沒有模組快照

舊圖片、停用 Metadata 或未保存額外資料的節點，可能沒有快照。程式會顯示缺少資料；目前組合無法證明舊圖片實際使用的內容。

## 更換工作區後有些選項沒有變

只會還原固定模組。其餘選擇、臨時片段與手動稿會保留。若固定組合也不符合預期，檢查是否勾選「以目前選擇更新固定組合」並儲存。

## 匯出顯示 Failed

選「只看失敗」查看原因。常見情況包括來源或目的檔在預覽後變動、目的地受保護、圖片超過限制，或動畫需要不支援的轉檔。修改設定後重新預覽再執行。

## 如何回報

到 [Issues](https://github.com/gghjkiof36-wq/modular-prompt-manager/issues) 提供：

- Prompt Studio 版本與啟動方式。
- Windows 版本；涉及 ComfyUI 時另附其版本與安裝方式。
- 重現步驟、預期結果與實際結果。
- 錯誤訊息或必要截圖。

請先移除個人路徑、API 金鑰與私人圖片。不要直接上傳整份資料庫。
