# 疑難排解

[返回首頁](../README.md)

| 狀況 | 處理方式 |
|---|---|
| 找不到 EXE | 尚無預先打包下載，請依原始碼安裝指南啟動。 |
| `No module named PySide6` | 使用同一個 `.venv\Scripts\python.exe` 安裝 requirements 並啟動，避免不同 Python 環境。 |
| 雙擊 Start.cmd 沒反應 | 它不會自動使用 `.venv`；改用安裝指南中的指令，查看錯誤訊息。 |
| 已有資料庫開啟的提示 | 關閉使用同一個資料位置的另一個視窗，再重新開啟。 |
| 選取素材卻沒有改變最終 Prompt | 檢查是否正在使用手動版本；確認後清除手動內容即可回到自動組合。 |
| 擴充無法載入或找不到 shared | 先執行 build_comfyui.py，再安裝 build 下的完整擴充資料夾。 |
| 打包顯示找不到 release | 先建立 release 資料夾，詳見 ComfyUI 指南。 |
| 沒有 Prompt Studio 側邊欄 | 確認裝到目前啟動的 ComfyUI、沒有多包一層目錄，並重新啟動後端及重新整理網頁。 |
| 桌面仍顯示未就緒 | 確認網址、文字欄綁定及「交給桌面版控制」，保持該分頁開啟。 |
| 生成後沒有新圖片 | 查看 ComfyUI 佇列、錯誤及快取；勿在結果不明時連續重送。 |
| 圖片缺少生成資訊 | 確認原始 PNG 是否保存 metadata；缺失資訊無法從目前 Prompt 推回。 |
| 搬移後圖片失效 | 重新連結原圖；JSON 備份與一般索引不包含外部原圖。 |

仍有問題時，請依 [回報方式](../CONTRIBUTING.md) 提供操作步驟、錯誤及版本。可附經檢查的 `data/error.log`，不要直接上傳完整資料庫。
