# 疑難排解

[回首頁](../README.md) · 適用：0.82 Alpha 1 Repair 5

## 下載後找不到 EXE，或找不到 PySide6

本次提供來源與 ComfyUI 擴充，沒有 EXE。依 [開始使用](GETTING_STARTED.md) 建立虛擬環境、安裝 requirements，再以同一個 Python 啟動。

## 版本不符或網頁未就緒

桌面與擴充必須對應 Repair 5；更新擴充後要重新啟動 ComfyUI 後端並重新整理網頁。保持綁定的原生工作流頁面開啟，重新選擇正確工作流及 CLIP 欄位。缺少唯一對應網頁時，本版拒絕提交，不會退回舊 JSON 生成。

## 為什麼只執行一次，不能關網頁或串多個工作流

本版支援單工作流每次一次。網頁 batch_size 可大於 1，PCS 多輪、跨工作流及無網頁背景執行尚未完成；排序設定存在也不代表順序執行已開放。

## 網頁文字被更新，或 PCS 文字沒有送出

檢查 CLIP 選的是「使用 PCS 提示詞」或「使用 ComfyUI 手動文字」。前者明確接管已綁定欄位，後者保留網頁文字與空字串。檢查綁定的原生節點與欄位是否仍有效、是否由上游供值或被其他 CLIP 占用；不要用反覆刷新繞過文字來源選擇。

## 有整批預覽，為什麼圖片輸入仍要選一張

本次完成整批顯示，尚未完成整批逐張下游執行。將圖片接到 Prompt，選擇同工作流的 LoadImage 目標並指定一張。純圖片而無有效 CLIP 綁定的工作流尚不支援。

## 預覽空白或停留舊結果

未接線時預覽會清空，可另開「最近生成」。有接線時，確認原生工作流身分與輸出節點正確，ComfyUI 任務已完成；歷史被清除、圖片原檔移走或第三方輸出格式均可能使結果無法取得。回報時附版本、步驟與經去識別的 prompt_id，不上傳私人圖片或完整工作流。

## 更新擴充被拒絕

關閉 ComfyUI，核對完整包及 DesktopData 路徑；新舊擴充名稱不可同時置於 custom_nodes。保留舊包與資料後，依 [安裝指南](../COMFYUI_GUIDE.md) 處理。不要直接覆蓋唯一資料或刪除憑證。

## CivitAI 回傳 401

檢查帳號權限、目前 Token 與模型存取限制。401 不足以證明 Token 必定失效；移除模型後再下載的真實服務根因未由本輪驗證。只提供去敏的狀態碼與重現步驟，勿分享 Token、帶驗證資訊的網址或整份下載收據。

## 資料庫被占用或素材不見

同一資料庫只開一個 PCS 主視窗；不要在程式運行時刪鎖檔。素材不見先核對 data 或 PROMPT_STUDIO_DATA，避免匯入覆蓋另一份資料。參考 [資料與隱私](DATA_AND_PRIVACY.md)。

## 回報問題

到 [Issues](https://github.com/gghjkiof36-wq/Prompt-Culculus-Studio/issues) 附上 PCS／擴充版本、Windows 與 ComfyUI 版本、重現步驟、預期與實際結果，以及去敏錯誤訊息。安全問題依 [SECURITY](../SECURITY.md) 私下回報。不要上傳資料庫、金鑰、私人圖片或日誌中的個人路徑。
