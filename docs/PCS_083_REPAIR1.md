# PCS 0.8.3 執行與工作區修復候選

這份候選接續「圖片來源與預排程」版本。使用時保持 PCS、ComfyUI 網頁及服務開啟，桌面與擴充使用同一交付包。實際原生網頁、GPU 及其他擴充的組合，仍需人工驗證。

## 普通執行

1. 把 Prompt 控制接到已綁定工作流的 CLIP 輸入。
2. 按執行開始第一輪。生成中仍可按執行，工具列立即顯示等待次數；次數設為 3 等同加入三次。
3. 未接預排程時，等待需求不保存提示詞，輪到提交時使用當時內容。中途改字會影響尚未提交的輪次。
4. 點擊工具列的「等待 N 次」可查看、繼續或移除尚未提交的普通需求。

## 預排程與圖片來源

- 要固定某次文字，把預排程放在 Prompt 控制與 CLIP 輸入之間。要固定圖文配對，圖片也接到同一預排程的圖片端口，再接圖片輸入。
- 預排程只保存接入的資料；未接入的負面提示詞、種子及工作流參數，在正式提交時取用。
- 每個預排程最多十項，含正在提交或生成的工作。圖片來源接入後，按一次啟動整批，完成一項才補入下一項；同一批再次按執行不會重建一整批。
- 列表顯示順序、來源、狀態及圖片縮圖。拖曳等待項目調整順序；點擊開啟全文視窗，等待項目可以修改，提交後只供查看。全文視窗固定顯示選中的工作，不會因下一筆開始而改存到別筆。
- 暫停：當前工作繼續完成，停止派送與補入。取消：只取消目前指定 PCS 工作，保留並暫停後續項目。繼續：核對後接著處理等待項目。
- 同一綁定工作流在 ComfyUI 手動按執行時，由 PCS 預排程領取同一筆工作，接著自動處理後續項目。其他工作流不消耗這份清單；已暫停的清單仍需在 PCS 按繼續。
- 圖片來源未接預排程時，按一次只處理一張；多按幾次增加幾張需求，完整工作流完成後才換下一張。

## 圖片文字

圖片來源可以直接接 Prompt 控制的藍色「文字」輸入，也可以先接畫布。多個文字來源用「排列文字來源」調整合併順序。

有 PCS 模塊紀錄的圖片沿用對應模塊；只有原始正面 Prompt 的圖片，接入畫布後顯示一張以圖片檔名命名的文字卡，保留完整內容、不拆 tags，也不重複輸出隱藏文字。換圖只替換來源產生的文字卡，保留自行加入的模塊；資料缺失時明確顯示原因，不沿用上一張。

## 工作區與編輯

- 「新增空白工作區」建立新的初始畫布與空白模塊；「複製目前工作區」才會複製現有內容。素材庫、工作流目錄共用。
- 畫布、模塊、線路、草稿、綁定及檢視位置各自保存。舊版本未保存獨立畫布，首次載入只能從既有共享畫面及各工作區原設定建立初始副本，無法還原過去沒有保存的差異。
- 生成中切換工作區，已提交工作繼續，結果歸回原工作區；原工作區的等待需求暫停，切回後按繼續。
- Ctrl+Z／Ctrl+Y 的編輯紀錄按工作區分開。刪除模塊可連同歸屬、線路復原；文字框保留自己的文字復原。
- 拖曳已連線輸入端可改接；選中線路後也可以拖動兩端圓點。放到空白處斷線，Esc 保留原線；有多條輸出線時只改選中的那條。
- Undo／Redo 不改任務日誌，也不重新提交生成。

## 卡住與重開

升級或重開保留既有等待需求，預設暫停。在「等待 N 次」或預排程內選擇繼續或移除，避免先前反覆點擊的工作突然補跑。

「任務紀錄」可查看原工作流、原工作區、提交入口、任務編號與錯誤。已結束但輸入或指定輸出有異常的工作會結案並暫停後續，不再永久占用執行位置。合法原生數值轉換（例如 FLOAT 的 2 → 2.0）不算內容被修改，實際種子、文字、圖片與連線仍須符合。

未確認任務先用「重新核對」。若後端已無這筆工作，也沒有待提交操作，可選「略過此筆並保留紀錄」；這只停止追蹤，沒有重新生成。仍在執行的工作會拒絕略過。重新連線不會自動重送結果不明的工作。

圖片查詢獨立於派送；同一綁定工作流、同一指定節點的整批新結果仍可更新，其他工作流的最近圖片不會補進來。

## 人工驗證清單

1. **先完全不接預排程**：第一輪生成中再按兩次，確認共三輪；期間改提示詞，核對第二、第三輪提交時的文字。再測次數 3 與完整生成後立即再執行。
2. 用 Anima、ill 分別測指定節點的整批圖片；切換 ComfyUI 可見工作流再執行，確認 PCS 綁定與預覽歸屬正確。
3. 預排程保存「白色上衣」「紅色洋裝」，測 PCS 執行與 ComfyUI 手動執行；確認各生成一次。另一個工作流手動生成不消耗清單。測等待項目拖曳、全文修改及提交後唯讀。
4. 使用超過十張圖片的資料夾測圖文配對、容量與補入；不接預排程時另測三次需求及中途手動改字。
5. 測固定／隨機／遞增／遞減種子，每輪原生控制只生效一次。測取消、斷線、重開、重新核對；保留的舊等待需求不應自行補跑，其他來源工作不應被取消。
6. 新增、複製並往返兩個工作區，各自修改後重開；測生成中切換、刪除後 Ctrl+Z／Redo、既有輸入改接、端點拖曳、空白斷線與 Esc。確認空白手動稿及原歷史保留。

候選交付先經離線回執流程與 Qt 介面事件自驗，這些測試不代表真實 GPU 已驗收。人工驗證回報後，再按使用者安排向其他組交接。
