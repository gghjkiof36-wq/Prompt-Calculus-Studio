# Stage 與每筆任務參數

[回首頁](../README.md) · 適用：0.8.5 Alpha 1

Stage 可以保存指定節點的 CFG、步數、尺寸、模型選項及可編輯種子。每筆等待任務也能保存不同設定，方便在相同提示詞與圖片下比較生成結果。

## 開始前

PCS 與 ComfyUI 擴充需為同版。更新後重啟 ComfyUI 並重新整理原生網頁，再開啟工作流；不需手動重建工作流。生成時保持 PCS、ComfyUI 後端與工作流網頁開啟。

## 編輯 Stage

1. 雙擊 Canvas 的 Stage 卡片，或選取卡片後按 Enter。
2. 確認工作流。尚未綁定且有多個來源時，請自行選擇目標。
3. 從左側選要修改的節點，可按名稱、類型或 ID 搜尋；分類可以收合。CFG、步數在採樣器；寬高、批量大小在實際 Latent 來源節點。
4. 修改右側欄位。切換節點會保留本次面板草稿；不同工作流的草稿分開。
5. 開啟「檢視變更」核對欄位與前後值，再按「套用」。套用只保存 Stage 設定；按「執行」才會生成。

一般 Stage 的設定可用 Canvas Undo／Redo 撤銷或重做，已提交任務不受影響。「重設為工作流值」清除目前工作流的 PCS 參數覆寫草稿，須再套用才保存，不會重設 ComfyUI 工作流。關閉面板時可放棄未套用草稿；草稿不會跨程式重開自動保存。

## 比較兩筆不同 CFG

1. 在預排程建立等待項目；需要相同輸入時，複製仍在等待的項目。
2. 打開第一筆等待項，按「Stage 名稱 · 參數」，選指定 KSampler，將 CFG 設為 3，再按「套用至此任務」。
3. 第二筆改為 CFG 4。兩筆使用 `batch_size=1`，若要比較 CFG，也可指定相同固定種子。
4. 後續即使將一般 Stage 的 CFG 改成 7，這兩筆仍各自保留 3／4。批量大小與任務數分開，不會自動為一批圖片分配不同 CFG。
5. 執行後從任務紀錄的「當次 Stage 參數」查看實際 CFG、種子與 ComfyUI 任務 ID。

| 設定位置 | 後續修改的影響 |
|---|---|
| 一般 Stage | 供新加入的任務保存；不回寫既有等待項。 |
| 單筆等待項 | 只改這一筆，優先於加入時保存的 Stage 設定。 |
| 沒有指定的欄位 | 執行前讀取 ComfyUI 的當前值，加入等待不會凍結整張工作流。 |
| 已開始準備或提交的任務 | 無法再改參數；如需其他值，等它結束後建立新項。 |

單筆任務設定不屬於 Canvas Undo；仍在等待時，請再次打開該筆參數修改。複製項目後的設定各自獨立。重開 PCS 時未完成流程先暫停，確認內容後再繼續；舊項沒有參數設定時，不會自動補入當前 Stage 的值。

## 種子與模型選單

種子數值旁可選固定、遞增、遞減或隨機。選模式與套用設定不立即換種子，生成時沿用 ComfyUI 原生更新時機。PCS 可編輯種子上限為 `1125899906842624`（2^50），且仍受節點範圍限制；輸入完整十進位整數。超出範圍的原種子會保留並顯示唯讀，可在 ComfyUI 中設定。

標準採樣器及採用相同原生種子控制的第三方節點可使用這套操作，包含符合條件的 Ultimate SD Upscale；多組種子或特殊控制可能唯讀，請依欄位提示在原生網頁操作。

模型下拉只列工作流已提供的選項，選擇不會下載模型或新增節點。超過 20 項的選單可搜尋；點選或按 Enter 確認，Esc 取消不改值。部分動態選項或多選控制需在 ComfyUI 設定。

浮點顯示會省去明顯的小數長尾，例如 `0.15000000000000002` 顯示為 `0.15`；將指標移到欄位可查看原值。只查看、切節點或修改其他欄位不會降低已保存值的精度。

## 唯讀與衝突怎麼處理

- **欄位已有接線或 PCS 綁定**：從真正供值的上游、CLIP 或圖片輸入修改，Stage 不會替你斷線。
- **更新後欄位仍唯讀**：先確認同版擴充，重啟 ComfyUI、重新整理網頁並重新載入工作流，再看欄位提示；特殊控制仍可在原生網頁設定。
- **原生值或模型選項已改變**：核對原生工作流，重新開啟面板比較再設定，避免用舊草稿蓋掉新值。PCS 不會自動換成第一個模型。
- **任務已開始準備**：參數不能再套用至該筆；保留未套用草稿，待任務結束後建立新項。
- **ComfyUI 已開始生成但 PCS 沒有結果**：先查看原任務，從紀錄重取圖片。直接再按執行會開始另一筆生成。

其他連線與恢復問題見[疑難排解](TROUBLESHOOTING.md)。分享 PNG、工作流或任務紀錄前，請檢查其中的模型、參數、種子及私人內容，詳見[資料與隱私](DATA_AND_PRIVACY.md)。
