# Prompt Studio 0.8.1 Alpha 2

2026-09-14。原始 Alpha 2 由 `Start-v0.81-Alpha.vbs` 啟動；若使用後續維護包，請由 `Start-v0.81-Maintenance.vbs` 啟動，詳見 `MAINTENANCE_081.md`。原有 Alpha 1 與日常版本保留。

設定直接保存，不需按儲存。介面個人化提供還原本次介面調整及重置介面設定；設定左側導覽可收合。資料備份與連線集中到設定頁，個人字典恢復顯示。字典尚未寫完的行會暫存，完成「中文 = 英文」格式後才替換有效字典。

CivitAI 搜尋改為圖片卡片；輸入後稍停即更新，提供模型名稱候選。沒有關鍵字時讀取 Red 模型目錄，以最高評價排序；保留當前類型與 Base Model 篩選。這是公開 API 的模型目錄，不是嵌入網頁，登入帳號個人化排序可能不同。

選取模型才展開詳情，也可手動收合。預覽保留完整比例，Details 使用較小文字，Trigger 為可選取文字；不再顯示 Hash 欄，下載確認仍保留官方校驗資訊。搜尋卡片以縮圖填滿圖片區，完整圖片在右側查看。

連線設定預設使用 CivitAI Red 並隱藏未成年／兒童主題，依來源的 minor 標記、名稱及標籤過濾；沒有標記的內容無法保證辨識。成人內容選項移到連線設定。Token 仍由 Windows 帳號加密保存，不隨此測試包複製。

圖片同時最多載入 3 張，僅載入可見縮圖；選取預覽優先排程，切換時捨棄過期結果。搜尋與檔案操作使用不同工作器，搜尋快取最多 12 組、2 分鐘，圖片快取最多 100 張／128 MiB。檔案下載、校驗與資產登記維持原流程。

最近生成頁移除次數、運行及取消控制，保留收藏位置、指定磁碟資料夾及既有圖片管理。

驗證紀錄與前後畫面見本包「驗收紀錄」。公開連線測試不使用 Token、不下載模型、不執行 GPU 生圖；原生多 DPI、受限模型及實際 ComfyUI 模型載入仍需實機測試。這次的公開網路測量為單次樣本，不能代表所有網路環境。

來源規則參考：[CivitAI 模型 API](https://github.com/civitai/civitai-developer-docs/blob/main/site/reference/models.md)、[官方網域說明](https://github.com/civitai/civitai/blob/main/docs/multi-host-domain-aliases.md)。
