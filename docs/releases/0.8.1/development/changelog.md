整理日期：2026-09-14。最新交付：**v0.8.1 Alpha 2 UI Repair 1**。

## Alpha 1：完成搜尋、下載與模型資產流程

設定左側新增 CivitAI，與 ComfyUI 分開；內含搜尋模型、下載紀錄、連線設定。搜尋可指定模型類型、Base Model 與排序，選取後顯示所選版本的資訊，缺少資料就顯示「未提供」。可前往版本的來源頁面，不嵌入長篇描述。

下載前確認版本、具體檔案、用途分類與儲存位置。依 Type 建議模型目錄，Base Model 保存為資產欄位，不強制建立子資料夾；無法對應的類型由使用者指定位置。同名檔案不覆寫。

檔案完成並檢查後才登記模型資產，保留來源、版本、作者、Type、Base Model、Trigger 及預覽資訊。使用者按「查看資產」才切頁，可以繼續留在搜尋頁找模型。下載完成但登記失敗時，可核對原檔後重新登記，避免再次下載。

官方 SHA256 相符、缺少官方值與校驗失敗分開顯示；自行計算的 Hash 不稱為官方驗證。下載紀錄保存失敗及取消狀態，重開不自動重送；重試下載仍是重新下載，未提供斷點續傳。

ComfyUI 模型資產補齊 Base Model 篩選及來源資訊，分類可指定適用的本機模型類型，支援新增、改名、排序、刪除。刪除分類只把資產轉為未分類，不刪模型、不搬檔案；舊分類保留。

同時修正 CivitAI 草稿的資料風險：檔案改變或查無結果時清除失效辨識狀態；背景來源更新保留使用者改過的名稱、備註、Trigger 等內容；背景工作使用開始時凍結的資料，拒絕過期預覽及 Token 回呼。搜尋、辨識、圖片及下載統一遵守聯網設定，Token 由 Windows 帳號加密保存。

## Alpha 2：搜尋、圖片與日常操作改版

- 搜尋結果由文字清單改為圖片卡片，名稱、作者、類型、底模與評價摘要輔助顯示。輸入後短暫停頓即更新，並提供名稱候選，不必按 Enter。
- 沒有關鍵字時載入 CivitAI Red 模型目錄，預設依最高評價排序，保留其他篩選。使用公開 API 目錄，並非嵌入網站；結果可能與登入後的網站排序不同。
- 未選取模型時隱藏右側詳情，選取後展開，也能手動收合。Details 改為較小文字，Trigger 顯示為可選取文字；移除詳情中的 Hash 欄，但下載確認的校驗資訊保留。
- 卡片圖片填滿圖片區，右側完整預覽保持原比例。只讀取可見縮圖，最多三張並行；選取預覽優先，快速切換時拒絕舊結果。
- 搜尋與檔案工作分開排程，加入有上限的搜尋與圖片快取，減少重複等待。搜尋快取最多 12 組、兩分鐘；圖片快取最多 100 張／128 MiB。
- 預設使用 Red 並隱藏未成年／兒童主題；依來源標記、名稱與標籤過濾。成人內容選項移到連線設定，搜尋列不再重複放置。
- 設定直接保存，移除底部「儲存設定／取消變更」。還原及重置介面設定集中到介面個人化；設定導覽可收合。
- 主畫布的連線與資料入口整合到設定。個人字典恢復顯示，未完成的輸入暫存，不覆蓋有效字典。
- 最近生成頁移除運行、取消與次數那一列，保留收藏位置、指定磁碟資料夾及圖片管理。

## Maintenance 1：整理內部責任，保留既有行為

先保存 Alpha 2 的精確來源與資料副本，再建立獨立維護目錄，沒有用舊備份覆蓋活躍目錄，也沒有把來源不明的未提交差異當成單一任務提交。

1. **建立基準與文件。** 補上專案 AGENTS、架構、開發狀態及技術債，記錄修改邊界、資料保護與驗證方法。
2. **集中變更通知。** 合併保存、刷新及同步，區分 Prompt、布局、模型、設定及生成狀態。移動版面、改備註或次數不再無條件重新編譯全部 Prompt；刷新不發起生成。
3. **集中高風險操作。** 手動稿與文字欄綁定共用入口，保留空手動稿、清單／畫布各自草稿及復原／重做。模型來源與生成沿用既有的檔案身分及批次核對入口。
4. **集中資料相容處理。** 舊格式在載入、匯入及快照恢復時驗證與轉換，畫面刷新不再修改格式；保留原文件與歷史 Prompt，拒絕不支援的資料。
5. **集中版本與打包。** 版本名稱、輸出路徑、啟動參數由同一份描述管理，舊旗標保留。每包附來源提交、逐檔清單與來源 ZIP；修正隔離建置環境找不到 Git 的問題，並補齊 ComfyUI 共用核心的打包模組。

這一版沒有重排 UI；七張固定資料畫面與 Alpha 2 完全一致。後續 UI Repair 的畫面變更是另一次明確授權的修復。

## UI Repair 1：本次完成的介面修正

- CivitAI 移除固定底部空白列，圖片清單延伸到底；結果數與「載入更多」放到搜尋列。
- 設定內容的黑色背景貼齊右側與底部，ComfyUI 三個頁籤不再露出透明底邊。
- 收合設定導覽時，連同左側透明空隙一起隱藏，只保留頂部材質區。
- **返回工作區放在左側導覽清單最上方**，附向左箭頭與粗體；隨導覽一起收合。
- 移除設定頁固定不透明底色，頂部與左側跟隨介面個人化的材質和透明度；內容仍保持不透明黑色。
- Canvas「設定」移到「匯出」左側。
- 工作流清單由五列加長為七列，修改字級後重新計算高度。
- 「取消」原先誤用停止符號的 24px 字級，改為與「執行」相同字級及高度；調整生成次數時尺寸不跳動。

修復提交為 `6b05980`、`5a36e8e`；獨立封裝及說明提交 `32c859c`。UI Repair 1 沒有修改資料格式、第三方依賴或 ComfyUI 擴充，不需為這次 UI 修復重裝擴充。
