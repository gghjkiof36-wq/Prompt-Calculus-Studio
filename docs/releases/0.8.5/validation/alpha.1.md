## 環境

Python／Qt offscreen、JavaScript 離線與原生來源探針；來源為 ComfyUI frontend 1.43.18、Ultimate SD Upscale 1.6.2；圖組裝及傳輸含替身。

## 項目與結果

### 被測資料流

Stage 保存明確參數覆寫，等待項捕捉加入時的設定，單項編輯優先於其捕捉值；未指定欄位仍於提交準備讀取原生工作流。原生套用經欄位與來源核對、暫時投影及序列化，結束後還原；實際 prompt ID 與回執決定種子狀態。Canvas 編輯與執行 journal 分開。操作見[Stage 參數指南](../../../guide/stage-parameters.md)，格式與相容見[資料相容](../../../development/data-compatibility.md)。

## 尚未測試與已知限制

- PCS、ComfyUI 後端及原生工作流網頁仍需保持開啟。關閉網頁後無法繼續準備並送出新的 Stage。
- 種子編輯上限 `2^50`，與節點範圍取交集；多組種子、特殊 serializer、動態選項、子圖或被改寫的控制可能唯讀。通用種子適配沒有擴大背景提交能力。
- 套用時會核對原生欄位變動及任務狀態。提交是否成功不明時先查原任務；取回圖片只重取結果，不以重新生成代替恢復。
- 新電腦安裝、所有工作流、第三方節點、真實 GPU 及 Windows 多螢幕 DPI 沒有由上述離線證據完整建立。

問題處理見[疑難排解](../../../guide/troubleshooting.md)。公開交付檢查與發布狀態由[交付狀態](../development/status.md)及[來源對照](../source-provenance.md)承接，不沿用舊 0.8.4 的測試結論。
