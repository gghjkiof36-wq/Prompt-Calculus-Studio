# 0.8.8 本機候選 3

本版接續[素材管理與分線修正](candidate2.md)，加入素材庫入口整理，以及使用者檢視期間回報的讀取流程控制項與畫布編輯視窗修正。公開版本仍為 0.8.7 Alpha 1。

## 操作變更

- 素材庫左側上方固定顯示「文字模塊、組合、流程」，各自依內容類型列出素材和數量；原「全部素材」入口改為只看文字模塊。LoRA、角色、動作等分類保留在下方。組合與流程不再混在一般分類中重複顯示，使用者既有分類資料保留。
- 文字變體選擇放在名稱右側，左側保留「＋ 新增變體」、變量及 Prompt；底部「管理」開啟右側排序、釘選及其他設定。雙擊變體才展開名稱和次數，列上的次數靠右，起始項以釘子標示。
- 素材庫預覽增加變體左右切換。組合新增／編輯頁的 Prompt 預覽移到名稱旁、管理移到底部；流程也統一稱「管理」。短內容避免不必要的外層捲軸，長 Prompt 在文字框內捲動。
- 加入素材頁按 Esc 返回原組合或流程，保留尚未保存內容。這項返回規則只限素材選擇頁；主編輯視窗原本的取消行為保留。
- 讀取流程的選單以畫布實際縮放與視窗位置定位；切換視窗不應改變輪次值或控制項外觀。
- 畫布文字及流程當輪編輯，展開排除 Tag 時卡片向上置中，收合後回到原位置。動畫只改內部卡片；快速反向操作接續當前位置，減少動態設定直接使用最終位置。
- 「編輯畫布模組」改為「編輯文字模組」。組合加入畫布後也沿用文字模組的編輯入口；素材庫原組合和其中的文字模塊保留，畫布修改仍屬該份副本。

本機檢視資料另外將流程 A 放到獨立「流程」分類，保留「組合」，並新增「表情變體測試」：微笑、大笑、認真。已有素材及使用者新增內容保留；個人資料不包含在可攜 ZIP。

## 同時修復的內容問題

複製流程、組合與變體保留完整內容；組合加入流程時保留外層規則，歷史還原涵蓋三種素材。Prompt 同源分線至多個 Stage 時共用當批取值，避免後續支路誤用下一批、只收到一筆或重複推進來源；直接與經預排程路徑皆適用。

操作與保存規則見[素材與批次](../../../guide/prompt-materials-088.md)。大批次預先展開仍在主執行緒，極大量內容的分段準備保留後續架構評估；這不同於候選 1 已修的閒置週期性刷新停頓。

## 驗證與使用界線

採用隔離資料的 Qt 操作與圖像檢查、實際提交值比較、保存／重開／Undo／Redo 檢查，以及來源與封裝內容核對。真實桌面合成器的閃爍及切換視窗手感仍須實機確認；離屏動畫檢查不等於原生接受。本輪沒有操作使用者桌面、替換正在使用的程式、重啟真實服務或執行 GPU。

使用 `Start-PCS-v0.8.8-Candidate3.cmd`，資料位於本包獨立 `data`。原包與原資料保留。文件版本仍為 7，配套保留 ComfyUI 0.39.2／0.40.0 兩版。
