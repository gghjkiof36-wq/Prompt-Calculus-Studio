# 前置驗證 9：流程、組合與文字模塊

本機候選，尚未通過使用者驗收。本版承接前置 8，整理 Prompt 素材的三個層級。

| 名稱 | 用途 | 介面範例 |
| --- | --- | --- |
| 流程 | 保存多個組合、起始位置與遞增／固定等供應方式 | 讀取流程、選擇流程、流程名稱 |
| 組合 | 流程中一輪使用的內容，可設定重複次數 | 起始組合、新增組合、組合名稱 |
| 文字模塊 | 組合內的文字單元，保存 Prompt、權重與局部設定 | 新增文字模塊、編輯文字模塊 |

素材庫同時容納流程與文字模塊，因此總覽及數量統一稱為「素材」。新增素材的類型為「文字模塊／流程」；流程的格式欄顯示「流程」，文字模塊保留標籤、一般文字或 Markdown 格式。

原「讀取組合」節點改名為「讀取流程」，選單、選擇視窗、空白狀態、輔助名稱與相關錯誤提示同步更新。綠色輸出標示「流程」，純文字輸出仍為「文字」。通用綠色接點可承接流程或圖片附帶的文字模塊，使用中性名稱「模塊內容」；資料型別不變。組合列表顯示其文字模塊數；若包含既有內嵌流程，會另列流程數，不當作文字模塊計數。

「輪」仍指執行次數；同一組合重複兩次會執行兩輪。「工作流」仍指 ComfyUI 工作流，「Stage」仍指執行階段，不與 Prompt 流程互換名稱。

本次是介面命名整理，沒有修改原有 Prompt、使用者自訂名稱／分類、順序、資料欄位、節點識別或接線型別。舊資料直接沿用；既有「組合」分類名稱保留。ComfyUI 0.39.2 舊版與 0.40.0 新版配套仍分開提供。

驗證涵蓋讀取既有流程、進入組合、編輯文字模塊、取消／套用、保存重開與 Undo／Redo。實際檢查結果及交付限制另記本機交付紀錄；離屏操作不代表原生動畫或 GPU 生成驗收。
