# 前置驗證 8：流程預覽與預排程接線

本機候選，尚未通過使用者驗收。

流程輪次原本已隨提交前進，但畫布卡片保留舊副本，Prompt 輸出也未刷新；這會讓已提交的第 5 輪與仍顯示第 3 輪的預覽不一致。現在供應位置變更會同步卡片、讀取組合衍生內容及 Prompt 輸出，保留手動 Prompt（包括空字串）、等待任務的固定內容與 Undo 歷史。

單次執行提交當下預覽，再準備下一輪。連續按執行可依序加入多輪；已完成圖片屬於該次任務，不會因目前改成下一輪而重寫其文字紀錄。批次供應則依原有進度更新顯示，不在預先建立佇列時直接跳到最後一輪。

預排程的紫色連接點統一顯示「輸入／輸出」。接入後顯示「輸入1」，下方保留「輸入2」；名稱不再變成來源節點名稱。CLIP 欄位目標與 Stage 範圍仍使用各自的既有資料契約，舊連線無須遷移。拖線途中切換視窗或在畫布外結束會取消未完成操作並還原原線。

新工作區的預設順序改為：畫布 → Prompt 輸出 → CLIP 輸入 → 預排程 → Stage → 圖片預覽。既有工作區不會自動重排。預排程仍可接在文字傳遞路徑或 Stage 後。

初始畫布由 560 × 280 調整為 960 × 560，右側節點跟著留出空間。小視窗維持可讀的文字大小，以平移查看較大的工作區；執行列仍固定在可見區域。這取代先前以狹小畫布整張塞入短視窗的版面條件，使用者原有的自訂尺寸與視角不會被初始化程序覆寫。

舊文件新增預設工作區時，也會同步整份文件所需的版本標記；切回舊工作區後仍可保存與關閉，不會因新工作區使用綁定排程而留下不一致的版本。

## 驗證與範圍

新增回歸檢查涵蓋六輪連續提交、顯示與實際原生提交資料一致、CLIP 綁定後排程、手動內容、批次顯示、Stage 後接線、斷連／Undo，以及離開視窗取消移線。

曾以本機 ComfyUI 最近八次既有執行紀錄，逐筆比較排程保存文字與實際 CLIP 輸入，八筆一致。這是既有真實執行的唯讀核對，不代表本候選重新完成八次 GPU 生成。封裝、原生介面與本輪測試的最終結果另記交付紀錄；不宣稱全產品回歸或使用者驗收完成。

ComfyUI 0.39.2 舊版與 0.40.0 新版配套包繼續分開保留，見[相容說明](../../../guide/comfyui-compatibility.md)。
