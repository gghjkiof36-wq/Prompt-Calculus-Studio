# 0.8.8 本機候選 4

接續[候選 3](candidate3.md)，整理使用者檢視時回報的素材預覽、變體管理、選擇頁與畫布初始版面。公開版本仍為 0.8.7 Alpha 1。

## 操作變更

- 素材預覽統一為名稱、圖片、Prompt、內容切換、鉛筆圖示「編輯」。沒有圖片不留空白；文字變體及流程可在底部左右切換，組合顯示合併後的 Prompt。預覽不改變來源的執行位置。
- 變體清單保留左側拖曳位置，圖釘移到右側次數之前。未釘選時懸停顯示空心圖釘，已釘選使用常駐灰色實心圖釘。移除清單上方的操作說明與底部獨立圖釘。
- 雙擊變體或選擇「… → 編輯名稱」，右卡切換到名稱與重複次數的編輯頁；按「返回」回清單。在左側切換變體時直接更新編輯頁，不先收合再展開。Prompt 編輯及新增變體仍留左側。
- 素材清單釘選改用灰色實心符號並顯示「已釘選」提示，保留既有卡片與捲動位置；名稱排序仍讓釘選項優先、手動排序保留原順序。素材「刪除素材」改為紅字「刪除」，變體刪除同樣使用紅字。
- Canvas 加入素材的上方入口與素材庫一致：文字模塊、組合、流程。編輯組合時只選文字模塊，編輯流程時只選組合；進入流程中的組合後，再次只選文字模塊。分類及數量同時依此範圍計算，Esc 只返回上一頁。
- 編輯頁高度納入捲動區內框，並隱藏空白的頁次資訊，消除只差數個像素的外層溢位；左側不顯示外層捲軸，長 Prompt 在文字框內捲動，極小視窗仍可用滾輪查看表單。
- 畫布排除 Tag 展開與收合時，內容與卡片同步顯示，Prompt 高度在動畫中保持穩定；快速反向、縮放視窗、減少動態及關閉時會結束或接續目前動畫。
- 新工作區六個節點改成較均衡的初始比例與完整總覽。畫布、Prompt 輸出、預排程和圖片預覽等高，CLIP 與 Stage 保留精簡卡片；既有工作區、位置及手動視角不重排。

## 使用與驗證界線

使用 `Start-PCS-v0.8.8-Candidate4.cmd`，資料位於本包獨立 `data`。本機交付複製候選 3 當時已保存的資料與資產，不改原件；可攜 ZIP 不含私人資料。文件格式仍為 7，ComfyUI 0.39.2／0.40.0 配套保留。

驗證涵蓋隔離資料的 Qt 操作、實際畫面、保存重開、Undo／Redo、取消、來源與副本隔離，以及來源與封裝核對。離屏檢查不等於 Windows 桌面合成器的閃爍已驗收；沒有操作使用者桌面、替換原程式、重啟真實服務或提交 GPU 工作。
