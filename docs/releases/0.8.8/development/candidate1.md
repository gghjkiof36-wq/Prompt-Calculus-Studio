# 0.8.8 本機候選 1

本版本整合三層素材、獨立取值進度、逐筆 Prompt 彙整及已記錄的週期性卡頓修正。它是本機檢視候選，未公開發布；0.8.9 的新動畫、個人化色彩與較大範圍架構改造不在本批。

## 修改清單

- **Prompt Editor**：新增文字模塊／組合／流程類型篩選。文字模塊增加命名變體、各項重複與四種變量；組合可獨立保存。流程先顯示組合與總輪數，成員選擇共用分類、資料夾及搜尋。
- **編輯視窗**：保留整列拖動、雙擊進入、置中及分離側卡。預覽與進階內容在右側；窄視窗重新分配兩卡寬度。文字變體編輯區不再被壓縮。未選流程使用窄視窗，隱藏底部分隔線，選取後才加寬。隱藏的素材選擇頁延後到使用時建立。
- **Canvas**：名稱旁可改權重，卡片顯示當輪實際文字。索引支援按鈕、輸入與滾輪；每份副本獨立前進，同位置分線共用一份結果。
- **Prompt／CLIP／預排程／Stage**：Prompt 統一管理逐筆文字，CLIP 保存欄位與每筆內容。直接執行和排程使用同一份取值計畫，多筆文字及圖片取較大輪數、較短者循環；畫布當次內容整批固定。外層執行次數各自產生一批。
- **保存與復原**：入列與取值進度原子保存，僅已保存筆數算取用；取消不倒退、回執不重推。重試及補位沿原批值，重開不自動重送。維持空字串草稿、原件／副本、Undo／Redo 與歷史。
- **效能**：Stage 卡片改查最新狀態，活動查詢避開已完成歷史；加對應資料庫索引。未變服務狀態不再反覆刷新 UI，排程懸停內容在需要顯示時才計算。
- **相容性**：桌面與兩份 ComfyUI 配套共同支援文件 1–7，分別保留 0.39.2 與 0.40.0 對照包。新候選與原程式、原資料分開。

完整操作見[素材與批次](../../../guide/prompt-materials-088.md)；資料邊界見[相容契約](../../../development/data-compatibility.md)。

## 驗證內容與效能對照

測試按實際生成 payload 核對每筆文字、圖片、欄位、數量及已保存進度，涵蓋固定／遞增／遞減／兩種隨機、重複跨批邊界、兩來源十對六、Canvas 整批固定、三次十輪共三十筆、同位置分線、保存失敗、六筆後取消、重試與重開補位。另核對素材類型、變體文件分離、雙草稿、歷史、斷線／復原、側卡及大量素材。

同一份隔離資料、同一測量程式對照前置 10 和候選程式，五次平均如下。這是離屏合成輪詢及畫布刷新，不能直接等同所有電腦的原生拖動手感或 GPU 執行負載。

| 場景 | 前置 10 | 候選修正後 |
|---|---:|---:|
| 狀態更新與任務觀察 | 492.53 ms | 6.14 ms |
| 全畫布刷新 | 892.09 ms | 19.73 ms |
| 模擬事件循環最大間隔 | 492.66 ms | 29.41 ms |
| 歷史增至 174 筆嘗試後，狀態更新 | 3350.75 ms | 6.13 ms |
| 同一較大歷史的全畫布刷新 | 6600.12 ms | 21.92 ms |

測量期間歷史內容雜湊一致、資料庫記錄變更為零。修正移除暫存排序與不必要整份快照讀取，沒有刪除歷史換取效能。完整任務編輯／歷史仍在需要時讀取原內容。

畫面檢查使用實際 Qt 元件，包含流程總覽、文字變體、獨立組合、模塊／直接輸入側卡、讀取流程空白頁／搜尋頁及窄視窗。測試亦檢查初次繪製位置、快速反向收合、同一原生視窗範圍及無游離控制項；這不取代 Windows 合成器上的原生閃爍驗收。

## 試用邊界

包內 `Start-PCS-v0.8.8-Candidate1.cmd` 使用本包獨立 `data`。`BUILD_INFO.json` 與各 manifest 記錄來源、二進位及配套，私人資料不放入可攜 ZIP。

使用第 7 版資料前，ComfyUI 端須更新為同包配套；前置 7 已安裝的擴充只支援 1–6。候選 1 的交付未替換正式安裝、重啟服務或提交 GPU 工作，兩個保留包的真實服務與 GPU 接受仍須另行核對。公開版號維持 0.8.7 Alpha 1。
