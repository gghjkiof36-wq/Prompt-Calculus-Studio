# 0.8.8 本機候選 2

本版整理文字變體的操作位置，並修正檢視期間確認的素材保存與跨 Stage 分線問題。沿用候選 1 的三層素材、Prompt 統一彙整及週期性刷新效能改善；公開版本仍是 0.8.7 Alpha 1。

## 修改清單

- **文字變體編輯**：目前變體選單移到文字模塊名稱右側。左側保留帶加號的新增變體、變量與 Prompt。底下「進階功能」改為「管理」，排序及較少使用的設定放入右側變體分頁。
- **右側變體管理**：整列拖動排序；次數列在右邊，起始項以釘子標示。雙擊或 Enter 才展開名稱與重複次數，收合按鈕明確標示「收合編輯」。短列表不再把欄位推到卡片底端，長列表在自身範圍捲動。
- **預覽與頁面導覽**：素材庫右側增加變體左右切換，不推進實際執行位置。獨立組合新增／編輯頁將 Prompt 預覽移到名稱右側、管理移到底下；流程也使用「管理」名稱。加入素材頁的 Esc 返回上一頁並保留草稿。組合重開及切換直接輸入時重新核對內容高度，避免少量內容產生外層捲軸；初次高度在繪製前確定。
- **素材內容與歷史**：複製流程、組合及變體時保留完整類型和內容；組合加入流程時保留外層排除、權重及覆蓋規則。歷史還原納入新的素材類型、組合和變體內容，仍可復原／重做。
- **Prompt 分線**：同一來源到兩個預排程，或分成排程與直接 Stage 兩條路徑，共用該批的取值結果。修正後續支路錯用下一批、只送一筆或再次推進來源的問題；另接獨立來源時仍按實際輪數展開。

操作方式見[素材與批次](../../../guide/prompt-materials-088.md)。本機檢視資料副本另將流程 A 放到「流程」分類、保留「組合」分類，並新增表情變體測試：微笑 `smile`、大笑 `laughing`、認真 `serious expression`。這些個人測試資料不包含在可攜 ZIP。

## 驗證範圍

以隔離資料檢查三種素材的複製、導入、歷史還原、Undo／Redo；以實際 Qt 元件檢查變體選擇、排序、釘選、雙擊編輯、長文字及不同視窗大小。排程測試比較每筆實際提交值，涵蓋兩條排程、直接／排程混合路徑、隨機只取一次、較長支路、獨立 Reader、圖片接續、取消、保存失敗、重開與補位。

封裝核對來源、EXE 內程式及 ComfyUI 配套，並在另外的資料副本啟動 EXE。這些是本機自驗；不代表 Windows 原生動畫、實際桌面拖動、真實 ComfyUI／GPU 或全產品驗收。

大批次開始前的內容預先展開仍在主執行緒。同機合成 16 組、每組 8 個文字模塊，預先展開 16 筆約 0.19 秒、48 筆約 0.63 秒；這是額外負載的診斷，不能當作所有資料量的效能保證，也不同於候選 1 已修的閒置週期性停頓。極大批次的分段準備仍需後續架構評估。

## 啟動與相容

使用包內 `Start-PCS-v0.8.8-Candidate2.cmd`，資料放在本包獨立 `data`。候選 1、原資料與使用者新建內容保留。文件版本仍為 7；ComfyUI 0.39.2／0.40.0 配套均保留，沒有在本次交付中替換安裝、重啟服務或執行 GPU 工作。
