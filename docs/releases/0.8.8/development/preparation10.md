# 前置驗證 10：Prompt 彙整與輸入排程

本機候選，承接前置 9；尚待使用者實機檢視。

## 接線與六輪內容

文字統一交給 Prompt 輸出，再交給 CLIP 輸入。CLIP 輸入可直接接 Stage，也可先接預排程，再由預排程連到 Stage。圖片先交給圖片輸入模塊。Stage 後的預排程及完整 Stage 範圍仍可使用。

```text
讀取流程（文字） ─┐
                 ├→ Prompt 輸出 → CLIP 輸入 → 預排程 → Stage
畫布（文字） ────┘                         └→ Stage
```

讀取流程也可先以「流程」接點送入畫布，由畫布交給 Prompt 輸出。新建讀取流程預設供應「整個流程」，仍可選「逐輪」。起始組合、遞增／遞減、重複次數及固定／隨機的輪數上限仍有效。既有讀取節點不會在開啟時被改寫供應設定。

流程 a、b、c、d、e、f 配上固定畫布內容 1，得到 a1、b1、c1、d1、e1、f1，共六份。新接入的流程置於固定文字來源前方，來源排序仍可拖曳調整；來源間保留現有文字分隔規則。Prompt 輸出預覽隨當輪更新，預排程保存各輪最終文字及 CLIP 目標；修改來源不會覆寫已保存項目。明確保存的空白手動 Prompt 仍是有效內容。

新預排程僅顯示輸入／輸出接點，接上輸入後自動出現下一個空白輸入。文字、圖片與模塊內容不能建立直連預排程的新線。讀取流程若沒有通過實際輸入到達 Stage，不可旁接預排程來決定輪數。

## 舊資料與歷史

舊資料接點及任務紀錄仍可讀取。載入舊接線時，既有線保留可見，並提供「整理舊接線」；不會在瀏覽、刷新或保存時默默重接。整理操作將預排程移到已綁定輸入之後；沒有使用者指定 Prompt 目的地的多義接線會保留並提示手動處理。整理可復原／重做，原本的任務內容不改寫；既有執行若因接線變更而不相容，後續保留並暫停。

素材選擇的歷史異常根因是自動保存更新了目前工作區的畫布副本，歷史比對誤把副本同步視為編輯。歷史投影現在從目前文件建立一致副本，排除目前工作區的視角同步，保留其他工作區、文字、手動草稿及綁定。讀取歷史不修改文件。未選流程時，讀取卡片僅留下選擇按鈕，選擇視窗隱藏未適用的組合、變量與套用操作。

## 驗證與界線

專項涵蓋六輪加固定文字、直接／畫布路徑、直接 Stage／預排程、重複整批、已保存文字隔離、空白草稿、圖片與文字成對供應、Qt 拖線、斷連／復原、舊接線整理、保存重開及素材選擇時自動保存。離屏畫面另檢視未選／已選流程、Prompt 來源順序、預排程六筆項目與使用者資料副本。

本版保留 ComfyUI 0.39.2 舊版及 0.40.0 新版配套，不變更文件版本或已安裝擴充。合成執行器替代真實 ComfyUI／GPU；本輪不操作使用者桌面、不重新驗收原生動畫，也不宣稱全產品回歸通過。詳細結果與仍不適用的歷史測試另見本機交付紀錄。
