# Prompt Calculus Studio 0.8.8 Alpha 1

這版讓可重用文字從單份編輯走到整批安排：文字模塊保存變體，組合排列文字與權重，流程決定組合順序；每個使用位置保存自己的取值進度。以下涵蓋公開 0.8.7 至 0.8.8 的完整變更。

## 素材與編輯

- **三層素材**：Prompt Editor 上方依文字模塊、組合、流程篩選，下方保留分類、資料夾、搜尋與釘選。文字保存命名變體，組合可獨立保存，流程保存有序組合與重複次數。
- **變體管理**：各變體有獨立文字與重複設定，圖釘指定起始項；雙擊或「… → 編輯名稱」進入右側子頁，再用「返回」回到變體清單。組合的 Prompt 預覽與管理入口重新排列，加入素材按層級篩選，Esc 回上一層。
- **清楚的預覽與副本**：素材預覽依名稱、圖片、Prompt、位置與編輯排列，可切變體或流程組合，不消耗執行進度。素材跨分類拖移保留內容、ID、歷史及草稿；Canvas 的副本與原件各自保存。
- **去重與排除**：組合可整理自身當輪重複的完整 Tag，保留首次順序；其他組合、不同輪次和相同文字的任務仍保留。排除 Tag 不刪除或停用原模塊，舊去重資料仍可讀。

## 批次、取值與排程

畫布每個批次提供一份固定內容，讀取流程供應多輪；文字先經 Prompt 輸出逐筆整合，再交 CLIP 綁定目標欄位，直接接 Stage 或先經預排程。

| 操作 | 結果 |
|---|---|
| 十輪來源配六輪來源 | 十筆，較短來源循環 |
| 讀取十輪＋畫布文字變體 | 同批共用畫布當次文字，下一批才換 |
| 全部來源固定或允許重複隨機，自動數量 | 預設十筆，也可指定 |
| 外層執行三次十輪流程 | 三批共三十筆，畫布每批取一次 |
| 六筆已保存後取消其餘 | 取值不倒退，下一批接第七筆；重試沿原筆值 |

固定、遞增、遞減及兩種隨機共用規則，先完成當前項的重複次數再換項，剩餘重複可跨批承接。只有實際可達的多筆來源決定批次長度，指定整批 N 後不因重複追加筆數。

同一位置分線共用凍結前綴，各放置位置獨立。保存內容與進度一起完成；保存失敗不消耗，容量補位、重試及重開沿原批內容。修改來源只影響新批次，重開保持暫停。完整範例見[素材與批次](../../guide/prompt-materials-088.md)。

## Canvas、圖片與日常操作

- 綁定後可接預排程，保存文字／圖片對應的工作流目標欄位；原有資料排程及 Stage 範圍排程保留。
- 可新增獨立圖片預覽，連接、折疊、調整尺寸、複製並保存；預覽只供觀看，不改下游來源或消耗取值。
- 改善編輯文字模組及排除 Tag 的展收置中、跨頁預覽欄、Reader 選單定位、窄視窗與大字布局；執行列拖動後的位置可保存，新工作區初始視野較均衡。
- 檔案選擇恢復原生對話框，刪除／移除操作使用一致紅字與停用樣式；保留各入口原有動作語義。
- 改善 prepared payload 回執延遲／遺失處理及可識別原生欄位相容。狀態查詢避免重掃已完成歷史，未變輪詢減少介面刷新，懸停內容按需載入。

## 同時修正

- 取消此工作區全部流程時的例外，以及取消紀錄與任務處理不一致。
- 舊格式升級後，巢狀素材已保存的重複進度可能重設。
- 切換到空輸出、保存重開或編輯時，其他輸出的有效 Prompt 順序可能改變。
- 生成快照夾帶未使用素材正文、分類及資料夾名稱；現只帶重建所需的內容與參照，完整備份仍保留整庫。
- 新增功能頁以鍵盤選 Stage 時，唯讀預覽的回呼例外。

## 下載與啟動

從[本次 Release](https://github.com/gghjkiof36-wq/Prompt-Calculus-Studio/releases/tag/v0.8.8-alpha.1)取得：

| 附件 | 用途 |
|---|---|
| `PCS-v0.8.8-Alpha1-source.zip` | 來源主程式，內含同版配套與安裝腳本 |
| `PCS-v0.8.8-Alpha1-ComfyUI.zip` | 通用擴充 |
| `PCS-v0.8.8-Alpha1-ComfyUI-legacy-0.39.2.zip` | 後端 0.39.2／前端 1.53.10 對照設定檔 |
| `PCS-v0.8.8-Alpha1-ComfyUI-modern-0.40.0.zip` | 後端 0.40.0／前端 1.55.17 對照設定檔 |
| `SHA256SUMS.txt` | 下載完整性校驗 |

來源版需 Windows 64 位元 Python 3.12。完整解壓後，在 `run.py` 旁開啟 PowerShell：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py --v0.8.8-alpha
```

首次安裝依賴後，雙擊 `Start.cmd`。公開資產以 Release 頁面為準，本頁使用來源版步驟，本次不提供 Windows EXE 公開下載。

**桌面與配套擴充都須更新。** 備份後用新資料夾及資料副本，保留舊程式、配套與原資料。關閉 ComfyUI 後安裝一份同版配套，再由你重啟後端並刷新工作流網頁，核對實際載入版本。現行資料格式支援 1–7，不能只重啟舊擴充或手改格式號。完整操作見[開始使用](../../guide/getting-started.md)及[相容指南](../../guide/comfyui-compatibility.md)。

## 已知問題與使用限制

- **特定舊 Stage PNG 無法還原**：部分舊候選圖片本已存在快照不一致，這次沒有修復存量圖片。保留原檔與資料備份，優先由原工作區取回；不要修改 metadata 或放寬驗證來強行載入。
- **必要內容仍會進入 metadata**：生成 PNG 保留必要 Prompt、分類／資料夾與來源參照，並非匿名。完整備份保留私人素材庫；分享前用匯出功能移除不需的附加資訊，再檢查檔案。
- **仍需工作流網頁**：PCS、ComfyUI 後端及該網頁都要開啟。已連線不代表頁面已準備好。執行後不清楚有沒有送出時，先看 ComfyUI 的佇列與歷史，避免重複送出。
- **欄位支援有界線**：未適配子圖、動態節點、特殊序列化、多選模型或多組種子可能唯讀。種子編輯上限 2^50 或節點更嚴範圍，較大原值保留；按提示回原生網頁設定。
- **配套選擇與確認**：通用包供一般安裝；legacy 對照後端 0.39.2／前端 1.53.10，modern 對照後端 0.40.0／前端 1.55.17。只安裝一份同版配套，重啟後從管理頁確認實際載入版本；其他環境先依[相容指南](../../guide/comfyui-compatibility.md)核對。
