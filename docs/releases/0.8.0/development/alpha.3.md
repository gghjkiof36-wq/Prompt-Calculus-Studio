# v0.8.0 Alpha 3 操作修正

這是獨立測試版本。執行 `Start-v0.8-Alpha.vbs`，使用同目錄的 `data`；原有 Alpha 2 與日常版本均保留。

## 本次修正

- 文字、圖片、執行與預覽端口的名稱放在卡片內側，與內容區分開，外側僅保留端口和連線。
- 修復底圖尺寸、圖片裁切、輸出預覽與文字綁定視窗的開啟錯誤。
- 展開畫布支援中鍵拖曳、空白處左鍵拖曳，以及空白鍵配合左鍵平移。右鍵可新增文字、素材、圖片、置中顯示與復原；空白處雙擊開啟素材選擇。編輯位置和外層位置分開保存。
- 預設輸出依序命名為 `prompt輸出1`、`prompt輸出2`。舊版自動名稱會更新，自訂名稱、手動稿、綁定與文字保持原樣。
- 「設定 → ComfyUI → 連線與工作流」整合已連結的桌面工作流與 ComfyUI 已儲存的工作流，提供名稱搜尋、來源與資料夾篩選。清單保持有限高度，數量多時可捲動。
- 刪除與復原刪除靠右，與「設為活動工作流」對齊；刪除使用紅字與紅色懸停效果。確認視窗提供「不再提醒」，只有確認刪除後才記住此選項。

## ComfyUI 工作流

讀取連線位址所對應的 ComfyUI 使用者已儲存工作流，包含 `workflows` 下的所有子資料夾；瀏覽清單不會將所有檔案大量匯入桌面。新增或修改 ComfyUI 檔案後按「重新整理」。尚未儲存的瀏覽器分頁仍可使用網頁擴充的「匯出到桌面」。

選取工作流後，按「設為活動工作流」讀取並連結；已連結的工作流可設定各個 Prompt 輸出的文字欄。標準工作流與 API 格式可直接使用。包含尚不能在桌面轉換的自訂節點或子工作流時，請在 ComfyUI 開啟後使用「匯出到桌面」，由 ComfyUI 產生可執行內容並自動送回桌面。

刪除桌面項目只移除桌面設定與綁定。刪除 ComfyUI 項目會將原檔移到該使用者資料內的 `prompt_studio/workflow-trash`，並解除桌面綁定；「復原刪除」會還原檔案與設定，重開程式後仍可使用。若原位置已有同名檔案，復原會停止，不覆蓋新的檔案。跨伺服器復原須先連回原位址。

## 驗證與資料

`驗收紀錄` 提供回歸測試、原生 Windows 畫面、ComfyUI 實測與資料遷移紀錄。資料副本來自本機 Alpha 2，遷移前後核對各輸出的自動文字與最終文字。

本次 ComfyUI 實測涵蓋已儲存工作流讀取、中文子資料夾、活動工作流設定、刪除、復原與重新載入管理頁後復原。前輪生成驗收紀錄另保留於 Alpha 2；本輪未重新評估模型生成品質，未完成另一台乾淨電腦的驗收。
