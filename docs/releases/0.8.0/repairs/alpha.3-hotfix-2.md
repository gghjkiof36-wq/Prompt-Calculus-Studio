# 0.8.0 Alpha 3 修正包 2

所屬版本：0.8.0 Alpha 3；本機獨立修正包。

## 問題與影響

執行次數變動會讓按鈕寬度跳動；圖片接線、導入位置及生成輸入方式也需要整理。只有 API 資料而沒有前端 Seed 規則時，需給出明確預設。

## 修正內容

獨立測試版本，請使用本資料夾的 `Start-v0.8-Alpha.vbs`。視窗標題會顯示「修正包 2」，資料使用原修正包 1 的副本，原程式與資料保持不變。

本版修正執行次數變動時的按鈕寬度跳動，移除載入圖片模組的接線捷徑；連線仍可拖動尾端至空白處解除，並可復原。導入結果圖片會在對應 Prompt 附近建立圖片模組，替換已有圖片也可復原。

### 依綁定輸入

工作流維持使用者指定的活動工作流，取消文生圖／圖生圖的操作切換入口。

- 只有文字輸入：更新已綁定的文字，保留工作流原有圖片。
- 有圖片輸入且已指定可寫入的圖片欄位：上傳並替換該欄位。
- 有圖片輸入但缺少圖片欄位：提示「圖片無法載入工作流」，不提交，不默默忽略圖片。
- 畫布接入圖片，但沒有黃線接到參與執行的 Prompt：該圖片不參與執行。
- 已連線但圖片不存在、來源不可讀或多個來源不一致：仍須修正來源後才能提交。

圖片欄位在設定的「連線與工作流 → 對應…」指定；沒有指定時沿用工作流圖片。文字欄維持逐份 Prompt 唯一綁定。

### Seed

匯入 ComfyUI 畫布或擴充匯出的工作流時，保留其中的 Seed 變更方式。只有 API 資料、沒有前端規則時，預設每次隨機；「參數…」仍可選固定、遞增、遞減或隨機。導入圖片不讀入圖片 Metadata 的 Seed，也不切換活動工作流。

這份獨立測試資料將目前活動工作流改為每次隨機，解決原本固定 Seed 造成的重複結果；原資料備份保留既有設定。

### 配套擴充

相配擴充是本包的 `PromptStudio-v0.8-ComfyUI.zip`。停止 ComfyUI 後，將舊 `custom_nodes/comfyui_prompt_studio` 備份到 `custom_nodes` 以外的位置，再解壓新版同名資料夾放入 `custom_nodes`。重新啟動後端並重新整理網頁。

## 驗證結果

測試紀錄見本包「驗收紀錄」。本輪依要求不操作桌面、不啟動 GPU 生圖；無視窗測試、Windows 封裝檢查與實際 ComfyUI 生成分開記錄。需要實際視窗或 GPU 的驗證保留待辦，不宣稱已完成。

CivitAI 功能另行隔離為草稿，不屬於本版公開功能；本輪不發布正式 0.9.0。

收尾回歸與 CivitAI 隔離結果見 [基準審查](../validation/baseline-review.md)。
