# Prompt Calculus Studio 0.8.6 Alpha 1

發布日期：2026-10-03（Asia/Taipei）。

這版整理日常使用的導覽和畫布，把連線、素材、圖片及更新操作放到更清楚的位置，並保留既有 Stage 與每筆任務的參數設定。

## 新增

- **Canvas 起始流程**：新工作區提供文字畫布、Prompt 輸出、預排程、CLIP、Stage 與圖片預覽六個接線節點；待設定提示依序帶你加入文字、連線與綁定。原工作區布局保留，啟動直接進入 Canvas。
- **連線及更新**：配套 PCS 擴充可從程式內安裝，不需先綁工作流；Manager 提供套件清單、固定版本及支援環境的更新操作，另改善 ComfyUI 前端 1.53.6 的參數相容。

## 改善

- **共同導覽與配色**：頂列切換畫布、媒體庫、探索、匯出與設定，側欄可收合、暫時展開與調寬；整理石墨、霧藍、紙白配色，改善選單、提示框、長文字及窄視窗操作。
- **媒體與素材操作**：切換縮圖／檔名清單，辨識目前檢視的圖片，獨立閱讀圖片資料，選取多張後一起匯出；模型與套件詳情的長名稱更容易閱讀。

## 修正

- **排程操作**：右鍵移除或取消單筆項目。底部叉號取消目前項目，其他項目保留並暫停；全部取消改用明確選單。改善背景頁面接收操作，擴充側欄移除舊版標題。

## 已知問題

- **背景網頁未能回應**：連線燈號只表示服務可達。若仍停在準備輸入，回原生網頁查任務、保存工作流再重新整理；不要連續重按執行。網頁關閉後不能繼續送出新的 Stage。
- **參數唯讀或種子超範圍**：依欄位提示從原生網頁或真正供值的上游設定；PCS 種子編輯上限為 `1125899906842624`（2^50），特殊控制或多組種子可能唯讀，原值會保留。
- **擴充已安裝但版本未載入**：重啟 ComfyUI 並重新整理網頁，管理頁會分開顯示安裝與載入狀態。安裝中斷或來源不明時先保留備份、查看安裝紀錄，避免反覆覆寫。
- **安裝回復紀錄與目錄不符**：其他程序同時建立目標時，回復紀錄可能不準確；保留目標及備份、停止重試，核對內容後再恢復。
- **Manager 更新未確認**：支援環境才提供更新按鈕；結果不明使用「重新查詢」，顯示待重啟後自行重啟核對。其他問題見[疑難排解](../../guide/troubleshooting.md)。

## 升級注意事項

更新前備份資料，把新版放到新資料夾並使用資料副本，保留舊程式、擴充與原資料。沿用資料時核對配套安裝位置；新資料需重新指定。啟用隨 PCS 更新配套時，只在 ComfyUI 關閉後安裝本版隨附包。更新後重啟 ComfyUI 並刷新網頁，再確認實際載入版本。未完成流程先暫停，核對內容後繼續。

## 下載與使用方式

從[本次 Release](https://github.com/gghjkiof36-wq/Prompt-Calculus-Studio/releases/tag/v0.8.6-alpha.1)下載：

| 附件 | 用途 |
|---|---|
| `PCS-v0.8.6-Alpha1-source.zip` | PCS 來源主程式，內含同版配套擴充與安裝腳本 |
| `PCS-v0.8.6-Alpha1-ComfyUI.zip` | 另供手動安裝使用的同版擴充 |
| `SHA256SUMS.txt` | 檢查下載內容完整性 |

本次提供原始碼版，沒有 Windows EXE 下載。先安裝 Windows 64 位元版 Python 3.12，完整解壓來源包，在含 `run.py` 的資料夾開啟 PowerShell：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py --v0.8.6-alpha
```

首次安裝需網路取得依賴，之後雙擊包內 `Start.cmd`。開啟 PCS 後，從「探索 → ComfyUI → 連線與工作流 → 安裝／更新 PCS 擴充」選 ComfyUI 資料夾，關閉 ComfyUI 後安裝；完成再啟動並重新整理工作流網頁。生成時保持 PCS、ComfyUI 與原生網頁開啟。完整操作見[開始使用](../../guide/getting-started.md)及[ComfyUI 指南](../../guide/comfyui.md)。
