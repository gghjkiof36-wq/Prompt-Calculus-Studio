# 0.8.6 啟動與回復修訂 12

這份本機候選包含三項修復：

- 已有文字、工作流及 CLIP／Stage 綁定的文件，可以在連線控制器尚未初始化時開啟。一般手動稿及空手動稿保留，引導刷新不會提交生成。
- 排程卡移除或替換後，舊卡片停止延遲布局；晚到通知須確認卡片仍屬於目前畫面及模型。正常卡片的字級、換行與尺寸更新保留。
- 擴充更新失敗時，只有核對原檔案確實恢復後才記錄 `rolled_back`。若其他程序建立同名資料夾，或備份無法驗證，保留現有資料夾及備份，記錄 `rollback_unconfirmed` 並停止自動重試。請先查看安裝紀錄與 `.pcs-program-backups`，人工確認後再恢復；不要刪除其中任何一份資料來強行續裝。

保留完整程式資料夾，再執行 `PromptCalculusStudio.exe` 或 `Start-PCS-v0.8.6-Revision12.vbs`。程式已包含配套擴充與安裝器。這次的修復位於 PCS 桌面與安裝器，不需要為修復排程畫面而更新正在運作的 ComfyUI 前端。

新版程式使用原有資料位置規則。若已有「啟動修復 1」資料副本，請使用該副本的最新內容；不要用更早的原 data 蓋回去。原程式、原包與資料副本均保留，這份候選不自動替換正式安裝。

修訂 11 的未知程序拒絕、版本拒絕降版、設定保留、包完整性檢查仍適用。來源套件名稱沿用目前的 `prompt_calculus_studio`／`comfyui_prompt_calculus_studio`；既有資料鍵、環境變數、節點及通訊名稱沒有更名。驗證範圍見[修訂 12 驗證](../validation/revision12.md)。
