# 0.8.7 候選驗證範圍

本候選以 0.8.6 修訂 12 為基礎，供本機核對。來源提交與交付檔案以包內 `BUILD_INFO.json`、`SOURCE_MANIFEST.json`、`PACKAGE_MANIFEST.json` 識別；這份紀錄區分來源操作、外觀及封裝檢查。

## 候選14：Canvas 模組與新增頁

新增頁包含搜尋、分類、功能清單和右側節點預覽。預覽使用隔離的真實節點元件，依節點高度排列；不讀取使用者執行歷史、不提交工作流。卡面統一標頭、名稱旁收合與更多選單，調整內容分組、內外層表面和下方陰影。權重可原位輸入 −100.0 至 100.0；文字／圖片綁定沿用既有資料流程。底部執行欄與 Canvas 背景保留原版。

- 固定來源 `c6fd8ff`：16 項模組操作及 18 項滑鼠操作通過，Qt 例外與外部呼叫均為 0。包含首次加入、取消、十種真實預覽、權重非法值／上下限／模擬組字、保存／重開／Undo、父子卡、收合端口／尺寸、綁定取消及失效目標解除、文字畫布底部入口，以及既有框選和多選流程。
- `5ec3338` 的 4 項代理元件邊界／大字檢查、11 項色彩檢查與 4 項封裝檢查通過。後續只修正底部入口的事件優先權及其測試，相關滑鼠流程已於 `c6fd8ff` 重跑；未修改上述色彩或元件繪製。
- 125% 離屏實際 Qt 視窗核對 9 張畫面，涵蓋一般／窄視窗、長名稱、停用、收合、原位編輯、兩類綁定、新增頁空結果和文字畫布展開頁。圖片來源為 `5ec3338`，後续事件修正不改繪製。九種配色組合的非模組色彩與舊版相同，執行欄類別程式亦相同。
- 切頁／縮窗沿用舊尺寸中心造成的畫面偏移已修正。啟動導引套件仍有 2 項既有小視窗排版失敗；在候選13基準 `46ee1b5` 亦相同，涉及大字導引與執行欄之間的底部間距，未列為本次已修正。舊綁定測試仍有 1 項欄位數預期落後，舊 Canvas refinement 測試使用不適用目前多畫布的資料與元件假設，兩者在基準亦失敗；未以它們宣稱完整回歸通過。舊文字畫布編輯測試仍等待已被取代的建立對話框，本輪未完成該套件，實際展開／返回、框選与編輯入口由本批相關操作檢查及畫面另行核對。

以上為隔離合成資料、離屏 Qt 操作和外觀證據；不代表原生 Windows 輸入法、真實 ComfyUI／GPU、安裝更新或使用者視覺接受。

- 本批待使用者實機檢視；未以離屏與模擬事件代表原生 Windows 輸入法、真實服務／GPU 或完整版本接受。候選11的清單高度與堆疊保留，使用者已給予正面操作回饋。

文字素材清單改用視窗剩餘高度，保留24px底部邊距，移除580px上限；卡片高度不拉長。內容超出時，底部最多三層卡片逐漸縮窄、重疊及變暗，向上捲動時恢復正文。文字不以零碎重疊方式呈現。一般滑鼠滾輪採160ms緩出，觸控板像素捲動沿原生行為；點擊、鍵盤、拖曳與搜尋中止尚未完成的滾動。內容放得下、已捲到底或啟用減少動態效果時維持平排，拖曳排序期間也恢復實際列位置。

- 固定來源 `6bf84fb`：28項Editor及8項排序檢查通過，包含8卡完整顯示、底邊距、長清單末項可達、堆疊露出區的單擊／雙擊對象、連續滾輪、鍵盤中止及減少動態效果；Qt例外與外部呼叫均0。
- 125%離屏實際主視窗以合成資料核對7張畫面及各狀態，最後程序正常退出。這是動畫試作，尚未取得使用者對舒適度的接受，也未驗證實體觸控板或所有Windows顯示環境。

## 候選9：縮窗時預覽維持右側（歷史）

- 固定來源 `4b35a2d`：Editor 24項通過，無略過、Qt例外或外部呼叫。包含連續縮放、搜尋與排序、編輯後取消、預覽關閉與重開，以及原件內容保留。
