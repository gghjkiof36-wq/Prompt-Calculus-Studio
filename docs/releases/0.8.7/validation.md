## 候選8：收合、拖曳與分類入口

分類／模組拖曳以每列垂直中心計算插入位置，不再把項目間距或側邊空白當作清單尾端；移出清單會清除提示並拒絕落下。「內容分類」右側的圖示「＋」直接開啟新增分類，取代原底部管理分類入口及只有一個選項的中間選單。

- 固定來源 `2310bf5`：Canvas 12、拖曳排序 8、Editor 23，共43項通過，無略過、Qt例外或外部呼叫。包含短名／長名子卡收合、正文雙擊、提示事件、交界與四側拖曳取消、排序保存、原件與草稿保留，以及新增分類取消／保存／復原。
- 實際DPR1與1.25各完成13張離屏Qt畫面，涵蓋名稱旁的收合箭頭、子卡長名稱、Stage提示阻擋、分類新增、拖曳導線及640px窄窗。每個比例的交界處36筆事件均維持同一局部插入位置，移出後清除導線與捲動計時器；新增分類另以實際主視窗核對取消與復原／重做。
- 已人工開圖，並依Impeccable指引獨立回核125%主流程8張。本次證據限合成資料、離屏Qt及注入的滑鼠／拖曳事件；靜態圖不單獨證明無閃爍，不代表Windows原生桌面拖曳、真實服務或使用者接受。

原件編輯移除進階區的第二層捲動框；素材資訊、標籤查詢、關係與預覽及內容歷史依內容展開，使用同一表單捲動區。保存、取消與錯誤訊息保持在表單外的固定底部；展開長文時也依可用視窗高度限制編輯視窗。

- 來源 `8844a6f`：工作區6、分類排序6與Canvas10項通過；後續來源 `83b8a0c` 的進階編輯與既有保存／取消／復原等22項通過。兩批涵蓋44個不同案例，無略過、Qt例外或外部呼叫；後批沒有改動前批頁首、分類及卡片控制。
- 來源 `83b8a0c`：實際DPR1與1.25各完成6張頁首／卡片圖及16張進階操作圖。頁首涵蓋1360、1024及640px寬；進階表單涵蓋1360×900／11pt和640×480／18pt，操作四個區塊、離線字典補全、圖片移除／選擇、歷史開啟、保存錯誤、取消及保存後重開。來源與圖檔雜湊均記錄，頁首及卡片另有獨立看圖回核。
- 原件表單已無巢狀捲動；共用歷史子視窗在大字窄窗下仍可水平捲動，本次沒有改寫其版面。證據限隔離資料與離屏Qt，不代表Windows原生桌面、真實服務或使用者接受。

頁首／卡片畫面輔助程式初次未等候雙擊的排程回呼便結束攔截，造成測試流程等待對話框；該批未完成輸出保留，不計通過。在攔截內等候事件完成後，兩種顯示比例均完成，產品未因這個輔助程式問題改動。

## 候選6：歷史介面與操作

候選6曾將工作區選擇與Canvas共用同一個工具列外觀，已由候選7整合至原平面頁首的安排取代。切換時保留各工作區草稿和復原紀錄；Canvas工具列已移除重複的「素材」入口。主清單沿用740px首選閱讀寬度，與右側預覽依工作區可用寬度居中配置，一般桌面縮小維持並排，真正窄窗才上下排列。預覽頂部對齊搜尋欄；搜尋、操作列與文字卡片切齊。模組數量的小字切齊標題底部，不需捲動時不顯示捲軸。這取代候選5「開關預覽不改變主欄邊界」的安排。

分類與模組可拖曳排序，順序保存且支援復原／重做；篩選後只重新排列可見項目，不改現有Canvas組合的輸出順序。卡片只顯示文字，移除無獨立操作的箭頭。加入挑選頁在右欄分類標題下設置與卡片同寬的搜尋，不顯示圖片或多餘的左上角灰字。

- 顯示來源 `0b4b06f`：配色11及按鈕3個案例通過。連續縮放視窗及挑選頁的Qt畫面，在實際DPR1與1.25各完成17張；涵蓋2048、1440、1360、1184、1152、1024及640px寬度、短／長預覽、空分類、搜尋與無結果。完整正常應用入口另於DPR1.25完成新增、取消、鍵盤操作、雙擊及頂層視窗事件檢查，未出現多餘的按鈕視窗。
- 已人工開圖核對，並依Impeccable指引獨立回核。這是隔離資料、合成素材及離屏Qt證據；沒有自動偵測引擎結果，也不代表Windows原生桌面或使用者接受。

## 候選5編輯與加入流程核對（歷史）

- **分類瀏覽與預覽**：主欄沿用設定頁740px首選寬度並置中；預覽開啟、切換短／長內容及關閉不改變主欄邊界。空間不足時預覽移至下方。模組清單只顯示文字，圖片保留在詳情；原圖片資料不因清單省略而刪除。
- **獨立原件編輯**：同一程式工作階段內，保存、關閉並重開後可使用原生文字 Undo／Redo 快捷鍵及右鍵選單。取消或 Esc 保留原稿、原有重做紀錄及編輯位置；保存才提交內容，不改既有畫布副本。
- **加入文字模組**：只保留分類、純文字模組選擇與固定底部「新增空白模組」；窄窗以分類下拉選單配合清單捲動。單擊只加入一份副本；取消空白編輯返回挑選器且不改資料。目的畫布失效、重試及副本交易另有檢查，沒有背景查詢或生成提交。
- **管理頁**：PCS 配套擴充、工具與自動更新使用相同首選欄寬；窄窗不產生水平溢位。既有安裝／更新操作未因欄寬調整而重作。

前批 Editor 17、加入流程13、管理欄寬3項測試通過，均無略過項目、Qt例外或外部呼叫。另有獨立的重開 Undo／Redo、Cancel及Esc三個原生文字歷史操作場景通過；這裡的「原生文字」指Qt文字文件，並非Windows原生桌面驗證。

後續功能覆核涵蓋上述33項、畫布滑鼠操作10項、保存工作流重開2項及啟動3項，共48個唯一案例；正常應用入口另核對啟動畫布、往返Editor與保存／重讀。舊啟動測試曾把清單稿誤當目前Canvas生成稿，已更正為核對舊稿保存、重開後可取回，沒有為通過測試改動程式行為。全部使用隔離資料及離線Qt，沒有以來源檢查代替新包啟動或真實ComfyUI／GPU驗證。

同來源實際Qt離屏畫面涵蓋1360×900、2048×1152、1150×900及640×480／18pt大字，DPR1；常規UI11pt、Prompt12pt，使用Windows本機字型。已人工開圖核對主次層級、純文字清單、長內容及窄窗操作。本次使用Impeccable指引人工審查，未執行自動偵測引擎；不將離屏畫面或本次自驗視為產品接受。保留的失敗核對程式紀錄與後續完成結果分開列於交付證據，不以重跑加總通過數。

## 封裝與限制

候選1／2的獨立來源審查涵蓋資料、操作、性能及提交安全；共享模組在封鎖Qt匯入後仍可載入。歷史包也已完成檔案集合、雜湊、來源allowlist及離線啟動核對。這些包結果各自綁定原版本，不能當作候選3的封裝結果；候選3的實際封裝與啟動結果另列於交付紀錄。

本輪尚未使用真實ComfyUI、網路下載或GPU，未替換正式安裝，沒有公開上傳。原生桌面的前景／背景切換、長時排程及不同實體螢幕仍需另行核對；離屏畫面與視窗旗標無法排除所有Windows桌面情況。

完整桌面候選為含EXE、`_internal`、配套擴充與對應來源／文件的資料夾，不能只搬EXE。測試使用獨立資料；保留舊程式和原資料，回退時使用相容的原資料副本。
