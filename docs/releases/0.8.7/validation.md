# 0.8.7 候選驗證範圍

本候選以 0.8.6 修訂 12 為基礎。這份紀錄描述本機合成資料及 Qt offscreen 檢查；來源提交與每個交付檔案的識別以包內 `BUILD_INFO.json`、`SOURCE_MANIFEST.json`、`PACKAGE_MANIFEST.json` 為準。通過這些檢查不代表已完成公開發布接受。

## 已執行的核對

- **Canvas 操作**：真實 Qt 事件覆蓋框選、Ctrl 選取、功能卡取得焦點後複製／刪除、容器與成員共同移動、Undo／Redo、游標錨定縮放及內嵌文字快捷鍵。另以失敗交易核對資料不部分提交。
- **素材及文字保存**：獨立副本、來源版本、分類／釘選、空草稿、全文與側欄同步、快速切頁／工作區、展開頁返回及資料庫重開。被刪除的 Qt 編輯器參照不再阻止保存。
- **素材管理入口**：全頁單擊選取供編輯，側欄單擊取用；兩處的右鍵編輯／釘選都不加入畫布。以有／無目的地的實際 Qt 滑鼠與選單事件核對，明確加入及「保存並加入畫布」仍可使用。
- **資料相容**：舊清單内容可取回；舊圖片快照使用當時的分隔規則驗證，不拿今天的 Prompt 改寫歷史。舊工作區 scene 依完整次序升級，二次載入不重複備份。未知版本及偽改歷史文字仍拒絕。
- **Stage 與排程**：未完成數字／空字串草稿保存，工作區與來源分隔，重開／明確套用／衝突拒絕，未提交項目局部復原及不自動重送。準備輸入也納入活動狀態。
- **Metadata 與圖片**：帶有效 PNG 文字區塊的本機樣本、正負／未知來源、文字欄位能力、晚到舊輪結果及先篩選後解碼；縮圖限制不縮減歷史或下游資料。
- **離線查詢**：個人字典、快取命中、過期／清除／停用、延迟回覆與工作區歸屬；真實外部查詢不在此輪範圍。
- **顯示**：1360×900 側欄／全頁及 640×760 單欄 Editor 的 offscreen 圖片核對；最大化／全螢幕切頁旗標、各自視角保存、縮放後排程選單定位。這些不等於實體螢幕/DPR 或桌面合成器驗收。

相關測試以 `tests/test_087_*.py`、`test_material_editor.py` 及受影響的既有 Canvas、Stage、metadata、snapshot、maintenance、search-cache 測試為主。原生 queue 的 JavaScript 測試使用合成回執。共享模組的 Qt 阻擋匯入與來源 allowlist 另由 maintenance-package/privacy 測試檢查。

## 容量與效能樣本

在 100 張合成文字卡、105 次移動提交的 Qt offscreen 樣本中，保留 100 個 Undo 步驟，序列化總量約 8.29 MB，沒有生成提交。將 Undo 大小計算改為按快照身分快取後，同機最後五次提交中位數由約 142 ms 降至約 91 ms。這是單一工作負載的比較，不是所有畫布或硬體的效能保證。

## 尚未驗證的邊界

此輪未使用真實 ComfyUI／網路下載／GPU，未替換正式安裝，沒有公開上傳。原生桌面前景／背景切換及長時排程需另以授權環境核對。無法以 offscreen 視窗旗標測試排除實體 Windows 的所有自行縮小情境。

新功能候選仍需固定來源版本的獨立資料、操作、UI 與性能核對。測試記錄不以「程式存在」取代操作驗證，也不將示意素材當成使用者資料復原證据。

## 候選 1 的獨立核對與後續修正

候選 1 的獨立流程核對有 18 個選定案例通過，涵蓋最後輸入、空內容、副本、保存重開及進行中提交隔離。提交安全來源檢查未發現阻擋；26 個共享模組在封鎖 Qt 匯入後仍可載入。舊生成測試原先預期返回已停用的清單生成頁，已改為明確保存舊清單稿，核對進入 Editor 後 Canvas 稿、唯讀舊稿及原圖 bytes 均保留；相關生成套件 13 項通過。

獨立封裝檢查核對了桌面與擴充的檔案集合、雜湊、來源 allowlist、EXE 內專案模組及版本識別，未發現私人資料混入。候選 1 的打包 EXE 以隔離離線範例完成啟動並正常退出。這些結果僅適用其固定包；後續候選按變更補驗並重新核對包。

原生桌面已觀察到 Editor 輸入同步保存、展開頁返回，最大化切頁序列未重現自行縮小。但操作工具的座標／焦點資訊有偏差，窄窗、完整快捷鍵、接線與圖片檢視等尚不足以作整輪原生接受。素材管理入口的耦合已修正，仍待對應新包的操作核對。
