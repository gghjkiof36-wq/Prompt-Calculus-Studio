# 0.8.7 候選驗證範圍

本候選以 0.8.6 修訂 12 為基礎，供本機核對。來源提交與交付檔案以包內 `BUILD_INFO.json`、`SOURCE_MANIFEST.json`、`PACKAGE_MANIFEST.json` 識別；這份紀錄區分來源操作、外觀及封裝檢查。

## 已執行的操作核對

- **Canvas**：Qt 滑鼠事件覆蓋空白左拖平移、右拖框選、Ctrl 累加、右鍵選單、多選複製／刪除、容器與成員共同移動、Undo／Redo及游標錨定縮放。輸入框的文字快捷鍵優先；失敗交易不部分提交。
- **Prompt Editor**：新稿與素材原件明確儲存，畫布副本局部同步。切換素材、全頁／側欄及窄寬視窗時，保留各稿文字、名稱、游標、選取、捲動和原生文字 Undo／Redo；舊控件銷毀不刪除目前草稿的復原紀錄。另核對最後輸入、保存失敗、取消離開及原件／副本隔離。
- **素材入口**：全頁單擊開啟編輯，側欄單擊取用；右鍵編輯／釘選不加入畫布。全頁儲存不產生副本，側欄「保存並加入畫布」沿同一交易處理。分類、釘選、預覽替換／清除及重開內容均有核對。
- **資料與歷史**：有效空手動稿、舊清單內容取回、工作區升級及二次載入保留。歷史圖片使用當時快照，不拿目前 Prompt 改寫；未知版本與偽改歷史仍拒絕。
- **Stage 與預排程**：未完成數字／空字串草稿、來源分隔、重開、明確套用及衝突拒絕；準備輸入納入活動計數。已確認失敗項目的右鍵移除只處理該項，其他等待項目、模塊與接線保留；不自動重送未知提交。
- **Metadata 與圖片**：PNG 文字區塊、正負／未知來源、可編輯字串欄位、晚到舊輪結果及先篩選後解碼。Recent 和 Canvas 正式入口各以橫／直圖開啟並關閉檢視器；依視窗空間等比例顯示，縮圖限制不刪除歷史或下游資料。
- **離線查詢**：個人字典、快取命中、過期／清除／停用、延遲回覆及工作區歸屬；未使用真實外部查詢。

本輪 Editor 整合來源 `b7b0ab5` 的素材34、獨立素材審查6、搜尋快取4、生成隔離13項通過，Qt例外0；另有6個唯一獨立操作場景通過。`a237415` 再補卡片自然高度／按字界換行，以及資訊開關保持閱讀位置，兩項受影響案例通過。較早結果只沿用未變行為，未加總重跑案例。

三個管理頁限局部文字層級、行距、自然換行及群組間距；5項閱讀元件檢查與4項維護封裝檢查通過。安裝／更新流程未因排版變動重作。

## 畫面核對

固定來源 `a237415` 的真實 Qt 離屏畫面包含1360×900、2048×1152，以及640×480／18pt大字。常規UI11pt、Prompt12pt；DPR1。涵蓋新稿、素材選中／搜尋、收合／重開、資訊展開、保存錯誤、長正文、三管理頁及同設定的既有匯出頁，另有Canvas選取／編輯／停用狀態。

正式圖補載Windows本機正文與符號字型，manifest記實際解析字族和每圖雜湊。Prompt Editor、PCS 配套擴充、工具與自動更新四頁已完成獨立看圖回核，沒有未解必修問題。靜態外觀與功能操作各自記錄，不能互相代替。

## 容量與效能樣本

在100張合成文字卡、105次移動提交的樣本中，保留100個Canvas復原步驟，序列化總量約8.29 MB，沒有生成提交。快照大小計算按身分快取後，同機最後五次提交中位數由約142 ms降至約91 ms。這是單一工作負載的比較，不是所有畫布或硬體的效能保證。

## 封裝與限制

候選1／2的獨立來源審查涵蓋資料、操作、性能及提交安全；共享模組在封鎖Qt匯入後仍可載入。歷史包也已完成檔案集合、雜湊、來源allowlist及離線啟動核對。這些包結果各自綁定原版本，不能當作候選3的封裝結果；候選3的實際封裝與啟動結果另列於交付紀錄。

本輪尚未使用真實ComfyUI、網路下載或GPU，未替換正式安裝，沒有公開上傳。原生桌面的前景／背景切換、長時排程及不同實體螢幕仍需另行核對；離屏畫面與視窗旗標無法排除所有Windows桌面情況。

完整桌面候選為含EXE、`_internal`、配套擴充與對應來源／文件的資料夾，不能只搬EXE。測試使用獨立資料；保留舊程式和原資料，回退時使用相容的原資料副本。
