# 0.8.7 候選驗證範圍

本候選以 0.8.6 修訂 12 為基礎，供本機核對。來源提交與交付檔案以包內 `BUILD_INFO.json`、`SOURCE_MANIFEST.json`、`PACKAGE_MANIFEST.json` 識別；這份紀錄區分來源操作、外觀及封裝檢查。

## 候選19：Canvas 彈窗分層與關閉操作

新增功能模組改為覆蓋目前視窗的遮罩頁，背景在 180ms 內加深、內容上移 10px 就位；點擊外側空白或 Escape 關閉，減少動態效果設定會直接顯示。內容面板沿用固定尺寸並受可用視窗範圍限制。Canvas 共用彈窗會遮暗實際開啟它的視窗；從文字選擇器新增空白模組時，底下的選擇器仍保留，取消後恢復。

新增模組及綁定頁採深色外框、較亮編輯區與深色輸入欄；命名、尺寸等簡單表單則以較亮欄位區隔外框。選單保留共用樣式，修正關閉點擊被重送到原按鈕而重新開啟的路徑。最近生成右側詳情的關閉圖示為 18px、命中範圍 36px；預排程暫停／繼續與存入素材庫共用一般操作樣式，切換淺色主題時一起更新。

- 固定產品來源 `ce27134`：132 項選定檢查通過。包含 7 項彈窗遮罩／動畫／取消／巢狀親層／選單事件／按鈕換色、12 項新增頁與堆疊、15 項文字選擇器、7 項共用浮層、27 項 Stage 參數與選項、10 項綁定、6 項最近生成、14 項來源／預覽、16 項模組、6 項更新效能及 12 項色彩檢查。
- 實際 Qt 元件、隔離合成資料、125% 倍率，共 10 張應用程式內視窗合成 PNG；涵蓋新增頁、選單、巢狀模組、綁定、命名、Stage 下拉、最近生成、暫停／存入素材庫、小視窗大字及淺色主題。這些是離屏元件畫面，不是原生桌面截圖；最近生成圖片採本地合成圖，沒有實際生成。
- 選單檢查確認外側按下事件啟用 Qt 的不重送標記，關閉後下一次獨立點擊仍可開啟。離屏平台不重現 Windows 的原生點擊重送，因此實機「再次點擊同一按鈕只收合」仍待核對。
- 初次新增測試使用抽象綁定元件及固定動畫等待時間，已改成實際 CLIP 綁定與有上限的動畫狀態等待。視覺核對另發現淺色切換後暫停／存入素材庫留用舊底色，修正即時更新並重測。最近生成套件的膠囊標籤預期落後現行 Prompt Editor 文案；已在未修改的 Candidate18 來源重現後更新預期，未將初次失敗列為通過。
- Candidate19 版本與文件索引整合後，4 項來源封裝／共享核心無 Qt 匯入檢查通過。包後離屏執行檔啟動及 ZIP／清單核對，以本批交付證據另外記錄；不能由上述來源測試推定。

本批延續 Canvas 彈出後 UI 優先順序，其它主頁按[適配順序](../../development/canvas-visual-baseline.md)另批處理。沒有原生 Windows 操作、真實 ComfyUI／GPU 或使用者視覺接受結論。

## 候選15：Canvas 繪製重用（歷史）

卡片底面、邊框及適合重用的陰影保留繪製結果；文字與操作控制仍即時以向量繪製，避免分數縮放下的文字位移。格點改為批次繪製並保留最近四組點陣。全畫布更新方式、資料格式與現有外觀不變；本批不代表使用者對 UI 風格的接受。

- 效能來源 `042fd72`：2048×1152、DPR 1.25、12 張展開文字卡與 2 張可見功能卡，離屏 Qt 事件與重繪時間。以同一程序交替原繪製／新繪製，每種操作各 90 筆：拖文字卡中位數 36.74→24.20ms、拖功能卡 35.88→24.04ms、平移 36.42→24.10ms、往返縮放 36.65→32.87ms。另各 48 筆連續放大為 38.07→34.87ms。這是合成場景中的改善，不是實體螢幕 FPS 或所有 Canvas 規模的保證。
- 影像快取分為卡面 48MiB 與陰影 8MiB 上限，另限制項目數。大型表面、半透明或不適用的變換直接繪製；連續改變縮放比例時暫停影像快取，避免建立大量一次性圖片。整體縮放仍比拖動耗時，未宣稱完全消除卡頓。
- 9 項繪製檢查通過，包含多 DPR／縮放／負座標格點、配色與操作狀態、快取容量、淘汰及縮放避讓。16 項模組、18 項滑鼠與 4 項代理邊界操作亦通過；這 38 項來自 `c37501a`，後續僅調整格點資料的重用，未修改其操作／元件繪製，相關格點像素檢查已重跑。
- `ebd1504` 實際主視窗完成 9 個畫面狀態及 5 張截圖，涵蓋拖動、滑過、改權重、Undo／Redo、平移、縮放與編輯後內容。和直接繪製的完整視區比較，每個色彩通道最大差異 2／255，限透明合成取整；文字保留即時繪製。最後僅保留更多相同格點陣列，不改點位與畫面。
- 預排程空狀態已改為「沒有等待執行的任務」，移除空佇列的「資料輸入／尚無等待項目」，保留實際數量及已暫停狀態；來源 `b7b08a7` 的空佇列與暫停／繼續核對結果沿用。

本批為本機測試候選。沒有原生 Windows 桌面流暢度、真實服務／GPU 或使用者操作接受；需以實機檢視確認感受。
