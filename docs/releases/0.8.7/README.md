# PCS 0.8.7

[版本總覽](../README.md) · [現行指南](../../guide/README.md)

## 版本摘要

0.8.7 將素材管理、文字模組與 Canvas 編輯連成同一套操作。

## 主要變化

Prompt Editor、資料夾分類與雙向收合同步、原位權重、框選與多選、Prompt 來源排序，以及四個常用模組的新增與預覽。
