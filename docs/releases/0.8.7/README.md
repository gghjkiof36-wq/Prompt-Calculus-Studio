# 0.8.7 Prompt Editor 候選

這是供本機核對的開發候選，尚未公開發布。保留自由畫布與接線，新增共用的文字素材 Editor；生成仍從畫布執行。

## 使用文字素材

畫布上方的 **素材** 開啟側欄，**Prompt Editor** 開啟全頁。窄視窗改用全頁，素材清單與編輯頁可互相切換。

1. 按「新增」，填名稱與內容，再保存。分類、別名、停用關係與預覽圖片可以稍後補充。
2. 選擇目的文字畫布後按「加入畫布」，或直接將素材拖入目的畫布。加入的是独立副本。
3. 雙擊畫布中的文字卡，微調目前副本。修改會自動保存到這份畫布；素材原件與其他副本不變。
4. 要重用修改後的版本，按「另存為新素材」。釘選只是原素材的快捷入口，不另存一份內容。

文字畫布內空白雙擊可快速輸入臨時文字；外層空白雙擊則新增功能模塊。新文字卡預設收合，舊卡片已保存的展開狀態保留。停用關係保留原詞：整卡未生效顯示灰框，部分停用顯示黃框。

「標籤」格式會整理末尾分隔逗號；長文字或 Markdown 請選對應內容格式。標籤查詢按需展開，離線仍可編輯和搜尋本機素材。舊清單保存的自動／手動內容，可從「取回舊清單內容」查看、複製或另存素材；有效的空手動稿也會保留。

## 畫布與復原

Ctrl 點擊切換選取，框選可選多項；外層框選功能模塊與容器，文字畫布內框選文字卡。多選拖曳、刪除與貼上各形成一次復原。複製的內部連線和相對位置保留，未選模塊的外部連線不複製；貼上建立新識別。

文字／圖片輸入複本保留來源設定參考，但需重新綁定唯一目的欄位。任何執行中的任務都不會複製。輸入框有焦點時，刪除、複製、貼上與文字復原仍只處理文字。

Canvas 復原最多保留 100 步，另有約 32 MB 的序列化容量界線；連續文字輸入合併為合理步驟。內容歷史保存修改前後，恢復舊版本會留下新紀錄。等待項目只有在尚未嘗試提交、來源未變且容量允許時可復原；復原後保持暫停，需明確繼續。

## Stage、圖片與顯示

Stage 未套用內容關閉時保留本機草稿；「不再提醒」不代表自動套用。明確按「套用」才改配置。綁定選單點外部關閉，不會套用當下選擇。

PNG 可讀取 ComfyUI、A1111 或 PCS 提示詞 metadata；圖片來源可選正面、負面或未判定的文字欄位，保留原文。JPEG、WebP、BMP 可作圖片使用，但此候選未新增它們的 metadata 解析。

文字輸入綁定支援原生工作流已確認可編輯的 STRING 欄位，不只限 CLIP 的 text。缺少原生能力描述的其他字串欄位，需要重新讀取工作流後才能選擇；不以欄位名稱猜測。

圖片預覽只顯示目前排程輪次，每輪的多張結果保留；歷史及下游輸出不刪除。最近生成的圖片可在較大的視窗查看。個人化可隱藏連線，接線和執行設定仍保留。

## 測試與回復

使用獨立資料目錄測試，保留舊程式與原資料。新增加的內容格式、素材關係及歷史不保證舊程式能解讀；回退應使用原本的資料副本。完整桌面候選是含 EXE、`_internal` 和配套擴充的資料夾，不能只複製 EXE。

[驗證範圍](validation.md)區分離線操作、來源與打包核對。真實 ComfyUI、GPU、安裝替換及不同實體螢幕的接受檢查尚未由本輪證據涵蓋。AI 轉換與 skill 執行仍屬後續功能，本候選只有[接入契約](../../development/087-ai-skill-contracts.md)。
