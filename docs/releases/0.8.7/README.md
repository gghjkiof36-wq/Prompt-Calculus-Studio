# 0.8.7 Prompt Editor 候選

這是供本機核對的開發候選，尚未公開發布。保留自由畫布與接線，新增共用的文字素材 Editor；生成仍從畫布執行。

## 使用文字素材

工作區左上角可在 **Canvas** 與 **Prompt Editor** 間切換，兩頁共用相同的工作區下拉選單；Prompt Editor 將它整合在原本的平面頁首列。Prompt Editor 依內容分類瀏覽可重用的文字模組；在 Canvas 雙擊文字畫布內空白處，開啟加入文字模組的挑選頁。

1. 選擇內容分類；清單顯示名稱與 Prompt 摘要。主內容欄沿用管理頁740px首選閱讀寬度，與預覽整體在工作區內居中，依可用空間收斂寬度。單擊模組，在右側查看完整名稱、Prompt 與已有的預覽圖；預覽頂部對齊搜尋欄。縮小視窗時，清單和預覽同步縮窄，預覽保持在右側，上方操作與篩選控制依欄寬換行。搜尋、操作列與卡片共用左右邊界，不需捲動時隱藏捲軸。
2. 雙擊模組、按 F2 或點「編輯素材」，開啟獨立的原件編輯視窗。「新增模組」也在這裡開始新稿。展開「進階功能」，再選「素材資訊」、「標籤查詢」、「關係與預覽」或「內容歷史」。欄位與正文在同一捲動區，保存、取消及錯誤訊息固定在底部。
3. 明確保存才更新素材原件；取消或 Esc 放棄本次視窗的修改，保留開啟前的草稿與復原紀錄。同一次程式執行期間，保存後關閉並重開編輯視窗，仍可用 Ctrl+Z／Ctrl+Y 或右鍵選單操作先前的文字 Undo／Redo。
4. 返回 Canvas，雙擊文字畫布內的空白處，選擇分類及素材；每次加入都建立獨立副本。從畫布建立新素材時，可保存並加入該畫布。
5. 雙擊既有文字卡，包括收合卡片，開啟「編輯當次模組」，保存只改這份畫布副本，素材原件與其他副本不變。

內容分類與文字模組可拖曳排序，保存後重開仍保留；文字模組在名稱或最近使用排序下拖曳，會切換成自訂順序。篩選清單時只調整可見項目，其他項目的位置保留。分類收納與左側排序另行保存，不改現有 Canvas 的文字組合順序。「全部模組」與「未分類」是固定入口；「全部模組」下方有分隔線。

候選26起，按「內容分類」右側的「＋」，在旁邊選單選擇新增資料夾或新增分類。資料夾可收納一層分類：箭頭只展開／收合，點名稱查看資料夾內所有素材；點分類則只看該分類。舊素材庫不會自動分組。選資料夾時新增的分類會放進該資料夾；從集合清單新增素材時，需明確選擇素材所屬的實際分類。

分類右側「⋯ → 移至資料夾」可選目的地或移回外層，也能拖曳分類到資料夾中央、外層列或清單末端。資料夾「⋯」可重新命名或移除；移除只解除收納，分類回外層，素材保留。選單浮在被點擊的列旁，Escape 或點外面關閉。窄窗時，分類下拉旁的「⋯」管理目前選項，「＋」仍可新增。聚焦左側分類清單或窄窗分類下拉時，Ctrl+Z／Ctrl+Y 使用既有復原／重做；文字編輯欄仍使用自己的文字復原。

文字卡片的展開／收合使用名稱右側的線條箭頭，滑過 Canvas 模組不顯示描述浮框。

在素材卡上按右鍵可編輯、釘選或另存新素材。釘選是原素材的快捷入口，不另存一份內容；Prompt Editor 的瀏覽與右鍵管理不會加入畫布。

文字畫布內空白雙擊開啟文字模組挑選頁；外層 Canvas 空白雙擊開啟功能模組新增頁。文字挑選頁包含分類、與純文字卡片同寬的搜尋欄及底部「新增空白模組」；搜尋目前分類的名稱、別名或內容。點選既有模組即加入副本；建立空白模組時取消，會返回挑選頁。標籤查詢、素材與分類管理留在 Prompt Editor。新文字卡預設收合，舊卡片已保存的展開狀態保留。停用關係保留原詞：整卡未生效顯示灰框，部分停用顯示黃框。

「標籤」格式會整理末尾分隔逗號；長文字或 Markdown 請選對應內容格式。標籤查詢按需展開，離線仍可編輯和搜尋本機素材。舊清單保存的自動／手動內容，可從「取回舊清單內容」查看、複製或另存素材；有效的空手動稿也會保留。

## 畫布與復原

功能模組新增頁可搜尋並按「文字／圖片／執行」分類。開啟時背景變暗，面板直接出現在固定位置，沒有進場動畫；點外側空白或 Esc 關閉。滑過清單項目，在右側查看節點預覽；單擊、Enter 或「新增模組」加入畫布。預覽會在固定區域內等比例縮放，切換項目不改視窗大小。目前圖片來源預覽仍省略批次控制，與實際卡片的差異待布局方案確認後一起調整。「⋯」保留依現有綁定補建 Stage 的工具。

Canvas 彈窗共用中性深灰表面與主要操作色，文字模組挑選頁沿用底部通知堆疊；開啟「減少動態效果」時使用一般清單。預覽圖片保留上一批完成結果，下一批仍在執行時不清空，收到新圖片後才更新；移除接線、換來源或換工作區則清空。

新增／編輯當次模組、文字與圖片綁定使用較亮編輯區及深色欄位；命名、尺寸等小視窗的欄位與外框也有明確色差。巢狀彈窗會壓暗後方頁面，取消後返回原頁。預排程「暫停／繼續」與「存入素材庫」共用一般操作樣式。最近生成右側卡片的關閉圖示與點擊範圍已加大，只收起詳情，不關閉圖片瀏覽。

模組名稱旁的箭頭可收合，端口、連線與錯誤仍保留；展開恢復內容及尺寸。右上「⋯」與右鍵共用操作，包含尺寸及該類模組原有的編輯、覆蓋、群組或移除功能。

權重維持「－ 數值 ＋」，點數字即可原位輸入。Enter 或失焦套用，Esc 取消；輸入過程不改值。非法內容提交後回到 1.0，超界截到 −100.0 或 100.0，加減每次 0.1。負權重可保存、重開及復原，但舊版程式可能無法讀取含負值的資料；回退請用原資料副本。

在空白處按住左鍵拖動畫布；按住 **Ctrl＋左鍵拖曳** 可框選，右鍵拖曳也可做相同框選。**Ctrl＋右鍵拖曳** 累加選取，**Ctrl＋點擊模組** 加入／取消該模組；短按右鍵仍開啟選單。Ctrl＋空白左拖未達拖曳門檻時保留原選取、不平移；開始框選後以框內結果取代原選取。外層只框選外層功能模塊與容器，文字畫布內只框選該容器的文字卡；純文字展開頁使用相同框選手勢。輸入欄、按鈕、尺寸調整與接線點優先處理自己的操作，圖片編輯工具維持原操作。

多選拖曳、刪除與貼上各形成一次復原。複製的內部連線和相對位置保留，未選模塊的外部連線不複製；貼上建立新識別。

文字／圖片輸入複本保留來源設定參考，但需重新綁定唯一目的欄位。任何執行中的任務都不會複製。輸入框有焦點時，刪除、複製、貼上與文字復原仍只處理文字。

Canvas 復原最多保留 100 步，另有約 32 MB 的序列化容量界線；連續文字輸入合併為合理步驟。內容歷史保存修改前後，恢復舊版本會留下新紀錄。只有從未開始準備／提交的等待項目可復原；工作區、連線與項目紀錄須相符，原流程未結束且容量允許。復原後保持暫停，需明確繼續。

## Stage、圖片與顯示

Stage 未套用內容關閉時保留本機草稿；「不再提醒」不代表自動套用。明確按「套用」才改配置。綁定選單點外部關閉，不會套用當下選擇。

PNG 可讀取 ComfyUI、A1111 或 PCS 提示詞 metadata；圖片來源可選正面、負面或未判定的文字欄位，保留原文。JPEG、WebP、BMP 可作圖片使用，但此候選未新增它們的 metadata 解析。

文字輸入綁定支援原生工作流已確認可編輯的 STRING 欄位，不只限 CLIP 的 text。缺少原生能力描述的其他字串欄位，需要重新讀取工作流後才能選擇；不以欄位名稱猜測。

生成圖片預覽顯示最近一輪，保留該輪多張結果；歷史與下游輸出不刪除。最近生成的圖片可在較大的視窗查看。個人化可隱藏連線，接線和執行設定仍保留。

## 測試與回復

使用獨立資料目錄測試，保留舊程式與原資料。新增加的內容格式、素材關係及歷史不保證舊程式能解讀；回退應使用原本的資料副本。完整桌面候選是含 EXE、`_internal` 和配套擴充的資料夾，不能只複製 EXE。

[驗證範圍](validation.md)區分離線操作、來源與打包核對。真實 ComfyUI、GPU、安裝替換及不同實體螢幕的接受檢查尚未由本輪證據涵蓋。AI 轉換與 skill 執行仍屬後續功能，本候選只有[接入契約](../../development/087-ai-skill-contracts.md)。
