# 0.8.7 Prompt Editor 候選

這是供本機核對的開發候選，尚未公開發布。保留自由畫布與接線，新增共用的文字素材 Editor；生成仍從畫布執行。

## 使用文字素材

工作區左上角可在 **Canvas** 與 **Prompt Editor** 間切換，兩頁共用相同的工作區下拉選單；Prompt Editor 將它整合在原本的平面頁首列。Prompt Editor 依內容分類瀏覽可重用的文字模組；在 Canvas 雙擊文字畫布內空白處，開啟加入文字模組的挑選頁。

1. 選擇內容分類；清單顯示名稱與 Prompt 摘要。主內容欄沿用管理頁740px首選閱讀寬度，與預覽整體在工作區內居中，依可用空間收斂寬度。單擊模組，在右側查看完整名稱、Prompt 與已有的預覽圖；預覽頂部對齊搜尋欄，一般桌面縮小仍保持並排，真正窄窗才移到下方。搜尋、操作列與卡片共用左右邊界，不需捲動時隱藏捲軸。
2. 雙擊模組、按 F2 或點「編輯素材」，開啟獨立的原件編輯視窗。「新增模組」也在這裡開始新稿。展開「進階功能」，再選「素材資訊」、「標籤查詢」、「關係與預覽」或「內容歷史」。欄位與正文在同一捲動區，保存、取消及錯誤訊息固定在底部。
3. 明確保存才更新素材原件；取消或 Esc 放棄本次視窗的修改，保留開啟前的草稿與復原紀錄。同一次程式執行期間，保存後關閉並重開編輯視窗，仍可用 Ctrl+Z／Ctrl+Y 或右鍵選單操作先前的文字 Undo／Redo。
4. 返回 Canvas，雙擊文字畫布內的空白處，選擇分類及素材；每次加入都建立獨立副本。從畫布建立新素材時，可保存並加入該畫布。
5. 雙擊既有文字卡，包括收合卡片，開啟「編輯當次模組」，保存只改這份畫布副本，素材原件與其他副本不變。

內容分類與文字模組可拖曳排序，保存後重開仍保留；在名稱或最近使用排序下拖曳，會切換成自訂順序。篩選清單時只調整可見項目，其他項目的位置保留。排序可復原／重做，不改現有 Canvas 的文字組合順序。拖至項目間隙仍依垂直位置顯示插入線；移出清單會取消提示與落下。「全部」與虛擬的「未分類」入口固定；「全部模組」下方有分隔線，區別可調序的內容分類。按「內容分類」右側的「＋」直接新增分類；窄窗時位於分類下拉右側。文字卡片的展開／收合使用名稱右側的線條箭頭，滑過 Canvas 模組不顯示描述浮框。

在素材卡上按右鍵可編輯、釘選或另存新素材。釘選是原素材的快捷入口，不另存一份內容；Prompt Editor 的瀏覽與右鍵管理不會加入畫布。

文字畫布內空白雙擊開啟文字模組挑選頁；外層 Canvas 空白雙擊開啟功能模組菜單。挑選頁包含分類、與純文字卡片同寬的搜尋欄及底部「新增空白模組」；搜尋目前分類的名稱、別名或內容。點選既有模組即加入副本；建立空白模組時取消，會返回挑選頁。標籤查詢、素材與分類管理留在 Prompt Editor。新文字卡預設收合，舊卡片已保存的展開狀態保留。停用關係保留原詞：整卡未生效顯示灰框，部分停用顯示黃框。

「標籤」格式會整理末尾分隔逗號；長文字或 Markdown 請選對應內容格式。標籤查詢按需展開，離線仍可編輯和搜尋本機素材。舊清單保存的自動／手動內容，可從「取回舊清單內容」查看、複製或另存素材；有效的空手動稿也會保留。

## 畫布與復原

在空白處按住左鍵拖動畫布，按住右鍵拖曳框選，Ctrl 可累加選取；短按右鍵仍開啟選單。外層框選功能模塊與容器，文字畫布內框選文字卡。多選拖曳、刪除與貼上各形成一次復原。複製的內部連線和相對位置保留，未選模塊的外部連線不複製；貼上建立新識別。

文字／圖片輸入複本保留來源設定參考，但需重新綁定唯一目的欄位。任何執行中的任務都不會複製。輸入框有焦點時，刪除、複製、貼上與文字復原仍只處理文字。

Canvas 復原最多保留 100 步，另有約 32 MB 的序列化容量界線；連續文字輸入合併為合理步驟。內容歷史保存修改前後，恢復舊版本會留下新紀錄。只有從未開始準備／提交的等待項目可復原；工作區、連線與項目紀錄須相符，原流程未結束且容量允許。復原後保持暫停，需明確繼續。

## Stage、圖片與顯示

Stage 未套用內容關閉時保留本機草稿；「不再提醒」不代表自動套用。明確按「套用」才改配置。綁定選單點外部關閉，不會套用當下選擇。

PNG 可讀取 ComfyUI、A1111 或 PCS 提示詞 metadata；圖片來源可選正面、負面或未判定的文字欄位，保留原文。JPEG、WebP、BMP 可作圖片使用，但此候選未新增它們的 metadata 解析。

文字輸入綁定支援原生工作流已確認可編輯的 STRING 欄位，不只限 CLIP 的 text。缺少原生能力描述的其他字串欄位，需要重新讀取工作流後才能選擇；不以欄位名稱猜測。

生成圖片預覽顯示最近一輪，保留該輪多張結果；歷史與下游輸出不刪除。最近生成的圖片可在較大的視窗查看。個人化可隱藏連線，接線和執行設定仍保留。

## 測試與回復

使用獨立資料目錄測試，保留舊程式與原資料。新增加的內容格式、素材關係及歷史不保證舊程式能解讀；回退應使用原本的資料副本。完整桌面候選是含 EXE、`_internal` 和配套擴充的資料夾，不能只複製 EXE。

[驗證範圍](validation.md)區分離線操作、來源與打包核對。真實 ComfyUI、GPU、安裝替換及不同實體螢幕的接受檢查尚未由本輪證據涵蓋。AI 轉換與 skill 執行仍屬後續功能，本候選只有[接入契約](../../development/087-ai-skill-contracts.md)。
