## 項目與結果

Candidate28 開發檢查38項，範圍為資料夾挑選、既有挑選、Editor收納、分類操作及封裝；另核對11個雙向切頁與保存讀取狀態、6張125% Qt畫面。這些是該固定候選的證據，不與較早批次數量加總。

各候選來源及逐批結果見[開發驗證紀錄](../development/candidate-validation.md)。發布端在固定修復整合後通過10項來源排序生命週期案例，包含同ID工作區／整文件匯入、移除來源、關閉及正常排序Undo／Redo；採用5cc8065的修正fixture，功能來源仍為62aabb4。

來源隱私／封裝6項通過，另建立來源與配套擴充，核對純快照、逐檔Hash、27共享模組及所有包清單。實際Canvas與Editor圖片重新以固定修復來源擷取，使用合成資料，服務呼叫及Qt例外均為0；僅指這次離屏擷取。

各批數量分列，不加總成整版全功能或原生Windows驗收。
