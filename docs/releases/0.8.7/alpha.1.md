# Prompt Calculus Studio 0.8.7 Alpha 1

發布日期：2026-10-13。

這版將素材整理與畫布編輯串在一起：用 Prompt Editor 管理文字模組，在 Canvas 挑選並建立副本，再調整順序、權重及生成流程。

## 新增

- **Prompt Editor**：集中搜尋、分類、釘選與編輯文字模組，支援 tags、一般文字及 Markdown。加入畫布會建立獨立副本，修改副本不會自動覆寫素材庫。
- **資料夾收納**：以一層資料夾整理分類，可展開、收合、改名及刪除。刪除分類會將素材移到「未分類」；刪除資料夾會將分類移回外層，內容保留。
- **Canvas 文字挑選**：沿用 Editor 的資料夾與分類，可搜尋所選範圍；兩頁的展開／收合狀態同步，窄窗也能辨識所屬路徑。
- **框選與多選操作**：Ctrl＋左鍵拖曳或右鍵拖曳框選；Ctrl＋右鍵拖曳累加選取。複製、貼上及刪除保留相對位置，復原不會重送已執行的工作。

## 改善

- **四個常用模組**：Prompt 輸出、圖片來源、單張載入與預排程的新增頁預覽共用正式卡片布局。圖片管理可展開；預排程順序改用明確套用。
- **Prompt 順序**：直接展開畫布來源並拖曳其中的文字模組；來源列顯示名稱與數量，清單隨內容調整高度。
- **原位權重輸入**：直接編輯卡片上的權重，Enter 套用、Esc 取消；父模組與子模組使用相同操作。
- **草稿與歷史**：切換 Editor 與 Canvas 保留目前編輯；素材原件與畫布副本分開保存，內容歷史可找回先前文字。

## 修正

修正權重輸入與舊數字重疊、收合分類重開後跳回「全部」、刪除分類後的舊引用，以及關閉 Editor 後仍到達的排版回呼。另改善 Canvas 拖曳與內容更新的反應。

## 已知問題

- **新素材加入畫布**：先在 Prompt Editor 建立並保存素材，再到 Canvas 的文字挑選頁加入副本。
- **窄窗加大字時新增頁重疊**：640×480、18pt及125%倍率下，功能模組新增頁的預覽可能蓋到名稱／說明。新增及關閉仍可操作；先放大視窗或降低字級。
- **圖片來源卡無法點開原圖**：直接點擊／雙擊卡片預覽目前不會開啟大圖，「下一張」仍可切換；需要看原圖時，先從檔案位置使用圖片檢視器開啟。
- **需保持 ComfyUI 網頁開啟**：連線燈號只表示服務可達。準備輸入時網頁未回應，先保存工作流、查看原任務再重新整理；不要連續重按執行。
- **跨分類拖放素材**：目前從分類及素材編輯入口管理，尚未提供把右側素材直接拖到左側分類的操作。
- **原生欄位不支援編輯**：特殊 serializer、子圖或種子控制可能唯讀，請在 ComfyUI 的實際供值節點設定。

## 升級注意事項

更新前保留舊程式與原資料，用副本開啟新版。這版增加素材收納、內容格式與歷史；含負權重或新欄位的資料不保證能由舊版解讀。要回退時使用原資料副本。

搭配同版 ComfyUI 擴充，更新後重啟 ComfyUI 並重新整理網頁。資料夾刪除會保留素材與分類；Canvas 副本仍是獨立內容。

## 下載與使用方式

[0.8.7 Alpha 1 Release](https://github.com/gghjkiof36-wq/Prompt-Calculus-Studio/releases/tag/v0.8.7-alpha.1)

| 附件 | 用途 |
|---|---|
| `PCS-v0.8.7-Alpha1-source.zip` | 主程式來源版，內含同版擴充與安裝腳本 |
| `PCS-v0.8.7-Alpha1-ComfyUI.zip` | 同版 ComfyUI 擴充，可供手動安裝 |
| `SHA256SUMS.txt` | 下載完整性校驗 |

安裝 Windows 64 位元 Python 3.12，完整解壓來源版，在含 `run.py` 的目錄建立環境：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py --v0.8.7-alpha
```

之後雙擊 `Start.cmd`。從「探索 → ComfyUI」選擇安裝／更新 PCS 擴充，關閉 ComfyUI 後完成安裝，再重啟並重新整理網頁。這次提供來源版，需先安裝 Python；操作見[使用指南](../../guide/README.md)。
