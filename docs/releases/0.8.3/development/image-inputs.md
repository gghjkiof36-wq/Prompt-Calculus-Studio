# PCS 0.8.3 圖片來源與預排程候選：操作及驗證

此為前次候選的歷史說明；後續修復與操作變更見 [0.8.3 執行與工作區修復候選](../repairs/repair-1.md)。

這份說明適用於「v0.83 圖片來源與預排程候選（0927）」（歷史包實際標題，對外對應0.8.3）。使用時保持 PCS、ComfyUI 服務與 ComfyUI 網頁開啟。這一版提供 Canvas 內的圖片來源、圖片輸入與預排程；AI 文字轉譯、關頁執行及跨工作流自動串接不在本次交付範圍。

## 先準備工作流

1. 換用候選包附的 ComfyUI 擴充，重啟測試服務並重新整理 ComfyUI 網頁。
2. 在 ComfyUI 開啟要使用的工作流。在 PCS 的 CLIP 輸入選取工作流及文字欄位；要採用 PCS 提示詞時，選擇「使用 PCS 提示詞」。正面、負面各用自己的 Prompt 控制及 CLIP 輸入。
3. 工作流選單共用設定中的工作流目錄；可重新整理，或先在工作流管理匯入。LoadImage 是接收圖片的節點；PreviewImage／SaveImage 是生成輸出，兩者分開選擇。
4. 本輪只使用一個目標工作流；它可以有多個 CLIP 文字欄位及多個圖片接收欄位。切換 ComfyUI 可見工作流不會改寫 PCS 的綁定。綁定原件必須能在該網頁定位；有重複或身分不明時會停止並保留資料。

## 一般操作：每次按執行增加一次需求

原本的「畫布 → Prompt 控制 → CLIP 輸入」接法保持可用。即使上一輪尚未完成，「執行」仍可按下。沒有預排程時，等待的是執行次數：真正輪到下一次提交時，才讀取當時的 PCS 內容。

例如 A 生成中，按兩次執行，然後把畫布改成 B；接下來尚未提交的工作會使用 B。它不會替兩次點擊分別保存提示詞。數字欄位設為 N，相當於增加 N 次需求。

## 圖片來源：單張、資料夾或選定的最近生成

在 Canvas 空白處的「新增模塊」選擇「圖片來源」。舊「載入圖片（單張／工作流輸出）」仍可使用。

圖片來源提供單張載入、多張選取、資料夾及最近生成選取。資料夾預設以檔名自然排序，例如 1、2、10；只讀該資料夾的圖片，不遞迴子目錄。開始前可在清單拖曳排序、略過圖片或切到指定項目。載入時保存一份來源副本，原圖不修改；清單固定後，資料夾新增或改名不會插入本批。

圖片來源有分開的輸出：

- **文字組合 → 畫布的文字組合入口**：圖片帶有有效 PCS 紀錄時，載入當時文字模塊，並保留目標畫布原有的其他模塊。只作用於這個畫布，不還原整個工作區。
- **原始提示詞 → 畫布的文字入口**：整段文字作為來源內容。沒有 PCS 模塊但有正面 metadata 時，文字組合入口也會自動採用整段回退，不拆 tags；需要修改可在 Prompt 控制輸入手動稿。
- **圖片 → 圖片輸入**：指定 ComfyUI 的 LoadImage 接收節點，不需再選一次檔案。只接圖片、不使用文字的工作流也可執行。

PNG 支援 PCS 紀錄、ComfyUI 正面欄位及 parameters 文字。JPEG／WebP／BMP 可作為圖片輸入；本輪沒有新增它們的 EXIF 提示詞解析。缺少文字或正面來源不唯一會明示，不能沿用上一張。多個正面欄位可在圖片來源選擇；不會拿負面欄位當正面。

**不接預排程**：按一次處理一張；按三次依序處理三張。前一張整個工作流完成且所需輸出可確認後，才輪到下一張。途中修改畫布或 Prompt 控制，從下一張尚未提交的圖片生效。失敗不算完成，也不會跳到下一張。

單張載入可重複作為同一張圖片使用；多張／資料夾是一份有限清單，走到底後不自動循環。要重新跑完一批，可先完成或停止原供應，再重新保存清單。

## 預排程：只保存穿過它的資料

新增「預排程」，文字通常接在 Prompt 控制之後、CLIP 輸入之前。它左右是成對的同型別端口；文字、圖片、文字組合分開連接，也可「增加端口」。要固定圖片與提示詞的配對，兩者必須通過同一份預排程。

典型放大接法：

```text
圖片來源的文字組合 → 畫布 A ─┐
其他畫布 ──────────────────┴→ Prompt 控制 → 預排程「文字」→ CLIP 輸入
圖片來源的圖片 ─────────────────────────→ 預排程「圖片」→ 圖片輸入（LoadImage）
```

Prompt 控制可以接多個畫布，使用「排列畫布來源」決定合併順序；各畫布的內容及修改獨立保存。正負面用途仍由各自的 CLIP 綁定決定。

只接提示詞進預排程時，每次按執行保存當次文字。沒有穿過預排程的負面提示詞、圖片或 ComfyUI 參數，仍使用派送時的內容。原生 seed 控制也在真正提交時生效；加入等待項目時不預先抽取或遞增種子。

有逐張圖片來源接入時，一次執行啟動整批供應：先填至最多十項，每完成一項再補一項。十項包含提交中／生成中的項目，完成紀錄另存。已保存的十項保持其內容，尚未補入的圖片使用補入當時設定。同一批供應中再次按執行不重複建立整個資料夾。

準備十項使用獨立資料內容，畫面不會為預備工作反覆跳圖。可查看來源目前圖片；手動前後切圖只改目前顯示，不改掉已保存項目。

| 模塊內操作 | 行為 |
|---|---|
| 選擇等待項目 | 查看文字、圖片、來源及狀態；工作流與來源畫布名稱在項目提示中 |
| 保存這項文字／替換這項圖片 | 只修改選定且尚未提交的項目；換圖片不暗中改保存文字 |
| 上移／下移／移除 | 只作用於等待項目，不打斷當前工作 |
| 暫停 | 當前工作完成，停止派送及補入 |
| 取消目前 | 只要求取消這個 PCS 工作，保留並暫停後續；不清空原生佇列 |
| 繼續 | 明確恢復派送及補入；未確認項目須先核對 |
| 停止這批後續供應 | 清除尚未加入的供應需求；已保存項目及當前工作保留 |
| 處理失敗項目 | 已確認失敗的項目可重試或略過；不會重送結果不明的提交 |
| 已完成紀錄 | 查看保存文字，並打開該項工作的整批圖片結果 |

手動暫停後再按執行，只增加需求，不自動恢復。沒有預排程的一般需求可由底部「繼續」恢復；圖片來源也有自己的暫停、繼續與停止供應控制。

## 中斷、刪除與舊紀錄

關閉網頁、斷線或重開 PCS 後，保留等待內容並先核對已提交任務，由使用者按繼續。提交結果不明不自動重送。錯誤提示會區分資料缺失、綁定變動與未確認結果。

移除或斷開預排程只隱藏／暫停，不刪除工作。可立即復原刪除；重開後也可從「任務紀錄 → 保留的預排程／舊紀錄」顯示或恢復模塊，接回原工作流和資料來源後再繼續。畫布 undo／redo 不提交生成。

舊整份工作流快照留在同一處閱讀，未自動改成新版預排程。生成歷史、手動空白稿、原本 Prompt 綁定及圖片紀錄保留。

## 人工驗證清單

候選包附固定提交、自驗紀錄及雜湊。自驗使用合成圖片、離線原生回執模型及 Qt 離屏畫面，不代表實際 GPU／ComfyUI 網頁通過。

1. **普通執行**：生成中連按三次，修改提示詞，確認後續使用派送時的文字；完整完成後再按第一次就能開始。再試中途取消與繼續。
2. **圖片來源**：用三張有不同正面 metadata 的圖片，不接預排程；按一次只完成第一張，再按兩次完成餘下兩張。中途改手動稿，確認下一張使用新內容。
3. **固定與即時輸入**：正面穿過預排程，負面直接到 CLIP。保存 A、B、C 後修改畫布；正面照保存內容執行，負面使用派送時內容。未經預排程的 ComfyUI 參數也應更新。
4. **超過十張**：資料夾放十三張以上，文字及圖片通過同一預排程。確認始終最多十項、完成後補入、不重複批次、沒有漏圖、圖文配對正確。
5. **控制**：暫停、改等待項目、排序、移除及取消。當前完成不應暗中恢復；取消不能停掉另外從 ComfyUI 手動提交的任務。故障不得算成功換圖。
6. **metadata 與多畫布**：PCS 圖片恢復文字模塊；普通 PNG 使用完整正面文字；無資料不沿用舊文字。兩個畫布合併順序正確，保留其他畫布及手動空白稿。
7. **原生種子**：固定、隨機、遞增、遞減，分別驗證原生前／後控制，每輪只作用一次；加入等待項目不改原生種子。
8. **工作流及結果**：Anima／ill 均驗證；切換可見工作流不改綁定；LoadImage 可以選取；綁定輸出節點能顯示同一任務的整批圖片。
9. **中斷與往返**：斷線／關網頁／重開先核對任務並暫停，等待資料保留；移除模塊後恢復、保存再開、undo／redo 均不多送一輪。

回報測試項目、使用工作流、出現訊息及實際結果即可。真實原生網頁與 GPU 結果由人工驗證確認後，再決定後續交接。
