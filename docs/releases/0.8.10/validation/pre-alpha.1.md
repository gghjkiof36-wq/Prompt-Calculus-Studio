# v0.8.10 Pre-alpha1 本機修正

此工作樹沿用 v0.8.10 Pre-alpha1 的版本名稱，包含 2026-11-02 的本機後續修正；不表示已公開發布的來源或執行檔已更新。包內 BUILD_INFO 與來源清單記錄實際建置來源。

- 文字模塊的變體前後切換循環，沿原交易保存與復原。
- 預排程批次支援優先、繞過／恢復、取消及拖曳排序，卡片／清單顯示執行中狀態。
- 新快照使用 formatter 3。主程式與 ComfyUI 配套採相同文字規則；歷史格式精確核對並保留原最終文字。既有失敗紀錄不自動重送。
- Stage 與畫布通知省去重複的重送說明，保留實際原因與原紀錄。

已完成隔離的排程派送、取消回覆、歷史快照及背景啟動檢查。這些結果不代表真實 GPU 生成或已運行的 ComfyUI 載入新版；配套更新須先保存工作、關閉後端，再更新並重新開啟。沒有在測試中修改使用者文件或要求真實生成。
