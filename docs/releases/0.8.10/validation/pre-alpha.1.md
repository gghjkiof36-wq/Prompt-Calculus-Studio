- 較早全文上下文、空稿及文末起稿的 115 項，屬 `d12b9d5` 的歷史證據，未在本次加總或當作全新版重驗。

## 使用限制

模型可能遺漏原意或生成錯誤，尤其潤飾不能只看語句流暢就視為完整保留資訊；請逐段審閱候選再按「保留」。上下文不足會回報，不以靜默截斷替代全文。思考上限依引擎及模型支援，不支援時需使用可用設定。

目前加入單檔 GGUF 引用及既有資料夾掃描，不包含任意分片模型支援、引擎自動安裝／更新或模型網路搜尋下載。圖片附件的保存／查看不代表文字模型具備視覺理解能力；外部 API、工具自動執行與多模型並行不是本版能力。

選取用浮動輸入框可能暫時覆蓋後文，固定來源與前版文件區逐像素相同，未列為本次新回歸。表格、公式、嵌入內容保留各自語意排版，不承諾與 Markdown 原文逐行對齊。

FPS 計主視窗的重繪批次，不是螢幕呈現更新率、模型 tokens/s 或測量器自身計時；閒置 0 屬預期。完整 Windows IME、不同 DPI／GPU、全部模型及正式安裝未全面驗收；離屏與替身檢查不代替它們。

## 發布核對

本次來源及配套的具體身份以 Release、BUILD_INFO、SOURCE_MANIFEST 與 PACKAGE_MANIFEST 為準。新增相對路徑 `Start.vbs`／pythonw supervisor／無 console 子程序；發布檢查涵蓋新旗標正確進入 WorkspaceShell、來源包入口與相關啟動失敗記錄，不啟動真模型或改動使用者原資料。

沒有新的 PCS binary Git head，不公開完整 PCS EXE、模型、registry 或獨立推理 runtime。Chrome 0.2.7 配套按其既有來源／binary 身份核對；它與 PCS 主程式的版本分列。
