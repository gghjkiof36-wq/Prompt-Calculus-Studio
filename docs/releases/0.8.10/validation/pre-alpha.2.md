# 0.8.10 Pre-alpha2：驗證與限制

## 本次來源與範圍

本次功能來源為 `b1d63af9bd767124f1a96bb2fa7886667e4b5043`，涵蓋工作資源、對話轉 Markdown、Skill／專案／Agent、Windows 本機委派，以及累積的介面與性能修正。發布整合保留既有相對來源啟動入口；來源包、ComfyUI 配套與獨立 Chrome 0.2.7 配套分別記錄來源和校驗。

## 已有驗證

- 工作資源涵蓋文件導覽、對話選取與逐份輸出、同名保留、取消、部分失敗及原件保存。Skill／Agent 涵蓋版本與來源範圍、管理副本、角色來源、工具核准、停止及聊天保存歸屬。
- 本機委派已有命令端、Windows pipe、既有 Agent、單槽及普通聊天 writer 的回歸與小型真模型任務；成果與實際來源可按任務 ID 查回。一般模型任務的品質需另看下列限制。
- 最新性能批有 100 個不同回歸案例，作者背景自驗後由規劃組核對來源與原始證據。固定負載下，Prompt／Canvas 反覆開關的 host 數各由 31 降至 1；40,000 字富文字投影中位約 179.3→87.7ms，相同壓力串流的 Qt 收件 p95 約 532→86ms。這些數據對應該負載與程序範圍。
- 冷暖模型對照沿同一引擎程序，等待主要在模型思考；本批沒有推論提速結論。前景／GPU 繪製、全天與大型資料集仍待後續驗證。

## 使用限制

- 長篇程式流程、對話分支和行號引用仍有模型錯誤。T04／R04 及後續固定短案未完成一般語意品質驗收，請核對來源再採用。
- Skill 目前用於讀取與參考，scripts／hooks 暫不執行。Agent 工具為已設定範圍內的唯讀操作；本機 AI 使用單一工作槽。
- Windows 同使用者本機委派需由專案明確啟用。正式 ChatGPT／Claude 任務轉接及多工作排隊尚待後續版本；下方 A01 只涵蓋獨立的合成連接。
- 完整 A15、全天資源趨勢、前景／GPU、原生 IME／多螢幕與新機安裝仍有驗證缺口。較長任務的實際耗時依模型、上下文及硬體而異。
- 更新先備份並使用資料副本；來源紀錄、模型輸入、附件和原始封存可能含私人內容。

## 第一階段合成連接歷史

本版提供可單獨啟動的 PCS 合成測試實例與 MCP 工具。工具讀取兩筆測試資源、建立即時完成的任務，並以任務 ID 查回帶有來源範圍的結果。重試可沿用同一把冪等鍵。配對的 Windows 實例保存回執。

共同契約 v1 涵蓋資源、資料包、Skill 與 Agent 修訂、任務和候選結果。架構、啟動方法、官方 MCP 客戶端操作方式與外部宿主條件見[第一階段連接契約](../../../development/mcp-probe-v1.md)。

2026-11-03 已在一個實際 ChatGPT 網頁帳號通過合成連接 A01。以私人外掛和 Secure MCP Tunnel 0.0.19 連接 Windows 測試實例，ChatGPT 四次呼叫分別列出兩筆資源、建立任務、按 ID 查回及查詢不存在的 ID。聊天取得的任務與成果 ID、文字及來源範圍與本機回執相符。查無任務時，這次宿主在外層顯示 INVALID_ARGUMENT，內層保留 PCS 的 not_found。驗收對應程式來源 `d5619e2`，只涵蓋此私人帳號與合成資料。獨立 SDK 測試另驗證重試、取消終態、保存、重開及實例隔離。
