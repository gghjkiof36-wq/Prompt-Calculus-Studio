## rev171 實機範圍

2026-11-18 的獨立實機驗證使用一份固定工作流，一次 Canvas 執行，產生兩筆不同任務、每筆四張原圖。第一筆開始後中斷 PCS，ComfyUI 完成後再重啟後端，保留原生頁面。當時 history 空、原暫存網址均為 404。重開 PCS 後第一筆八張中的前四張收齊，第二筆自動送達並完成；八張本機原圖的順序與 SHA256 逐一相符。

日常 8188 服務另核對 Desktop 與瀏覽器的原生工作流讀取及重新選取，該輪沒有生成。發行來源承接這些已驗修正，公開包以乾淨 Git 組建並另核來源、manifest、配套及啟動。
