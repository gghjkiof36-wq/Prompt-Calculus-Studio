# Prompt Calculus Studio 0.8.2 Alpha 1 Repair 5

首次發布日期：2026-09-27。

## 改善

- 整合清單、Canvas、模型與圖片管理；CLIP 可選用 PCS 文字或 ComfyUI 手動文字。
- 生成前套用綁定的文字與圖片，保留其他未綁定的 ComfyUI 欄位。
- 整批圖片並排或網格預覽，點圖放大；修正較晚到達的舊縮圖覆蓋最新結果的問題。
- 預覽拔除圖片接線後清空，最近生成紀錄獨立保留；擴充版本不相容時提示更新。
- 改善清單操作、工作流選擇與重新連線。

本版每次執行一個工作流，使用時需保持 ComfyUI 網頁開啟。。

## 升級注意事項

使用同版 PCS 與 ComfyUI 擴充；更新擴充後重新啟動 ComfyUI 並重新整理網頁。重建或核對這一版時，以發布頁固定標籤內的說明為準。
