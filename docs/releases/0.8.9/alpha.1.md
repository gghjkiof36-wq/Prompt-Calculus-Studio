# 0.8.9 Alpha 1 更新內容

[開始使用](../../guide/workspace-089.md) · [驗證與限制](validation/alpha.1.md)

Markdown 筆記、Canvas 工作流與 Prompt 分類現在可以在同一個視窗開啟，分頁也能左右並排。內容保存在本機資料夾，從「內容」加入其他資料夾後即可瀏覽與編輯。

## 修復與新增

- Markdown 支援編寫與閱讀切換、搜尋／取代、大綱、連結、圖片、表格、數學式、圖表及 PDF 匯出。原文與閱讀畫面共用文件；`Ctrl+Shift+V` 可貼上純文字。
- 改善提示框的字體、位置與首次顯示，統一選單邊緣及項目高度，修正重按選單按鈕又打開的問題。`Alt+Space` 使用一致的視窗選單。
- 修正清晰透明材質，將視窗透明度控制的 100% 對應到實際最多約 30% 透出背景；保留清晰、Acrylic、Mica 切換。選單透明度可調至 50%。
- 修正窄視窗時的分頁寬度、左右分隔拖動及從設定返回分頁只顯示一側的問題。
- Prompt 素材拖入 Canvas，起始時經過其他功能模組也能繼續拖到可放置位置。
- 收合內容側欄後，游標靠近左側會暫時展開，離開後收回。浮動側欄使用完整圓角表面，不擠動文件或 Canvas。設定中可關閉自動展開，或分別調整展開與收回延遲。
- 保存時檢查原檔版本與父資料夾身份，處理外部修改及資料夾被替換的衝突，保留可取回的草稿。切換筆記根時丟棄舊索引結果；關閉視圖也會取消對已關閉視圖的延後更新。
- 大型 Markdown 分段載入、背景解析閱讀內容及外部檔案更新，搜尋分批處理；減少不必要的全文掃描與隱藏視圖排版。

## 仍待改善

- 接近 8 MiB、包含大量短段落的文件，首次閱讀仍可能短暫卡頓；複雜內容完整呈現可能需要數秒。此次改善沒有消除全部大型文件延遲，8 MiB 上限未調低。
- 實體上下鍵放開後的延遲手感、特定原生退出、完整輸入法／DPI／媒體編碼組合仍有待確認範圍。
- 舊版資料請保留原件，以副本試用；完整舊資料庫導入與所有歷史任務的接受範圍尚未全部閉合。不要把新版資料直接交回只支援舊格式的程式。

詳細驗證區分程式自驗、獨立複驗、原生環境與發布附件；不將本機通過視為所有環境通過。
