# Prompt Calculus Studio 0.8.9 Beta3

2026-10-23。本機開發交付，待使用者驗收；沒有本版公開下載或正式安裝替換。

本版延續 Beta2 的貼上與對話匯入，增加三項流程：

- 保存演示原檔、靜態預覽、明確選取的依賴及來源；缺失可重新指定，修訂與 Undo 保留舊附件。
- 查回原問答與分支，將所選分支分段複製到 ChatGPT，貼回後編輯內容、按需查看原文、保留釘選，另存整理稿。
- 預覽目前文件、所選對話分支與附件，輸出資料夾或 ZIP，在新根建立獨立副本並重新開啟。

對話整理分為「原對話／ChatGPT 整理／整理稿」。整理清單直接顯示內容，原文按需展開；分類與對照記錄收在「項目選項」。窄窗可從頂端選單切換項目；預覽後按「編輯項目」返回會保留手改稿，內容更新時可選「保留編輯」或「重新產生」，重新產生也可復原。

閱讀[完整操作步驟](../../guide/markdown-retention.md)、[技術接點與資料界線](../../development/markdown-retention.md)及[驗證與限制](validation/beta.3.md)。已有依賴的來源環境可用 `python run.py --v0.8.9-beta.3 --root <獨立筆記位置> --data <獨立資料位置>` 啟動。
