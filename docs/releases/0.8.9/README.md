# 0.8.9 Alpha 1

[更新內容](alpha.1.md) · [開始使用](../../guide/workspace-089.md) · [驗證與限制](validation/alpha.1.md) · [版本索引](../README.md)

此版將 Markdown 筆記、Canvas 與 Prompt 管理整合到本機分頁工作區。這份資料對應待發布的 0.8.9 Alpha 1；公開附件與發布日期以 GitHub Release 實際紀錄為準。

公開來源套件不含 Python 或 Qt 執行環境。Windows 桌面成品與來源套件分開交付；Windows 成品目前僅供本機使用，尚未完成第三方執行環境的公開散布材料核對。
