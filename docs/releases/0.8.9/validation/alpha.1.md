# 0.8.9 Alpha 1：驗證與限制

2026-10-20。此紀錄對應 0.8.9 Alpha 1 的交付候選，來源提交及成品身份另由 `BUILD_INFO.json`、來源清單及成品清單固定。

## 已完成的自驗

使用 Windows Python 3.12.5、PySide6 6.11.2、合成資料與獨立資料目錄，核對了：

- 保存衝突、父資料夾替換防護、草稿回復、引用整理及 PDF 保存。
- 筆記根切換後舊索引結果不能操作新根中的同名檔案。
- Markdown 載入、編寫／閱讀切換、搜尋、Undo、原文保存及視圖提前關閉。
- 側欄的展開／收回、選單與編輯期間保持開啟、釘住、設定持久化及 Canvas 幾何不變。
- 側欄在首頁、設定、圖片、探索及匯出頁，以及深淺配色、100%／125% 比例下的離屏畫面。

保存防護與視圖生命週期的較早修復已有獨立複驗。其後的父資料夾固定身份、新側欄與背景載入變更有開發端驗證，仍待對最終固定版本的必要獨立複查；此頁不代替該複查。

## 性能

同一台主機、同一執行環境及固定合成文件，觀察「呼叫返回」「內容完成呈現」與 GUI 最長停頓，而非只量背景工作的排程時間。

| 樣本 | 觀察結果 |
| --- | --- |
| 約 12 KiB 一般文件 | 開啟至可用約 143 ms，搜尋約 15 ms；無明顯新增負擔。 |
| 約 300 KiB 複雜文件 | 首次閱讀最長 GUI 停頓由約 3.97 秒降至約 0.32 秒；完整呈現仍約 3.5 秒。 |
| 接近 8 MiB、約 30 萬短段落 | 開啟最長 GUI 停頓由約 2.34 秒降至約 0.29 秒；完整載入約 2.83 秒。首次閱讀仍有約 1.15 秒停頓，未結案。 |
| 接近 8 MiB 長行 | 搜尋最長 GUI 停頓由約 0.60 秒降至約 0.11 秒；搜尋完整完成約 1.33 秒。 |

上述為局部測量，並非承諾所有硬體或文件達到相同速度。資料與 Undo 檢查通過；首次 WebEngine 初始化及大型文件仍有延遲。

## 尚未閉合

- 大型文件性能需求仍未全部通過，不能宣稱已完全消除卡頓。
- 三份舊設定介面測試含過時外觀假設或逾時，已在變更前固定版本重現；沒有用修改現行介面來使舊斷言通過。
- 原生鍵盤手感、全部輸入法／DPI／材質／媒體組合、新機安裝與真實 ComfyUI／GPU 不由離屏測試代替。
- Windows 成品的完整第三方通知、對應來源、重建／替換及 Microsoft 執行環境材料尚待發布端核對，不能由專案來源授權推定已完成。
