# 0.8.9 Alpha 1：驗證與限制

2026-10-20。功能來源與 EXE 實際編譯提交為 `3e7b29fae16b5acd23a8f320ef2ad8954e49ae50`（R3）；後續公開文件整合提交另由來源及成品清單記錄。本頁整理現成證據，不表示已發布。

開發端使用 Windows、Python 3.12.5、Qt 6.11.2 及隔離合成資料。下列自驗與獨立結果各有固定來源，重疊方法及重跑次數不相加。

| 範圍 | 已有結果 | 尚未確認的部分 |
| --- | --- | --- |
| 保存衝突與共享視圖關閉（089-002／003） | r1 已修，原提報組分別完成保存複驗及關閉回呼確認；R3 另有相關回歸自驗 | r1 的原組結果不擴成 R3 全部新增差異或完整原生操作通過 |
| 保存期間父資料夾保護（089-006） | r2 修復的 98 個方法自驗通過，R3 保留相同保護。原安全提報組在固定 R3 獨立執行兩個既有必要方法，2 通過、0 跳過：父資料夾替換遭拒、根外未落草稿、原文與候選可取回，以及正常保存後清理 | 此項必要確認已通過；更廣的目錄／競態檢查仍屬開發自驗，不涵蓋 UNC、其他檔案系統或全部新差異 |

## 大型文件性能仍未通過

同機、同執行環境與固定合成文件分開量測內容完成呈現及 GUI 最長停頓：

| 樣本 | 觀察結果 |
| --- | --- |
| 約 12 KiB 一般文件 | 開啟至可用約 143 ms，搜尋約 15 ms |
| 約 300 KiB 複雜文件 | 首次閱讀最長 GUI 停頓約 0.32 秒，完整呈現仍約 3.5 秒 |
| 接近 8 MiB、約 30 萬短段落 | 開啟完整載入約 2.83 秒；首次閱讀最長 GUI 停頓約 1.15 秒，比同樣本 r2 的約 0.52 秒更差，M18 仍未過 |
| 接近 8 MiB 長行 | 搜尋最長 GUI 停頓約 0.11 秒，完整搜尋約 1.33 秒 |

大型量測在正式入口整合前的固定功能來源完成，最後側欄監聽調整另核小檔；不外推為所有文件或硬體的速度承諾。剩餘性能修復延後作 Alpha 已知限制，保留 8 MiB 支援上限，不寫成全部消除卡頓或完整性能驗收。

## 仍保留的限制

- 物理上下鍵滑行感仍未重現／待確認；未知原生退出的原因未定，不與已修 timer 或共享視圖回呼合併結案。
- 完整文件語意、舊素材庫接受，以及全部輸入法／DPI／材質／媒體組合尚未閉合；選定情境通過不代表完整矩陣接受。
- 新機安裝、真實 ComfyUI／GPU 與使用者既有安裝更新不在上述確認範圍內。原失敗、舊快照及未驗項保留，不宣稱全倉全綠。

## 成品與公開範圍

來源、EXE 編譯與後續文件整合身份分列；包內清單及雜湊用於確認內容，不能代替實際操作驗收。公開範圍為來源、通用／legacy／modern 三配套及 SHA256 校驗檔，實際發布狀態以發行紀錄為準。

Windows 成品盤點有 308 個原生檔案，`public_allowed=false`，僅供本機。完整第三方通知、對應來源、重建／替換及 Microsoft 材料尚未閉合，沒有 Windows 公開下載。
