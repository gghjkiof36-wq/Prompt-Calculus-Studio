# 0.8.9 Alpha 1 Repair 1：驗證與限制

2026-10-20。歡迎頁與新建 Canvas 的功能來源為 `2f1e044f0730fb347ebf522ee0d76c5eb5a9b50a`。本次另整合公開說明、教材打包及修正版身份；實際來源提交由包內 `BUILD_INFO.json` 記錄。未發布 Windows 執行檔。

## 本次確認範圍

- 在固定功能來源及獨立資料完成 4 個歡迎頁、3 個新建 Canvas 方法：首次開啟歡迎、指定文件優先、恢復分頁、既有內容不被補寫，以及新建六模組、刻意清空與原件保留。
- 固定本機 EXE 的三個離屏啟動情境通過：首次開啟歡迎、指定左右文件、既有內容根。這些結果只適用於 `2f1e044` 編譯的本機包，不冒稱修正版重新編譯或原生操作驗收。
- 教材可閱讀、編輯、保存及重開；關閉歡迎頁後恢復其他分頁。連結與圖片另核實際成品，來源 ZIP 補齊教材模板及組裝工具。
- 本次公開成品逐檔核對來源／交付清單、ZIP 路徑、完整性及 SHA256。配套共用核心保持原 Alpha 1 的 34 個模組，另以禁止 Qt 匯入的包內檢查確認。

以上是選定範圍確認，不代表全倉、乾淨安裝或所有操作通過。修正版打包與來源檢查不把既有不同提交的測試數量相加。

## 沿用的限制

原 Alpha 1 的保存衝突、共享視圖關閉與父資料夾保護證據、舊索引複驗缺口，以及大型文件效能結果見[原版紀錄](alpha.1.md)。這次沒有修改這些行為，沒有把原本未過的性能項改記通過。

接近 8 MiB 且含約 30 萬短段落的樣本，原量測首次閱讀最長介面停頓約 1.15 秒；複雜文件完整呈現可能需要數秒。完整舊資料庫導入、全部輸入法／DPI／媒體、新機安裝與真實 ComfyUI／GPU 仍有驗證缺口。

Windows 本機成品的第三方通知、對應來源、重建／替換與 Microsoft 材料尚未閉合，仍不公開散布執行環境。公開來源版不包含 Python／Qt 執行環境。
