2026-10-23。本頁記錄本分支的 MD 演示、原問答／人工 ChatGPT 往返及可攜包增量。來源基於公開 Beta2 加開發指南提交 `c1aa825969f2dd01e2e8135f4f1653527f13abb6`，本批實作與本頁一同保存在 Git；本版未公開發布或替換正式安裝。

環境為 Windows、Python 3.12.14、PySide6 6.11.2、markdown-it-py 4.0.0，使用隔離資料和 Qt offscreen。合計 **77 個測試通過**，不重複加總修正前的多次執行：

| `test_md12_retention.py` | 17 | 原件／修訂、分支範圍、分段與回覆綁定、候選保存、附件追溯、ZIP／目標替換及失敗反例 |
| `test_md12_interface.py` | 6 | 真實 WorkspaceShell 離屏插入／保存／Undo／Redo／重開、查回釘選／人工往返／手改保存、可攜重開、過時回呼、深淺色／窄窗 |

另有非作者的限定資料／安全邊界複驗。已報反例涵蓋正文與未選分支不一致、文件改名搬移後的分支判定、整理稿附件及重複擷取身份、目標被替換、混合修訂、原檔與預覽共用路徑，以及建立父目錄前的身份檢查；修正後必要反例通過。這是合成邊界證據，沒有擴張為獨立完整 UI 或發布驗收。

## 單次本機量測

以下是固定合成資料的一次執行，未控制 OS 快取，也不是跨版本 A/B 性能接受。所有來源、輸出及清理均在測試暫存範圍。

| 樣本／操作 | 結果 |
| --- | --- |
| 1,000 則主分支訊息＋1 則另一分支，867,104 bytes | 載入 0.024 秒、已載入搜尋 0.004 秒、分段 0.007 秒，24 段 |
| 10,000 則主分支訊息＋1 則另一分支，8,728,606 bytes | 載入 0.195 秒、已載入搜尋 0.041 秒、分段 0.069 秒，233 段；逐段涵蓋 3,648,890 字元 |
| 302 個來源檔，共 8,695,861 bytes | 演示準備 2.162 秒、保存及讀回核對 4.091 秒 |
| 可攜 306 檔，共 8,791,175 bytes | 準備 4.603 秒、資料夾寫入與核對 6.201 秒、ZIP 寫入與核對 0.132 秒、ZIP 新副本寫入與核對 6.494 秒 |
| 首次保存進度回呼提出取消 | 約 0.005 秒到安全停止；沒有完成回執，原件與已完成輸出保留 |
| 整個量測程序的 peak working set | 約 132.7 MiB，包含各個階段，不等於整個產品的峰值或容量保證 |

準備階段已移除逐檔累積檢查中對先前內容的重複雜湊，最終清單和寫後驗證仍完整執行。多個本機檔案的準備／保存仍需數秒，背景工作顯示進度並在檢查點處理取消。上述取消時間不代表最慢單檔寫入或所有硬碟條件。

## 驗證界線

- ChatGPT 功能依本版選擇採人工複製／貼回。測試使用明示的合成回覆，不是實際 ChatGPT 整理結果，沒有模型語意正確率或自動壓縮端到端結論。登入串接另排。
- 人類決定、提案、局部取代與未解問題仍由使用者逐項查原文核對。引用有效不代表內容語意正確；多分支不提供自動差異合併。
- 原生 Windows IME、DPI、跨應用剪貼簿、鍵盤／焦點全流程及真實帳號封存仍待驗。離屏測試不能代替這些情境。
- 未完成全產品 UI 暫停／首幀性能量測、近容量上限／磁碟滿／所有權限與檔案系統競爭情境。外部服務、ComfyUI／GPU、正式安裝及全倉回歸不屬本輪有效結論。
- HTML／SVG 靜態依賴掃描不能證明動態網站完整離線可用。外部開啟交給使用者的預設程式；本輪未以真實專案或第三方普通 Markdown 閱讀器全面驗收。
- 本包排除已知設定／憑證／診斷路徑，合法選取的原文和附件本身仍可能含私人內容。沒有任意內容機密掃描功能。
