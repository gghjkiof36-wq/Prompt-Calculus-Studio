## 效能與異常退出

Markdown 渲染、段落格式及搜尋刷新減少部分重複處理。作者指定暖樣本曾觀察到收益；本輪沒有獨立性能 A/B，不把比例寫成所有文件都會變快。大型閱讀、貼上及大量 JSON 仍可有數秒或更長等待，全文呈現與首次可操作時間分開判讀。

特定完整關閉恢復套件在 GC 退出時仍有未釐清異常，不能用局部替身正常退出解除。已重現的 CivitAI 預覽排版路徑修復，不代表其他退出原因都已排除。

## 邊界與相容

- 文件交易共用既有歷史及 Undo／Redo；內容提交成功不等於其後磁碟保存必然成功。恢復未成功落盤時保留視窗與稿件，仍需使用者另存到可寫位置。
- 備份以舊檔移至恢復位置、再發布新 ZIP 兩步進行，有檔名空窗；不是單次 atomic replacement 或 CAS，也不保證所有檔案系統與外部競爭情境。
- 收圖的 32 MiB 是優化擷取界線，超過沿原 importer，並非最大匯入檔案限制。Stage 的 25 MiB 是單份來源捕獲上限，不是整體 RSS 上限；沒有跨操作全域快取。
- 外部服務封套目前接入 CivitAI 既有連線測試、搜尋及版本詳情。未增加模型／AI／skill 自動執行，也未把所有 ComfyUI 或 Manager 操作改成該封套。
- 本輪本機診斷啟動器調整為需取得 GIL 的有界 Python 心跳；原生程式長期占用 GIL 時也可能無法產生快照。該本機診斷 BAT 及私人日誌不隨公開包附送，不將它描述為下載包新增入口。
- 完整原生 Windows 輸入法、系統剪貼簿、DPI、真服務／GPU、正式安裝與全部舊庫相容仍有驗證界線。離屏、合成資料、限定靜態檢查與逐檔 hash 不代替它們。
- Windows 執行環境的第三方通知、對應來源與重建／替換材料仍未閉合，沒有 Windows EXE／ZIP 公開下載。

資料格式及路由識別沿用；新版本名稱不代表資料格式遷移。公開提供來源、通用／legacy／modern 三配套及 SHA256，實際身份以 `BUILD_INFO.json`、`SOURCE_MANIFEST.json`、`PACKAGE_MANIFEST.json` 及 Release 紀錄為準。
