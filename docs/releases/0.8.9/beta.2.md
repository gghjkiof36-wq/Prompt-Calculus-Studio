# Prompt Calculus Studio 0.8.9 Beta2

Beta2 著重保存、恢復、匯入與備份的可靠性，也減少 Markdown 閱讀和圖片來源處理的重複工作。原有筆記、Prompt 素材、Canvas 及 ComfyUI 操作繼續保留。

## 修復的內容

- **保存、恢復與關閉**：修正接受恢復稿後又被舊狀態覆蓋、重試關閉時碰到已關閉資料庫，以及收藏位置偏好影響保存／另存的問題。輸入法提交後仍在組字，或原檔／刷新失敗且恢復副本未落盤時，視窗保持開啟，保留稿件與目前 Undo。正常保存、恢復成功與明確捨棄仍沿原流程。
- **匯入部分完成**：後段附件損壞、CRC 或解壓縮失敗時，先前完成的對話與完成紀錄保留，畫面回報實際部分結果。
- **備份取消與失敗**：新 ZIP 驗證完成前保留舊健康備份；清理只處理本次持有的檔案，不覆蓋其他程式晚到的檔案。恢復位置保持可讀，長訊息可捲動到結尾並複製全文。
- **Markdown 閱讀與搜尋**：減少純文字渲染、段落格式及同查詢刷新中的重複處理；上／下筆仍逐次執行。修正大型文件 lazy 排版後的末段捲動範圍與游標。
- **筆記資料夾範圍**：巢狀筆記的讀取與投影改在背景處理。新增或移除有效根後，拒收舊範圍結果；可見頁延遲刷新，隱藏頁返回時更新，原文、未保存修改與歷史不因範圍更新而被改寫。
- **收圖與來源歸屬**：雜湊、解碼、附加資訊及縮圖共用同一次擷取的內容；相同 ID 的圖片內容更新仍會處理，已接受的工作回到原文件，另存後不混用收藏歸屬。
- **CivitAI 與回覆更新**：修正已重現的預覽排版退出路徑；更新或清除 Token 後，過期搜尋、詳情與預覽回覆不再改動目前畫面與快取。首次私有寫入前的父目錄保護也一併修正。

## 這次的內部整理

- 文件內容修改共用同一個交易提交入口，沿用原驗證、內容歷史、Undo／Redo 與保存通知，減少不同畫面各做一套提交。
- 背景工作明確區分完成、取消及失敗；過時的閱讀結果拒收，已完成寫入的回執則交回原歸屬，避免清理或關閉時遺漏已接受的工作。
- CivitAI 現有連線測試、搜尋與版本詳情使用共用請求／回覆及安全錯誤格式，保留原認證、傳輸與過期檢查。
- Stage 同次操作共用已驗證的來源內容、SHA 與附加資訊，各 Reader 仍獨立投影，保留選擇、覆寫、循環及輸出順序。

## 下載與啟動

從[本次 Release](https://github.com/gghjkiof36-wq/Prompt-Calculus-Studio/releases/tag/v0.8.9-beta.2)下載：

| 附件 | 用途 |
|---|---|
| `PCS-v0.8.9-Beta2-source.zip` | 來源主程式、歡迎頁、教材、同版配套與安裝腳本 |
| `PCS-v0.8.9-Beta2-ComfyUI.zip` | 通用配套 |
| `PCS-v0.8.9-Beta2-ComfyUI-legacy-0.39.2.zip` | legacy 相容設定檔 |
| `PCS-v0.8.9-Beta2-ComfyUI-modern-0.40.0.zip` | modern 相容設定檔 |
| `SHA256SUMS.txt` | 下載完整性校驗 |

本次沒有 Windows EXE 公開下載。來源版需要 Windows 64 位元 Python 3.12；完整解壓後，在 `run.py` 旁開啟 PowerShell：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py --v0.8.9-beta.2
```

首次安裝依賴後可雙擊 `Start.cmd`。更新前保留舊程式、配套及原資料，以新資料夾和內容副本試用；搬移時同時保留 `files` 與 `data`。ComfyUI 配套三擇一，更新前關閉後端，完成後由你重新啟動並刷新工作流網頁。[開始使用](../../guide/workspace-089.md) · [配套相容](../../guide/comfyui-compatibility.md)。

## 使用前留意

- 大型文件、貼上及大量 JSON 仍可能停頓。局部樣本改善不代表所有文件或硬體都有相同加速。
- 備份替換分兩步搬移，原檔名可能短暫不存在；中途失敗時先檢查訊息中的恢復位置，勿反覆覆寫唯一備份。詳見[備份與回退](../../guide/data-backup-privacy.md#備份與回退)。
- 舊版匯入輸出不會自動清理。重新匯入另存，保留手改筆記，分享前檢查原始紀錄與附件。
- 異常退出仍有未釐清情境；完整原生輸入法、DPI、舊資料庫、真實封存及 ComfyUI／GPU 尚未全面驗證。
