# Prompt Studio Alpha：單張圖生圖

2026-09-13。此版延續文字 Canvas，新增清單與 Canvas 共用的生成面板。這不是 1.0.0 正式版；圖片拼排、色塊底圖與逐區生成尚未加入。

## 使用流程

1. 在清單或 Canvas 組好提示詞，最終 Prompt 仍可編輯為手動稿。
2. 在最終 Prompt 下方選「圖生圖」。清單會顯示來源圖片；Canvas 會在最終 Prompt 左下側建立拼接的圖片模組。也可先拖圖到畫布，再拼接到 Prompt。
3. 到「設定 → ComfyUI → 連線與工作流」匯入或拖入 JSON。支援 API 格式及已知標準節點的畫布格式；自動辨識生成方式與欄位，存在多個可能對應時再指定。文生圖與圖生圖分別記住工作流。
4. 在設定中按「參數…」調整工作流可寫入的值，再返回按「運行」。Canvas 直接預覽、儲存目前圖片，點「最近生成」開啟浮動內容面板；清單使用原本的最近生成頁面。
5. 想拿結果再生成時，主動按「導入圖生圖」。也可從媒體庫選圖；目前 Prompt 不變。

換來源圖、切換生成方式、匯入工作流都不改目前 Prompt。圖片的提示詞或模組組合只能經「載入圖片的提示詞／組合…」明確載入。生成完成不自動更換來源圖。清單與 Canvas 的選項／手動稿仍依原本的分離設定運作，生成方式、工作流與來源圖共用。

清單模式下，右側空間不足時可以捲動；Canvas 中可放大最終 Prompt 模組或縮放畫布。圖片預覽會依模組大小縮放。已拼接圖片時可以暫切文生圖，來源圖仍保留。

## 工作流與實際生成值

- API JSON 可直接使用；標準畫布 JSON 先轉換為後端格式。未支援的自訂節點或子工作流需先匯出 API。保留模型、負面提示詞、節點與接線，僅改綁定的文字、圖片與參數欄位。
- 支援標準 LoadImage、KSampler，以及 ImageScale、EmptyLatentImage、EmptySD3LatentImage 的直接輸入。接線控制的參數不覆寫。其他工作流可選擇沿用原參數，但需自行指定有效文字欄位與來源圖。
- 對應 KSampler 時會檢查文字是否連到正面條件、來源圖及尺寸節點是否連到該採樣器。多個採樣器可選擇其中一個控制，不宣稱已涵蓋所有自訂節點或多階段工作流。
- Denoise 初始值沿用匯入工作流，不固定為 0.8 或 1。Seed 支援完整 64 位元整數，選擇固定、批次內逐次遞增或每次隨機；每次提交的實際 Seed 留在任務紀錄。
- 沒有尺寸節點時沿用來源圖／工作流的處理，不自動插入縮放節點。工作區「建議值」不會覆蓋生成參數。
- 匯入並選定工作流後可直接呼叫 ComfyUI 後端，不依賴網頁；需更新為本包對應的 Prompt Studio ComfyUI 擴充並重啟後端。「目前 ComfyUI 網頁工作流」會自動恢復該工作流的文字綁定與桌面控制。

## 原圖、紀錄與備份

選圖時保存原始位元組副本及 SHA-256，不修改原圖；支援單張 PNG、JPEG、WebP、BMP，最多 25 MB、四千萬像素。每次點擊運行即固定當時的 Prompt、工作流、參數與來源圖，之後的編輯只影響下一次運行。上傳到本機 ComfyUI 的 input/prompt_studio 目錄，保留工作流要求的影像處理方式。

「設定 → ComfyUI」的「任務紀錄」顯示最近 100 次提交及當次 Prompt／實際參數。資料庫保留最近 200 筆已結束任務；未確認的任務不自動重送。來源副本、工作流與紀錄包含在完整 ZIP 備份中；JSON 索引不含圖片位元組或任務紀錄，移機請使用完整備份。

生成狀態以輪詢顯示提交、佇列、生成中、完成或失敗，尚無逐步百分比。停止沿用 ComfyUI 的全域停止，目前生成可能來自其他介面；右鍵可連同待執行佇列清空。網路中斷或提交結果不確定會停止後續批次，不自動重試，以免重複生成。重新連線會核對既有任務。

若 ComfyUI 完全沿用快取且沒有新圖片輸出，會明確提示，不把舊圖的 Metadata 改成新紀錄。只支援目前安裝的後端所接受的工作流；尚未宣稱官方桌面版相容或多人構圖品質。

## 驗證範圍

已有自動化測試涵蓋 Prompt／來源圖保留、完整 Seed、工作流對應、提交後修改、取消後的延遲回覆、重啟後任務核對與 ZIP 備份。隔離 ComfyUI CPU 測試實際經過圖片上傳、API 佇列、PreviewImage、PNG Metadata、最近生成、主動重用、後端拒絕與停止生成；不代表模型畫面品質測試。

已讀取 D 槽的「illustrious v1.0」文生圖及圖生圖 JSON，確認格式轉換與正面文字、圖片、採樣器對應。模型生成品質仍待實測，不以 CPU 流程測試代替。
