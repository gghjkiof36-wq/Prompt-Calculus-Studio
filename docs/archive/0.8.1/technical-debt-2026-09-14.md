# 技術債與處理條件

更新：2026-09-14。

| 項目 | 證據／影響 | 保留與處理条件 | 驗收 |
|---|---|---|---|
| 已消除：工作流重複刷新／同步 | `GenerationPanel.changed` 現在經範圍協調器 | 即時局部操作與 350 ms 保存保留 | 20 次快速修改合併；不增加提交；Notes、布局不做無關同步 |
| 已收束：手動稿、文字綁定入口 | `drafts.edit/clear`、`multi_output.set_binding` 共用 | 一般設定仍可由 UI 更新；不全面引入狀態框架 | 多入口、清單／畫布隔離、undo／redo、原文檢查通過 |
| 已移出 UI：舊資料遷移 | `state_loading.prepare_state` 負責載入、JSON、快照入口 | 1–4 文件與歷史格式仍保留；相容表見 DATA_COMPATIBILITY | 保存／重開／ZIP 副本及歷史快照往返通過 |
| HTTP 查詢取消 | urllib 讀取最多等待 timeout；取消阻止回寫但不立即中斷 socket | 圖片已用 Qt 可中斷請求；搜尋快取、debounce 先緩解 | 不把取消誤報成功，不顯示過期結果；後續替換傳輸層須獨立測試 |
| 未成年主題資訊不完整 | 來源 minor／tags／name 才可辨識 | 不聲稱可以識別未標記圖片年齡 | 已標記內容被排除，成人與未成年類別不混為一談 |
| 已集中：版本專用建置分支 | `releases.py` 描述版本、路徑、啟動器及共享依賴 | 舊旗標保留；不是回到當年來源 | 舊旗標映射、來源清單、共用模組及 EXE 檢查通過 |
| 保守 Prompt 通知 | 舊 `changed()` 呼叫者未全部改為細分範圍 | 尚未證實可縮小的呼叫維持原行為，避免漏同步 | 後續逐項分類須證明 Prompt、生成及復原不變 |
| 模型檔案識別快取 | size／mtime 用於避免每次重新 Hash | 不是針對惡意保留 metadata 的檔案竄改防護 | 安裝時核對 Hash；後續需要強制重新辨識時另加明確操作 |

原有未知歷史變更來源已封存，沒有刪除。未經實機驗證的項目只列限制，不以離線模擬宣稱通過。
