# 0.82 Alpha 1 Repair 3

本批處理三個可見問題：PCS 新增文字後，ComfyUI 必須等執行才更新；最近生成及 PCS 預覽已有圖片，ComfyUI 預覽仍為空；Prompt 輸出清單不能直接刪除項目，右鍵選單在縮放畫布後偏離點擊處。

## 操作結果

- 已綁定的 CLIP 文字會跟隨 Canvas 新增、刪除、停用、排序及手動稿更新，不需按執行。沿用桌面 350 ms 延遲保存，網頁可見時每 500 ms 查詢，通常在停止編輯後約一秒內更新；不是零延遲。隱藏頁面、切換工作流和未完成的讀取會避免重複或過期回寫。
- 圖片仍由 ComfyUI 後端的實際任務結果提供。對應工作流的 PreviewImage／SaveImage 經前端原生輸出事件更新，不需要從網頁再跑一次。重複讀到同一結果不重繪，節點重建或下一張結果則更新。
- 在 Prompt 輸出「目前組合」選取文字項目，可用 Del／Backspace 或右鍵「刪除選取項目」刪除。操作指向清單項目，不跟隨畫布上先前選中的其他卡片；沿用既有刪除及 undo／redo，素材库原件不受影響。手動稿啟用時，原本停用的自動組合清單仍保持停用。
- 清單右鍵位置會經過嵌入元件、場景、縮放／平移、視窗四層座標轉換；選單接近螢幕邊緣時仍由 Qt 避免超出畫面。

## 根因與相容邊界

Repair 2 的文字來源是已提交 queue/history，所以只能呈現上一次提交。現在既有 workflow/run-state 另外讀取已設定桌面資料庫的目前保存狀態，使用共用 bound_texts 編譯已綁定欄位；没有新增另一份資料庫、生成佇列或常駐桌面服務。舊 API 的預設素材庫回應不附帶連線設定。

目前文字與任務快照用途分開：即時文字只改網頁已綁定欄位，沒有寫回已排隊 payload、PNG 或歷史。工作流按完整路徑／原生 ID 或 PCS 交換身分對照，並核對伺服器、桌面工作區與資料庫；同名、重複或無可靠身分時不猜測。未綁定欄位、模型、參數、連線及排版保留。開著子圖時暫停這条根節點同步，避免同號節點寫錯；返回根圖後繼續。

若網頁手動改了受控欄位，或把該欄接成輸入線，會保留網頁編輯並提示衝突；PCS 生成仍以 Canvas 為準，沒有宣稱雙向編輯。此版只有網頁實際觀察到空綁定後才清除受控基線，不能保證隱藏期間解除再綁定必定重新接管；該接管語義仍待決，不能以重新整理網頁作為安全接管步驟。斷線、解除綁定或目前資料讀取失敗，不會拿上一個任務文字補回已清空的欄位。

圖片問題已核對使用者當時實際載入的前端 **1.43.18**。該版 app.nodeOutputs 是舊資料物件，直接寫子項不會通知目前的圖片 store；Repair 2 只檢查舊物件，漏了實際顯示入口。Repair 3 使用實際識別的後端結果發送 executed，沿用 ComfyUI 的 setNodeOutputsByExecutionId、顯示節點定位與 onExecuted。版本依據是 [1.43.18 官方 app.ts](https://github.com/Comfy-Org/ComfyUI_frontend/blob/v1.43.18/src/scripts/app.ts)，並與現機靜態 bundle 對照，不以最新 main 代替安裝版本。

清單問題有兩個入口错误：刪除動作读取場景選取而非清單目標；QWidget.mapToGlobal 未包含 QGraphicsProxyWidget 的畫布變換。這次共用轉換函式也用在嵌入的舊組合樹選單，沒有改全域縮放或選单造型。

## 更新及驗證

需要更新 Repair 3 桌面版與 comfyui_prompt_calculus_studio 擴充，重啟 ComfyUI 後端並重新整理網頁。原 local_library.json 及個人資料保留；旧／新名稱擴充不可同時載入。這次提供新包及更新原資料啟動入口，不代為停止程序或覆蓋實際安裝。Repair 2 包與原入口備份保留。

- qa/082-repair3-regression.log：81 項 Python 回歸，涵蓋服務保存狀態／綁定、刪除及復原、縮放定位、兩次圖片更新、A→B、歷史與既有封裝核心。
- qa/082-repair3-js.log：27 項 JavaScript 回歸，涵蓋無任務即時文字、空稿、手寫衝突、切圖、圖片原生事件與隱藏／停止後無查詢。
- qa/082-repair3-native-handler.log：離線執行現機 1.43.18 的實際 executed handler，確認已識別圖片送到輸出 store 入口；store 本身使用隔離測試替身，此項不等於實際瀏覽器渲染驗收。
- qa/082-repair3-list-visual.log：Qt 離屏實際彈出選單，在 0.7 倍縮放下位置與點擊座標一致，選單刪除與復原通過；已檢視 list-window／list-menu 兩張離屏圖。
- 新 EXE 的隔離資料啟動、保存及兩包版本／來源／逐檔 SHA256 校驗，隨 build/082_DELIVERY.json 登記。沒有將 qa/preview-data 或私人圖片用於測試或封裝。

仍待實機確認：ComfyUI 安裝後的網頁顯示、原生 Windows 選單／多 DPI、GPU 生成及先前卡死的原始觸發原因。無新增依賴或資料格式遷移；保留不開網頁生成，沒有自動重送或重啟 GPU。
