## 本輪範圍與背景執行評估

使用者選擇先完成單工作流修復，跨工作流仍暫擱。一次 PCS 執行對應一次目前原生工作流的提交；ComfyUI 節點的 batch_size 可以大於 1。PCS 多輪暫不開放，工作流順序設定保留，可保存與 undo/redo，但本候選不執行多工作流。

ComfyUI 後端能執行 API 圖，不代表它已持有網頁尚未存檔的最新狀態。舊候選未完成可靠的關頁狀態接管；直接回到已保存的 JSON 會重現參數不一致。本輪停止自動背景回退，要求保持已綁定的 ComfyUI 工作流網頁開啟；沒有唯一對應的網頁時明確拒絕提交。這是本候選的取捨，不是宣稱背景執行在原理上不可行。

## 已修復

- CLIP 新增「使用 PCS 提示詞／使用 ComfyUI 手動文字」，預設 PCS。選擇可保存與復原；手動模式保留網頁文字，包括刻意清空。初次綁定的既有網頁文字不再阻止明確選擇的 PCS 同步。

- CLIP 綁定視窗可選同一工作流接收 PCS 圖片的 LoadImage 節點。只有 Prompt 有圖片接線才套用選定圖片；寫入原生 LoadImage 後同樣核對提交內容。圖片輸出節點的綁定及多圖片明確選取繼續保留。

- 舊擴充或舊網頁尚未支援新綁定協定時，提示更新，防止忽略文字命令後仍執行。視窗標題明確標示「Repair 5（0927 綁定修復候選）」。圖片上傳使用 prompt_calculus_studio 資料夾；外部擴充資料夾沿用 comfyui_prompt_calculus_studio。
