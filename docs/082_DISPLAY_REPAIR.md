# 0.8.2 顯示修正（2026-09-14）

使用者於 5d1f03e 預覽後提供九張截圖、十四項修正。以下是已處理的顯示問題；跨工作流排程與圖片綁定已由後續提交實作，見 082_WORKFLOW_IMAGES.md。主要倉庫仍為 0.8.1，不以本文件宣稱已整合。

## 共用尺寸還原

- `refresh_layout` 曾把未存尺寸的功能模組設為 `[0,0]`，完整 `attach` 卻套用各模組預設，移動與完整刷新因此呈現不同大小。所有可縮放卡片現在透過 `restore_size` 讀取已存尺寸或該類預設；重設尺寸、undo 也用同一路徑。
- `TextCard.update_text` 曾以固定 `panel.height()+60` 比較所有子類，忽略各種接點標頭高度。實際外框改跟隨 proxy geometry；內容刷新不再以錯誤高度觸發額外排版。
- 圖片模組的「接到 Prompt」按鈕原先在算完最小尺寸後才隱藏，造成新建首次移動再縮小。可見控制項及圖片內容在計算前確定。新增回歸測試先抓到 351→320 的首次縮小，修正後通過。

資料中的 `text_sizes` 格式不變，未存尺寸的文件仍按既有各類預設開啟，不批次回寫使用者尺寸。

## 經常復發：透明視窗上的拖曳殘影

既有 Canvas 場景已使用 FullViewportUpdate 與不透明 viewport，但浮動執行列是 viewport 的 QWidget 子元件，移動不會觸發場景物件更新。因此執行列移動、隱藏時也須使 viewport 重繪，以清掉原位置，沒有常駐重繪計時器。

後續檢查浮動面板、通知、拖曳工具列，必須同時驗證 QWidget 子元件與 QGraphicsItem；只測場景節點不能代表工具列。原生 Windows 驗收：在淺、深背景、多種 DPI 下連續拖曳、停下、隱藏，原位置不能留圓角邊或文字殘影。

## 雙擊素材面板閃爍

移除面板 opacity effect 的啟用／動畫／停用切換，並在第一次顯示前設定視窗幾何。遮罩每次繪製維持同一暗度，避免先顯示最終暗度又回退動畫起點。開啟、關閉與查詢取消沿用原有生命週期。

## 介面修正

首次選擇頁仍顯示 Canvas／清單，Canvas 在上並預選；不再一次覆寫既有介面偏好。Prompt／CLIP 內的重複名稱輸入移除，名稱仍可由右鍵更改。CLIP 按鈕開啟工作流→CLIP 節點選擇，支援選取非當前工作流；保留各工作流既有綁定並防止占用欄位。工作區或工作流在開窗後改變，拒絕過期套用。

素材採简单卡片，分類取消逐項底線；主欄引導線縮短為 200 邏輯像素，Prompt splitter 僅畫中性一像素細線，保留九像素拖曳命中區。設計參考 Microsoft [Divider](https://fluent2.microsoft.design/components/web/react/core/divider/usage) 與 [Card](https://fluent2.microsoft.design/components/web/react/core/card/usage) 的分組與單一物件容器用途，實作延續現有 Qt 版面。

雙擊面板新增「功能模組」分類，操作沿用 CanvasFunctions 同一組建立動作，包含畫布、Prompt、CLIP、加載圖片、預覽圖片。新增位置、單次關閉與 undo 與素材入口一致。圖片名稱已修正；跨工作流圖片與完整排程於下一個功能提交處理。

`qa/082-ui-corrections.log` 38 項中 37 項通過，新增 picker 用例發現 Qt QVariant 無法按值尋找 Python tuple；修正為 Python 值比較後，該用例單獨重跑通過（0.665 秒）。已檢視更新後 `qa/082-palette.png`、`qa/082-flow.png`。完整跨工作流未在這批宣稱完成。
