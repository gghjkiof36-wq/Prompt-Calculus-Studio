# 單一 ComfyUI 工作流關頁執行候選

本輪只處理 illustrious v1.0，同一原生 ID 與檔案路徑；跨工作流仍暫擱。PCS 的正常 GenerationRunner 入口保持不變。

網頁正常開啟時，仍由原生 queuePrompt 執行。網頁將目前完整視覺圖、API 圖及可核實的原生種子控制狀態交給 Service 的 BackgroundState 保存。僅正常 pagehide、沒有未確認請求、最後完整內容與已確認版本相同時才釋放編輯權；心跳失聯不能代替這個交接。

沒有原生頁面時，正常執行入口只可使用已釋放的最新版本，經 ComfyUI 自己的 /prompt 路由驗證及排程。真 prompt_id、實際入列圖和不可變收據核對後，才保存原生種子控制的下一個顯示狀態。PCS 文字來源變更、未確認關頁、服務重啟或不明提交結果均拒絕使用舊檔案補跑。

重新開啟原網址時，在原生第一次載圖之前取得已確認版本，載入同一 ComfyWorkflow 物件。保留真正磁碟 baseline 與未儲存標記，不改寫工作流檔。已在進行中的真任務透過已核對的原生 execution store 登記，再接收伺服器觀測到的同 prompt 事件。初始狀態與後續事件使用訂閱 ID、序號、原生工作流、節點連線及另一個活動任務檢查。不存在從圖片或計時器製造執行事件的路徑。

## 目前範圍

- 僅已核對的 ComfyUI 0.21.1 / frontend 1.43.18；原生私有 bundle 以 SHA-256 限定。
- 僅已核對的標準八節點形狀（七種 class，一個 KSampler）。其它自訂 hook、子圖、bypass 或未知種子狀態保留網頁執行。
- 正常關頁後可執行；服務重啟及異常關頁的明確恢復入口尚未提供，不能宣稱任意斷線可恢復。
- 遺失提交回執會標記不確定並避免重送；不以重送猜測是否成功。
- 執行完成後才開頁不重播正在執行動畫，結果仍可由任務歷史查看。

## 驗證界線

核心交易/種子、正常執行路由、關頁指紋、冷開恢復及事件隔離已有離線測試。它們不代替真實 Windows 關頁、中途重開、KSampler 進度與兩張圖片的驗收；真實結果另記於本輪 QA 報告。
