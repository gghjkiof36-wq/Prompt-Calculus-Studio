## 責任與資料流差異

以前 UI 的 changed、局部刷新與工作流面板各自安排副作用；現在經 `ChangeCoordinator` 合併。Prompt 才安排同步；位置、比例、Notes、次數與一般設定避免無關編譯。畫面刷新不會發起生成。

以前主編輯器與每份輸出自行改手動稿、兩個綁定視窗自行移除綁定；現在共用 `drafts` 和 `set_binding`，仍使用原 Canvas 交易及復原紀錄。`Catalog.update_identified_models` 原本已按當前檔案身分合併來源，`GenerationRunner` 原本已凍結提交並核對批次，本輪驗證並沿用，不新增平行狀態。

以前 refresh_builder 可能遷移舊 Canvas 分類；現在 `prepare_state` 在資料入口產生驗證副本。只有確認新狀態可讀後，才備份并保存；不支援資料報錯而保留原文件。快照最後仍驗證歷史文字，已排隊的任務不使用最新 Prompt。
