# Prompt Studio 0.5

可直接使用的 Windows 本地桌面程式。素材庫、模組組合、模型管理、圖片庫與工作區設定都能離線操作，不會載入模型權重或啟動 AI 推理。

0.5 新增獨立 ComfyUI 側邊欄擴充：綁定工作流 text 欄位、模組直接更新 Prompt、挑圖一鍵收藏、每次生成保存模組快照。桌面圖片庫可讀取快照，並備份目前狀態後恢復歷史組合。安裝與操作請看 [ComfyUI 整合說明](COMFYUI_GUIDE.md)。延續 0.4.3 的獨立輸出排序，以及目前圖片內嵌資料的簡潔顯示。

0.4.3 將右側組合排序獨立保存，右側拖曳不改左側模組順序。新加入的群組依左側位置插入，例如第一項 LoRA 插到最上方，第二項 Artist 插到第二項；目前項目不足時放到末尾。已在右側的群組保留手動順序，取消整組再加入時重新依左側位置插入。

0.4.2 在「設定 → 外觀 → 視窗材質」選取 Acrylic 後，顯示 0–100% 透明度滑桿與數值欄；數值越高，模糊背景越明顯，文字區維持深色。調整可預覽，取消恢復原設定，儲存後下次開啟沿用。「清除內容」確認視窗新增「不再提示」；勾選並確認清除後生效，取消不記住。可由「設定 → 外觀 → 操作確認 → 清除手動內容前先詢問」恢復提示。

0.4.1 將主視窗改為 Windows 原生外框，移除與背景合成衝突的分層視窗和自訂圓角遮罩。最小化、最大化／還原、關閉均由系統繪製，玻璃區提高透明度。保留 0.4 的手動版本、清除／儲存位置、複製回饋及收合過渡，以及 0.3.1 的非阻塞選單修正。

單一螢幕睡眠喚醒後偶發的介面縮小，依使用者意見列為次要追蹤項目。目前補入顯示變更／恢復啟用後的字型與排版重新整理，尚未重現實際睡眠情境，不能視為已完全解決。

## 開啟程式

雙擊 **Start.cmd**，或開啟 **release/PromptStudio/PromptStudio.exe**。封裝版本不需要另外安裝 Python。`_internal` 是必要的執行檔案，請勿單獨搬走 EXE。

移機時複製整個 `release/PromptStudio` 資料夾。它是免安裝版本，資料保存在同層的 `data`。外部連結的圖片與 ComfyUI 模型仍需保留原路徑，或在程式內重新指定。

## 提示詞頁

1. 左側選模組，中間點選項目，右側即時產生完整 Prompt。
2. 模組可新增、改名、刪除，拖曳改變輸出順序；各模組可設定單選／複選。
3. 提示詞項目可填中文名稱、實際內容、別名、備註及可選的預覽圖。
4. 在模組、素材項目或右側組合按右鍵，可複製、編輯或取消選擇。模組有「複製已選」與「複製全部」兩種操作。
5. 中間素材區的輸入框同時搜尋素材，並提供 Tag 候選。選候選會加入「臨時片段」，不必先存進素材庫；也可手動輸入後按「加入片段」。
6. 直接修改右側 Prompt 後，顯示「正在使用手動版本」，上方組合淡出並停用。按文字框上方紅色「清除內容」，確認後清除手動稿並恢復組合；已選模組與臨時片段保留。自動組合時「清除內容」為灰色停用。
7. 拖動分隔線調整預覽大小，或收合模組／已選項目。較大字級搭配矮視窗時，先收合選擇區以保留輸出空間。
8. 自動組合時，右側「目前組合」可直接拖曳群組名稱，調整整個模組的位置；「臨時片段」整組也能移到其他模組之前。提示詞可在同一群組內排序，右鍵亦有向上／向下移動，或使用 `Ctrl+↑`／`Ctrl+↓`。這些順序會保存並立即反映到自動組合。
9. 滑鼠懸停在已選項目上會顯示移除按鈕。拖曳到組合區的上／下邊緣時會自動捲動。
10. 「存入素材庫」位於最終文字框上方，與「清除內容」並列；窄視窗會自動換行。複製成功時按鈕短暫顯示「✓ 已複製」，不彈出視窗。

快捷鍵：`Ctrl+F` 搜尋、`Ctrl+Shift+C` 複製完整 Prompt、`Ctrl+,` 設定。候選用滑鼠或方向鍵選擇，`Enter`／`Tab` 接受，`Esc` 關閉。

## 模型管理

「選擇資料夾」指定 ComfyUI 的 **models 根目錄**。本機已確認的位置：

```text
D:\ComfyUI_windows_portable_nvidia\ComfyUI_windows_portable\ComfyUI\models
```

目前讀取 `loras`、`checkpoints`、`diffusion_models`、`unet`，包含子資料夾。Diffusion 額外標示，避免把分開載入的模型都誤稱為 CKPT。

- 每個檔案可填易懂名稱、分類、觸發詞、網址與備註；文字自動保存。
- 分類可新增、排序、改名或移除。改名會更新現有模型，刪除分類會將模型歸入「其他」。
- 預覽圖自行選擇或移除，只保存壓縮縮圖，不修改來源圖片，也不在 models 資料夾塞入圖片。
- 「匯入模型檔案」將已下載檔案**複製**至選定子資料夾。原檔保留、同名不覆寫，背景複製可取消。
- 「移至資源回收筒」先顯示名稱和完整路徑，確認後操作**實際模型檔案**。回收失敗、檔案變更、路徑不符或檔案鎖定時停止，不降級為永久刪除。
- 模型移走或回收後，說明與預覽保留並標示原檔不存在。從 Windows 還原後重新掃描即可。
- 掃描只讀檔名、大小和修改時間，不載入張量，不計算大檔案雜湊。

沒有自動從 Civitai 下載、辨識用途或抓取圖片。照原本習慣在網站下載，再從程式匯入即可。外部新增或移動檔案後，按「重新掃描」。

## 圖片庫

- 「新增資料夾」建立應用內的相簿，可按日期、角色或系列命名。
- 可一次加入多張圖片，也可加入磁碟資料夾**本層**的圖片，不遞迴匯入整顆磁碟。
- **預設連結原圖**，另外建立最長邊 512 px、品質 85 的 JPEG 縮圖。可勾選另存原圖副本，方便移機。
- 每頁最多 60 張縮圖。只有選取圖片時才讀完整生成資料，不把整個圖片庫的原圖和工作流同時載入 RAM。
- 相簿移動不會搬動外部原檔。移除圖片紀錄也不會刪除原圖。
- 原圖搬動後可重新連結。請選同一張圖片，原有手動附註會保留，內嵌資料重新讀取。

PNG 如含有 ComfyUI 的 `prompt`／`workflow`，會保留原始內容，並列出可辨識節點中的提示詞、模型、LoRA、CFG、步數、採樣器、Seed 等值。多個採樣器或文字節點分開呈現，不擅自判斷正向／負向或合併參數；間接連線及自訂節點不保證能解析。「查看原始生成資料」可檢視完整保留內容。

**圖片內嵌參數**與**手動附上的工作區建議**分開顯示。只有按下「附上目前工作區資料」，才複製當下 Prompt 與參數建議；之後改動工作區不會回頭改掉已附註的圖片。程式不會把最近複製的 Prompt 自動當成圖片實際生成參數。

JPG／WebP 可預覽，目前尚未解析其 EXIF 生成參數。缺少內嵌資料的圖片仍可備註及手動附上工作區資料。

## 工作區與版本

左上角選擇工作區，旁邊的「⋯」集中提供設定、新增與刪除。「工作區設定」保存固定模組、CKPT／Diffusion、LoRA 與權重、CFG、步數、採樣器、調度器、Denoise、Seed 和備註。

- 勾選「以目前選擇更新固定組合」後儲存，才更新固定模組的預設選擇。
- 切換工作區只還原固定模組，其餘模組、臨時片段和手動稿保留。
- 模型建議可手動填，或從已掃描模型庫選取。
- 參數改動會保存歷史版本，可加說明，再將舊版本帶回編輯並另存一版。
- 目前是**建議參數**，不會改動 ComfyUI 工作流的生成參數；擴充只更新明確綁定的文字欄。

## Tag 補全與中文

英文候選已接 Danbooru 文字 API。輸入 `simple` 可選 `simple_background`；輸入 `@ap` 只查繪師。插入時可設定成空格格式，繪師可選自動加 `@`。此工作區接受過的候選會記錄使用次數，供常用排序及離線補全。

停止輸入約 0.6 秒後查詢，請求間隔至少約 1.1 秒，同時只有一個請求。有逾時、過時結果丟棄及本地快取。**沒有背景全量抓取詞庫，也沒有全量 CSV 匯入。** 可在設定完全關閉聯網。

中文先查「設定 → 個人字典」，每行一個對照，例如：

```text
白色的牆壁 = white wall
一個女孩 = 1girl
紅色衣服 = red clothes
簡單背景 = simple background
```

在新增提示詞的編輯框接受候選，會自動補上 `, `；上方快速輸入框接受候選，則直接加入臨時片段並清空輸入，方便接著打下一個詞。

**建議先一次輸入一個概念，再選候選。** 英文句子翻譯和可靠的 Tag 拆解是兩件事；這版不會把任意中文段落自動標成已驗證 Tag。

Google Cloud Translation 官方介面已準備，可在設定填自己的 API 金鑰；僅在本次程式記憶體保存，不寫入 SQLite／JSON。**尚未使用真實 Google 金鑰完成端到端測試。** 需自行開通服務，可能計費。預設使用個人字典與 Danbooru 名稱查詢；沒有內建免費 Google 網頁爬取或本地大型模型。

聯網只送出目前輸入的片段，不上傳圖片、模型或整份素材庫。快取只保存候選文字。

## 外觀與性能

設定可選字型、介面／Prompt 字級、舒適／緊湊間距、中性灰白／霧藍／柔綠，以及實色／Mica／Acrylic 材質。

0.3 統一主內容黑底、圓角素材卡片與按鈕，限制超寬螢幕的內容寬度並保留兩側留白。新增／命名、編輯與確認使用應用內視窗；選擇磁碟檔案仍使用熟悉的系統檔案挑選器。滾動條完整設定滑塊與軌道色，避免原生樣式的同色與格紋。右鍵選單統一留白；次要按鈕在懸停時才顯示邊界。

主面板維持黑色，使用 Windows 系統背景效果，沒有每張卡片各自做即時模糊。Mica 主要帶入桌布色調；Acrylic 的背景模糊較明顯。效果受 Windows 版本、透明設定與顯示環境影響，不支援時使用實色。

檔案工作最多一個背景執行緒，網路候選另有一個；閒置時不持續掃描資料夾或播放動畫。圖片解碼有配置限制，過大的圖片可能無法建立預覽，原檔不會被修改。

本機 Windows 實際視窗測試：讀取 21 個模型索引、建立 6 張測試縮圖、切換頁面／彈窗與字級後，約 191 MB 工作集、102 MB 私有記憶體；模型清單掃描約 0.026 秒。這是原始碼版的小型資料集測量，並非大量圖片或封裝版的固定上限。工作集包含可共用的程式元件，不能與私有記憶體相加。未載入 AI 模型或使用 CUDA。

## 資料與備份

封裝版保存在 `release/PromptStudio/data`：

| 位置 | 用途 |
|---|---|
| `studio.sqlite3` | 模組、Prompt、工作區、模型說明、圖片索引、快取、設定 |
| `thumbnails` | 壓縮預覽圖 |
| `originals` | 勾選另存副本時保存的原圖 |
| `before-import-*.sqlite3` | 資料庫備份 |
| `error.log` | 發生錯誤時的除錯記錄 |

「資料 → 匯出 JSON」保存文字與檔案索引，不內嵌圖片或模型檔。「匯入 JSON」先驗證並詢問是否取代索引，自動建立匯入前資料庫備份；不搬動外部檔案。JSON 匯入上限 64 MB，較大資料庫使用 ZIP 備份。

「備份資料庫與圖片副本（ZIP）」包含一致的 SQLite 快照、縮圖及應用內原圖副本。外部連結原圖與 ComfyUI 模型需另外備份。還原時先關閉程式，另存目前 `data`，再把 ZIP 裡的 `data` 放到 EXE 旁。

移除紀錄或更換預覽後，舊縮圖／副本暫不自動永久清除，以免舊備份失去引用；目前還沒有清理未引用圖片的工具。

## 修改與除錯

原始碼在 `prompt_studio`。改完先執行 `run.py` 檢查，再重新封裝。直接改 `.py` 不會更新舊 EXE。

| 檔案 | 用途 |
|---|---|
| `core.py` | Prompt 組合、字典規則、SQLite 保存、預設項目 |
| `window.py` | 主畫面、模組、素材庫、剪貼簿、資料選單 |
| `dialogs.py` | 設定、提示詞編輯、工作區、模型分類 |
| `pages.py` | 模型管理、圖片庫畫面 |
| `media.py` | 檔案操作、縮圖、PNG 參數、分頁索引 |
| `theme.py` | 色彩、間距、字體、Windows 材質 |
| `views.py` / `widgets.py` | 素材卡片繪製、拖曳排序、圓角彈窗與共用控制項 |
| `completion.py` / `network.py` | 候選視窗、聯網查詢、翻譯 |
| `jobs.py` / `backup.py` | 背景工作、ZIP 備份 |
| `tests` | 行為與畫面測試 |

本機已有 `vendor` 相依套件，可用 Python 3.12 執行 `python run.py`。未封裝版預設使用專案根目錄 `data`，與封裝版分開；若需測試正式資料，先備份，再明確設定 `PROMPT_STUDIO_DATA` 指向該目錄。

新環境可用 `python setup_dependencies.py` 安裝指定 Qt，需要網路。本次使用 Python 3.12.14、PySide6 Essentials 6.11.2、PyInstaller 6.22.2。開發封裝工具安裝在專案內：

```powershell
python -m pip install --prefix .builder PyInstaller==6.22.2
python build_windows.py
```

封裝先寫入 `build/package`，再替換 `release/PromptStudio/_internal` 的程式元件，保留現有 `data`。更新前先關閉應用，不要把個人檔案放在 `_internal`。封裝時會隔離其他軟體的搜尋路徑，避免混入不相容的 DLL。`python tests/test_studio.py` 執行行為測試，`python tests/visual_smoke.py` 產生測試畫面；都不使用正式資料庫。

尚未加入 ComfyUI 模型與採樣參數自動同步、AI 長句拆 Tag、Civitai 自動下載、模型內容分析、重複圖片偵測或完整歷史工作流還原。
