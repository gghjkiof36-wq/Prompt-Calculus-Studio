# 使用這一版 PCS

開啟資料夾內的 `PromptCalculusStudio.exe`，或執行「啟動PCS.bat」。程式已包含執行所需元件，不需要另外安裝 Python。請保留完整資料夾，不要只移動 EXE。

第一次開啟會顯示「歡迎使用」，側欄可找到素材、筆記模板、參考與 Markdown 相容性測試。

## 素材

開啟「素材」中的分類文件，就能搜尋、編輯與拖入 Canvas。

| 分類 | 用途 |
| --- | --- |
| 場景與環境 | 建立地點與空間 |
| 光線與氣氛 | 比較時間、光源與明暗 |
| 構圖與鏡頭 | 控制視角、景別與留白 |
| 材質與風格 | 比較表現方式 |
| 研究與學習 | 保存研究、教學及推導的提示文字 |
| 寫作與整理 | 保存摘要、校對、設定與回顧的提示文字 |

每類有六份文字、兩份組合及一份三段流程。流程是可編排的素材內容；它不會自行呼叫 LLM。

選擇一份文字素材，複製後改成自己的內容。組合與流程可以再調整成員和順序。拖入 Canvas 的副本可獨立修改，素材分類原件仍保留。

「筆記模板」提供八份可複製的 Markdown 文件。檔案內的提示只是起點，可以刪掉或換成自己的格式。

素材與筆記都是一般本機文件。備份時保留整個 `files`，包括其中的 `assets`；工作區設定與恢復紀錄另在 `data`。更新時使用「沿用既有資料」，選擇上一版的程式資料夾即可繼續使用同一份內容。

## 畫面動畫

「設定 → 介面個人化 → 操作行為」可選擇關閉、櫻花、下雨或雪花。預設關閉；效果只作輕量點綴，不擋住編輯。縮小、切到背景或啟用「減少動態效果」時暫停。

## Chrome 傳入

從 PCS 的下載紀錄頁按「加入 Chrome」，依序連接 PCS 並載入擴充。Chrome 仍需手動啟用開發人員模式及載入未封裝項目。更新後請重新載入擴充，並重新整理 ChatGPT 頁面。
