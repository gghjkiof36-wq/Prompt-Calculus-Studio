**Prompt Calculus Studio · 0.8.9 Beta3**

在同一個工作區寫筆記、整理 Prompt 素材，再把想法放進 Canvas。

這是可以直接編輯的 Markdown 文件。從內容側欄可以再次開啟；重新啟動程式會接續上次的分頁安排。

## 從這裡開始

| 想做的事 | 操作 |
|---|---|
| 寫一份筆記 | 開啟新分頁，選擇 Markdown |
| 整理提示詞 | 開啟新分頁，選擇 Prompt 分類 |
| 建立工作流程 | 開啟新分頁，選擇 Canvas |
| 先跟著練習 | 閱讀 [從筆記到 Prompt](入口/00-從這裡開始.md) |

按 **Ctrl+T** 開啟新分頁。新文件會出現在左側「內容」；也能把分頁放到左右兩側，對照筆記、素材與 Canvas。

## 寫筆記

Markdown 有編寫、原文、閱讀三種視圖。用工具列插入標題、表格、連結與待辦，再切到閱讀查看結果。

- 按 **Ctrl+F** 搜尋目前文件，**Ctrl+H** 取代文字。
- 按 **Ctrl+Shift+V** 貼上純文字。
- 展開大綱後，點標題跳到對應段落。
- 按 **Ctrl+S** 保存筆記，再關閉或切換文件。

[海岸筆記](入口/01-海岸筆記.md) 包含表格、待辦、圖片、公式、Mermaid 與文件連結，可以直接在程式裡練習。

## 整理 Prompt 素材

開啟內容側欄「入口」裡的 **02-海岸素材**，試著搜尋、預覽及編輯。

- **文字**：保存常用提示詞，也能準備不同文字版本。
- **組合**：把場景、光線與構圖組成一份素材。
- **流程**：安排多個段落依次使用。

教材有三份文字、一份組合及一份流程。修改前可先複製文件，保留一份初始教材。

「素材」資料夾另外提供場景與環境、光線與氣氛、構圖與鏡頭、材質與風格四個圖片提示詞分類，共 36 份文字、組合和流程素材。

研究與寫作的方法放在「筆記」資料夾的 [研究與學習](筆記/研究與學習.md) 和 [寫作與整理](筆記/寫作與整理.md)。兩份都是可以閱讀、編輯的 Markdown 文件。

「筆記模板」有八份可直接複製的文件：每日筆記、研究筆記、學習與推導、實驗紀錄、專案規劃、會議紀錄、角色設定及每週回顧。

[公式與單位](參考/公式與單位.md) 收錄常用的數學與物理寫法；[Markdown 相容性測試](Markdown 相容性測試/Markdown-相容性測試.md) 可對照公式、表格、連結與圖片的實際顯示。

## 建立乾淨的 Canvas

新增 Canvas 時，只有以下六個預設模組：

**畫布 → Prompt 輸出 → CLIP 輸入 → 預排程 → Stage → 圖片預覽**

沒有預填提示詞、圖片、生成紀錄或測試綁定。可以先將文字素材拖進畫布，從 Prompt 輸出查看組合結果；新增與位置調整會自動保存。

內容側欄裡的 **03-練習畫布** 也是同樣的乾淨入口。放入 Canvas 的素材是獨立副本，修改副本不會改掉素材庫原件。

筆記、素材整理與 Canvas 編排可離線使用。需要生成圖片時，再按照 [連接 ComfyUI](入口/04-連接ComfyUI.md) 選擇自己的工作流、設定 CLIP 與 Stage。

## 保存與接著練習

自己的文件與教材都放在程式旁的 `files` 資料夾，設定與工作區記錄放在 `data`。備份時請一併保留。加入其他本機資料夾後，編輯會直接保存到該位置。

大型 Markdown 首次閱讀可能短暫停頓。更新時先關閉舊版，在新版資料夾執行「沿用既有資料.bat」，選擇舊版 PCS 資料夾；之後直接開啟新版 EXE 就會使用原本的文件、素材與設定。請保留舊資料夾中的 files 和 data，不要同時用新舊程式編輯同一份資料。

接著打開 [操作練習](入口/05-操作練習.md)，試試分頁、搜尋、拖放與保存重開。
