# 從筆記到 Prompt

這份教材用「海岸散步」作為練習主題。內容都是可自由修改的示範，不需要連接 ComfyUI 就能完成前三步。

這個「入口」資料夾隨程式提供，可以直接在 PCS 裡練習。若想保留初始教材，先複製文件，再修改副本。

## 1. 先整理想法

從內容側欄開啟 [海岸筆記](01-海岸筆記.md)，在編寫、原文和閱讀之間切換。

- 將第一段的「清晨」改成「傍晚」。
- 展開大綱，按「構圖與光線」跳到對應位置。
- 保存後關閉分頁，再開啟，確認文字仍在。

閱讀頁的公式與流程圖需要一點時間載入。它們使用本機元件，不需要登入或連線。

## 2. 找到可重用的素材

從內容側欄開啟 **02-海岸素材**。它是一份 Prompt 分類文件。

1. 搜尋「海岸」，查看對應素材與預覽文字。
2. 打開「海岸場景」編輯視窗，修改文字後保存。
3. 看看「海岸組合」如何把場景、光線、構圖放在一起；「晨昏變化」則示範不同段落依次使用。

名稱和中文別名是用來尋找素材的；英文提示詞是這份練習的實際輸出內容。可以改成你慣用的文字。

## 3. 把素材放進 Canvas

從內容側欄開啟 **03-練習畫布**。初始內容只有六個預設模組：

**畫布 → Prompt 輸出 → CLIP 輸入 → 預排程 → Stage → 圖片預覽**

1. 把素材頁與 Canvas 放到左右兩側。
2. 將「海岸場景」和「暖色光線」拖入畫布模組，或使用素材頁的「加入 Canvas」。
3. 在 Prompt 輸出查看合成的文字。新增與位置調整會隨 Canvas 保存。
4. 修改畫布內的文字副本，再回到素材頁，確認原素材仍保留。
5. 按 Undo／Redo 觀察放置結果，關閉再重開確認保存內容。

放到 Canvas 的素材是獨立副本。兩個模組即使使用相同名稱，也不代表編輯會互相同步。

## 4. 需要生成圖片時

先完成 [ComfyUI 接續步驟](04-連接ComfyUI.md)。本教材沒有替你設定模型、外部工作流或欄位綁定；CLIP 與 Stage 初始待綁定是正常狀態。

完成後可用 [操作練習](05-操作練習.md) 檢查常用流程。
