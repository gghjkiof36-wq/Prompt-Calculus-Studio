# 接上自己的 ComfyUI

筆記、素材與 Canvas 整理可以離線使用。要產生圖片，需要自己的 ComfyUI、模型，以及原本能成功生成的工作流；教材不包含模型或虛構的生成結果。

## 安裝同版配套

1. 先在自己的 ComfyUI 測試既有工作流，確認模型及必要節點可用，保存工作流。
2. 關閉 ComfyUI，在 PCS 的「探索 → ComfyUI → 連線與工作流」使用安裝／更新入口。
3. 使用本包 `Program/extensions` 中的一份同版擴充。通用、legacy、modern 擇一，不要同時安裝三份。
4. 重新啟動後端，刷新 ComfyUI 網頁，再連接 PCS。

若不確定自己的版本適用哪份配套，先閱讀完整指南的「ComfyUI 相容性」。不要僅因檔名帶有某個版本，就認為你的所有自訂節點都已驗證。

## 綁定六個預設模組

| 模組 | 在這個流程中的用途 |
|---|---|
| 畫布 | 放置、編輯及安排文字素材 |
| Prompt 輸出 | 查看畫布組合出的提示詞 |
| CLIP 輸入 | 選擇你工作流中的文字輸入欄位 |
| 預排程 | 控制本次流程的安排與執行次數 |
| Stage | 選擇實際生成工作流及相應參數 |
| 圖片預覽 | 查看回傳圖片 |

在 CLIP 選擇真正要寫入的文字欄位，在 Stage 選擇你已測試成功的工作流。先保留一次執行，核對 Prompt 與參數後才執行。未綁定前顯示待綁定是正常的。

## 第一次執行

保持 PCS、ComfyUI 後端及網頁開啟。確認實際送出的內容、回傳圖片與保存位置，再增加批次或排程。

如果出現錯誤，先保存工作流與錯誤訊息，確認後端和網頁的擴充版本一致。不要在執行狀態不明時反覆按執行。

生成圖片可能包含提示詞或工作流資料；分享前請檢查。完整說明可在本包 `Program/docs/guide` 查閱「ComfyUI」「Stage」「資料與備份」。
