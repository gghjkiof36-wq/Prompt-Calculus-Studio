# 操作練習

在教學工作副本上完成下面幾項，不需要把自己的正式資料拿來試。

| 操作 | 應該看到的結果 |
|---|---|
| 新增一份 Canvas | 只有六個乾淨預設模組，沒有提示詞、圖片或模型綁定 |
| 開啟海岸筆記，切換原文與閱讀 | 表格、圖片、公式及流程圖可閱讀，原文仍可編輯 |
| 在大綱選擇標題 | 跳到對應段落 |
| 搜尋「海岸」 | 找到相關段落或素材 |
| 按 Ctrl+Shift+V 貼上複製的文字 | 以原文貼入，不附帶其他程式的文字格式 |
| 將素材與 Canvas 左右並排 | 兩個頁面同時顯示，可調整分隔位置 |
| 將文字素材加入畫布 | Prompt 輸出反映新增的內容 |
| 修改畫布內的文字副本 | 素材庫原件維持原有內容 |
| 對放置操作 Undo／Redo | 文字卡片移除後可還原 |
| 關閉文件再重開 | 剛才保存的內容保留 |
| 收合側欄後把游標移向左側 | 側欄暫時展開，移開後收回 |
| 從設定返回原來的左右分頁 | 兩側內容一起恢復 |

若結果不符合，記下操作順序與當時文件；可以連同練習副本回報，避免傳送私人資料。

這份表是使用者練習，並不表示所有硬體、輸入法或 ComfyUI 組合都已驗證。
