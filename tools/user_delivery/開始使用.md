# 開始使用 PCS 0.8.9

把筆記、Prompt 素材與 Canvas 工作流程放在同一個本機工作區。

這份完整包已包含 Windows 執行環境。請先完整解壓到新的資料夾，再選擇一個入口：

| 想做的事 | 開啟的檔案 |
|---|---|
| 直接開始自己的工作 | [Start-PCS.cmd](Start-PCS.cmd) |
| 跟著教材練習 | [Start-Tutorial.cmd](Start-Tutorial.cmd) |
| 先看操作與畫面 | 繼續閱讀本頁，或開啟 [教學導覽](Tutorial/00-從這裡開始.md) |

在檔案總管雙擊啟動檔即可。瀏覽器若把啟動檔當作下載，請回到解壓後的資料夾開啟，不需要重新下載。

## 乾淨的工作入口

`Start-PCS.cmd` 使用新的 `MyFiles` 內容資料夾。從首頁新增 Canvas 後，會得到以下六個預設模組：

**畫布 → Prompt 輸出 → CLIP 輸入 → 預排程 → Stage → 圖片預覽**

畫布沒有預填提示詞、圖片、生成紀錄或測試綁定。CLIP 與 Stage 要使用你自己的 ComfyUI 工作流才能執行生成；筆記、素材整理與 Canvas 編排可先離線使用。

已有文件會保留自己的模組與內容，不會在開啟時被替換成預設布局。

## 跟著做一遍

`Start-Tutorial.cmd` 會在第一次開啟時，把教材複製到 `Practice`，並使用獨立的 `TutorialData` 保存練習設定。之後開啟會接續你的練習，不會重新覆蓋。

教材包含：

- **筆記範例**：標題、表格、待辦、程式碼、圖片、公式、Mermaid 與筆記連結。
- **Prompt 素材**：可搜尋的文字、替代段落、組合與流程，附中文名稱和用途。
- **乾淨 Canvas**：六個預設模組，跟著步驟把文字素材放進畫布，查看 Prompt 輸出。
- **操作練習**：左右分頁、保存重開、Undo／Redo、搜尋、側欄展收與獨立副本。
- **ComfyUI 接續說明**：配套安裝、綁定、第一次生成與檢查方式。

教材原件在 `Tutorial`。想重新練習時，先關閉教學視窗，把 `Practice` 和 `TutorialData` 另存到別處，再開啟教學入口。不要直接刪除其中想保留的內容。

## 我的文件放在哪裡

| 資料夾 | 用途 |
|---|---|
| `MyFiles` | 你自己新增的筆記、Prompt 分類及 Canvas |
| `UserData` | 日常工作設定與內部記錄，首次啟動後建立 |
| `Tutorial` | 隨包附上的教材原件 |
| `Practice` | 可以修改的教材副本，首次開啟教學後建立 |
| `TutorialData` | 教學的設定與工作區記錄 |
| `Program` | 完整程式與配套，請保留整個資料夾 |

備份時，請同時保留自己的內容與設定。加入其他本機資料夾會直接編輯該位置的文件，不會自動複製；更新版本時先使用內容副本，新舊程式不要同時寫入同一份資料。

日後保存 Canvas 或 Prompt 分類時，可能看到名稱含 `.recovery-` 的檔案；那是保存保護留下的回復副本，不是一般教材，也不表示它是測試垃圾。遇到保存衝突時請先保留它們與原文件。

## 版本與目前限制

這是 **0.8.9 Alpha 1 的本機交付更新**，包含乾淨 Canvas 入口的修正與使用者教材，交由發布組核對。既有 GitHub 發布頁的附件仍是先前公開批次；不要把兩份包的校驗值混用。

Windows 完整包目前僅供本機使用。大型 Markdown 的效能仍有限制：接近 8 MiB、含大量短段落時，首次閱讀可能短暫停頓。完整新機、輸入法、多螢幕與真實 GPU 流程仍有待確認範圍。

R2 是較早的開發試用包，其合成資料與保存回復副本不包含在這份教材內。更新不會搬動或刪除原 R2 資料。
